# Enable Telegram Threads for Your Hermes Agent Bot

Melvin Vivas · X post · 2026-08-04 · [Open on X](https://x.com/melvindvivas/status/2084607372371329398)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** beginner

## Summary

If you use Hermes through a Telegram bot, turn on threads so you can talk to the agent about different topics in separate threads. You enable this in Telegram's BotFather with the /setthreads command.

## Key points

- Threads let you keep separate conversations with your agent, one per topic.
- Open a chat with BotFather in Telegram.
- Type /setthreads.
- Select your Hermes bot to enable threads for it.
