## Summary

This is a music video, not a tutorial. It's a funny song about how a developer's job moves from writing code by hand to managing AI coding agents. The lyrics joke about familiar problems: the agent changes 47 files when you asked for minimal changes, it claims 100% confidence and breaks something else minutes later, and several agents disagree about the plan. Its main point is that years of coding experience still matter, because they "moved one layer up" into reviewing diffs and steering the agents. The quoted post says it was made with Claude Opus 5.5, Suno V6, Codex and ChatGPT.

## Key points

- This is mainly entertainment: a song about developers moving from writing code by hand to working with AI coding tools.
- Recurring problem: you ask for a small fix and the agent rewrites half the app ('keep the changes minimal' -> '47 files changed').
- Don't trust an agent's 'I found the issue, 100% confidence'. Test and read the diff before accepting changes.
- Having several agents or models review each other often turns up bugs a single model missed ('ask another model... I find six bugs immediately').
- When an attempt fails, the loop is: revert, write a new prompt with more context, and try again.
- Core message: coding experience doesn't disappear. It 'moves one layer up' into planning, reviewing and directing AI agents.
- Tools used to make the song (per the quoted post): Claude Opus 5.5, Suno V6 (music), Codex and ChatGPT.
