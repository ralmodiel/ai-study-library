# Pi Coding Agent: Four Built-In Tools (read, bash, edit, write)

Melvin Vivas · X post · 2026-08-10 · [Open on X](https://x.com/melvindvivas/status/2086793807895683107)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The quoted post explains that the Pi coding agent ships with only four tools: read, bash, edit and write. It argues these are mostly all a coding agent needs, because models already know how to use bash well. Pi's SDK lets you add these same primitives to your own app.

## Key points

- Pi's four built-in tools are read, bash, edit and write.
- A small set of basic tools is enough for an effective coding agent.
- Models are good at using bash and can do more with these basics than you might expect.
- Pi's SDK lets you add these tool primitives to your own application.
