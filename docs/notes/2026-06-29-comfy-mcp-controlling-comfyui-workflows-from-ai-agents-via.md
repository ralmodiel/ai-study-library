# Comfy MCP: Controlling ComfyUI Workflows from AI Agents via MCP

Melvin Vivas · X video post · 2026-06-29 · 0:33 · 1,443 views · [Open on X](https://x.com/melvindvivas/status/2071653463487107207)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Melvin Vivas shares a quoted launch post for Comfy MCP, now in public beta. The launch calls it the first MCP server built for production pipelines. It connects AI agents and coding assistants such as Claude, Codex, Cursor and Hermes to the ComfyUI ecosystem. That lets you run image and media generation workflows with natural-language prompts. The video has no spoken content, so everything here comes from the post text.

## Key points

- Comfy MCP is an official Model Context Protocol (MCP) server for ComfyUI, launched in public beta.
- It is billed as the first MCP built for production pipelines, not just local experiments.
- Supported clients named in the post: Claude, Codex, Cursor and Hermes.
- You can run any ComfyUI workflow by describing it in natural language to your agent.
- You can search ComfyUI models, nodes and templates from inside the agent.
- You can share a workflow URL with the agent (the post text is cut off at this point).
- Takeaway: MCP lets general-purpose agents drive specialised tools like node-based diffusion pipelines without custom glue code.
