Summary

This is a 15-second reel that reads out a list of AI engineering topics as a study roadmap. The list goes from LLM basics through embeddings, vector databases and RAG, then agents and MCP, then LLMOps, observability, evaluation with LLM-as-a-judge, and AI safety. It ends with machine learning basics and the creator's community. The video doesn't name any specific courses or videos. The caption asks viewers to comment "AI" to get the full roadmap and an invite to the creator's AI engineering community.

Key points

  • Topics in the order spoken: LLMs, embeddings, vector databases, RAG, hybrid retrieval, agents, agentic design patterns, multi-agents, agent memory, MCP, LLMOps, observability, LLM as a judge, AI safety and ethics, machine learning basics.
  • Retrieval comes before agents: learn embeddings and vector databases, then RAG, then hybrid retrieval (keyword search combined with vector search).
  • The agent topics go from single agents to agentic design patterns, multi-agent systems, agent memory, and the Model Context Protocol (MCP) for connecting tools.
  • The production topics are LLMOps, observability, and using an LLM as a judge to evaluate outputs.
  • AI safety and ethics, and machine learning basics, are listed as separate topics.
  • The full roadmap with the actual videos to watch is only available by commenting "AI". The reel itself doesn't list specific videos.
