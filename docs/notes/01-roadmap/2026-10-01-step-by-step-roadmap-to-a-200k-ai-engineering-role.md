## Summary

This is a quick roadmap for landing a well-paid AI engineering job. First, learn a core stack: Python, FastAPI, the LangChain family of tools, Langfuse, Terraform and vector databases. Add machine learning basics and a working understanding of how LLMs work, and build projects with those skills. Then use AI to compare your skills against what target companies are hiring for, build a project that fills the gap, post about it on LinkedIn, and prepare for interviews with a focus on system design and how you use AI tools.

## Key points

- Core stack: Python, FastAPI, LangChain, Langfuse, LangSmith, LangGraph and Terraform.
- Vector databases to learn: pgvector, Weaviate and Pinecone.
- Machine learning basics: PyTorch, scikit-learn and a basic understanding of how LLMs work.
- Build projects with each skill you learn.
- Research your target companies: what teams they have and what roles they're hiring for. Give that to an AI and ask for a market gap analysis that shows which skills you're missing and what you should build.
- Build the project the gap analysis points to, add it to your resume (AI can write the entry for you), and post about it on LinkedIn.
- In interview practice, spend much more time on system design and how you use AI tools than on hand-coding.
- Once you get an interview, ask what specific problem the company wants this hire to solve.

- [ ] Learn Python, FastAPI, LangChain, Langfuse, LangSmith, LangGraph, Terraform and vector databases (pgvector, Weaviate, Pinecone).
- [ ] Learn machine learning basics with PyTorch and scikit-learn, and get a basic understanding of how LLMs work.
- [ ] Build projects using each of these skills.
- [ ] Research your target companies' teams and the roles they're hiring for.
- [ ] Give that research to an AI and ask for a market gap analysis of the skills you're missing and what you should build.
- [ ] Build the project the gap analysis suggests and add it to your resume (you can ask AI to write the entry).
- [ ] Post on LinkedIn about the project.
- [ ] Practice interviewing, with a focus on system design and how you use AI tools.
- [ ] In interviews, ask what specific problem the company wants this hire to solve.
- [ ] Watch the full roadmap video.
- [ ] A portfolio project chosen from an AI-assisted market gap analysis of what your target companies are hiring for.
