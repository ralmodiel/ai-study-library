Summary

Bashiri Smith sums up an article by an unnamed "biggest AI expert" that lists four AI engineering skills every developer will need: building and deploying AI apps, software engineering fundamentals, using AI coding agents at an elite level, and writing clear specs. The article's main point is that having AI engineering skills is not the same as being an AI engineer. It compares this to cloud: every developer uses the cloud, but not every developer is a cloud engineer. Most of the reel is a pitch for the creator's AI engineer community.

Key points

  • Skill 1: Build and deploy AI applications end to end.
  • Skill 2: Keep strong software engineering fundamentals. AI does not replace them.
  • Skill 3: Use AI coding agents at an elite level.
  • Skill 4: Write clear specs that guide what gets built, whether by agents or by teams.
  • AI engineering skills are not the same as the AI engineer role. Every developer needs the skills, but not everyone will hold the title.
  • Cloud analogy: every developer works with the cloud, but not every developer is a cloud engineer. AI is heading the same way.
  • The creator's opinion: since you need the skills anyway, aim for the full AI engineer role and its higher pay.
  • The source article and its author are not named in the reel.
