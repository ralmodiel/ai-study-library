# Melvin Vivas's open-source AI tools, built with Codex

Melvin Vivas · X post · 2026-09-14 · [Open on X](https://x.com/melvindvivas/status/2099223578558538050)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP, Evaluation (Evals) & Testing · **Level:** intermediate

## Summary

Melvin Vivas lists eight open-source projects he builds and maintains mostly with OpenAI Codex. They cover multi-agent orchestration in Codex, a single API for AI tasks on local and cloud models, local evals, an AI coworker app, a JSONL dataset viewer for fine-tuning data, a Markdown editor with local AI editing, and reusable agent skills. Together they give learners working code to study and use across agents, evals, LLMOps and fine-tuning.

## Key points

- codex-astra-luna-orchestrator: uses Astra (or Sol) as the root orchestrator and Luna models as subagents inside Codex.
- ai-backends: an API server for common AI tasks. It runs locally with Ollama or LM Studio, or in the cloud through OpenRouter, OpenAI or Anthropic.
- local-evals: an eval app that runs on your machine against local models or any OpenAI-compatible API.
- coworker: an open-source AI coworker with skills, tools, and support for local and cloud models.
- aibackends: a Python library for running common AI tasks locally on your GPU.
- jsonl-viewer: lets you view and edit JSONL datasets for fine-tuning and training.
- markdown-editor: a lightweight Markdown editor with local AI editing; skillsbento: free reusable skills for AI agents.
- He uses Codex heavily to maintain these projects and asks OpenAI to support open-source work with more usage.
