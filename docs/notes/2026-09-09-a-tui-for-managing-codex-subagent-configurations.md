# A TUI for Managing Codex Subagent Configurations

Melvin Vivas · X post · 2026-09-09 · [Open on X](https://x.com/melvindvivas/status/2097587630083023211)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator previews a terminal UI (TUI), written in Go, for building Codex configurations for subagent setups. The idea is to save config sets and apply them to each project. It would be added to his codex-astra-luna-orchestrator repo, and he asks followers whether it is worth shipping.

## Key points

- The TUI generates Codex configurations for multi-agent (subagent) setups.
- Saved config sets could be reused across projects.
- It is built in Go, so it needs a build step.
- It would go in the codex-astra-luna-orchestrator GitHub repo.
- The creator worries it might make things more complicated, so it is not decided yet.
