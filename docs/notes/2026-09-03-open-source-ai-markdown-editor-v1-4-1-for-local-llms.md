# Open-source AI Markdown Editor v1.4.1 for local LLMs

Melvin Vivas · X post · 2026-09-03 · [Open on X](https://x.com/melvindvivas/status/2095504880660332952)

**Topics:** AI Dev Tools & Productivity, Portfolio Projects · **Level:** beginner

## Summary

Melvin Vivas released v1.4.1 of his open-source markdown editor. It has AI editing and works with local models through Ollama and LM Studio. This release adds a wide view, puts the chat and outline panels more in view, and fixes bugs.

## Key points

- The markdown-editor repo (donvito/markdown-editor) is a lightweight markdown editor with AI editing.
- It works with local LLM runtimes: Ollama and LM Studio.
- v1.4.1 adds a wide view.
- Quality-of-life updates put the chat and outline panels more in view.
- The release includes bug fixes.
- It's a good example of building a small app on top of local models.
