# Using a Personal AI Agent to Monitor a Stock Portfolio

Melvin Vivas · X post · 2026-07-12 · [Open on X](https://x.com/melvindvivas/status/2076021771242004878)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator gave his Hermes personal AI agent his stock portfolio and asked it to watch news and market events that affect it. The agent sends pre-market and post-market briefings, plus updates every 30 minutes during trading hours. It shows how a scheduled, recurring agent task can automate information gathering.

## Key points

- Give the agent context first: send it the list of portfolio holdings.
- Tell it what to watch for: news and market events that affect those holdings.
- Set a schedule: pre-market and post-market summaries.
- Set how often it reports during trading hours: every 30 minutes.
- The agent gathers the information, and the person still makes the investment decisions.
- The creator ran Hermes with Grok 4.5 as the main model (from related posts).
