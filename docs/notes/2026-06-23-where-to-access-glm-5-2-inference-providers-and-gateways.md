# Where to Access GLM 5.2: Inference Providers and Gateways

Melvin Vivas · X post · 2026-06-23 · [Open on X](https://x.com/melvindvivas/status/2069421300364493126)

**Topics:** LLMOps, Deployment & Monitoring, LLM Fundamentals · **Level:** intermediate

## Summary

Lists the providers that serve the GLM 5.2 model: Z.ai's own coding plan, Together AI, Baseten, Fireworks AI, Vercel AI Gateway and OpenRouter. It's a useful map for choosing where to call an open-weight model.

## Key points

- GLM 5.2 is available through Z.ai's coding plan, from the model's own lab.
- Hosted inference providers for it: Together AI, Baseten and Fireworks AI.
- Gateways or routers for it: Vercel AI Gateway and OpenRouter, which let you reach many models through one API.
- Open-weight models usually have several providers, so compare price, speed and reliability before picking one.
