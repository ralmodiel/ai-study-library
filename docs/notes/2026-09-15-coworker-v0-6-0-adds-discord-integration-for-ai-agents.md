# Coworker v0.6.0 Adds Discord Integration for AI Agents

Melvin Vivas · X post · 2026-09-15 · [Open on X](https://x.com/melvindvivas/status/2099540403431342459)

**Topics:** AI Agents, Tool Use & MCP, Portfolio Projects · **Level:** intermediate

## Summary

Version 0.6.0 of Coworker lets you pair an agent with Discord. You can message it from Discord, and the messages sync to the desktop app. Discord threads are supported.

## Key points

- You can pair a Coworker agent with Discord and message it from there.
- Discord messages sync to the desktop app.
- Discord threads are supported natively.
- The release is on the GitHub repo.
