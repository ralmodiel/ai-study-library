## Summary

Announces that OpenAI's GPT Image 2 image model can be used through Replicate. The quoted post says the model has strong photorealism, sharp text rendering and follows layouts closely, so it suits UI and design work.

## Key points

- GPT Image 2 is OpenAI's new image generation model.
- It is available through Replicate's hosted model platform.
- Strengths: photorealism and crisp text rendering inside images.
- Follows layouts closely, making it useful for UI mockups and design assets.
