# Kev-0.5B: A Tiny Open-Source Decision Model to Train on a MacBook

Melvin Vivas · X post · 2026-09-19 · [Open on X](https://x.com/melvindvivas/status/2101110094868165108)

**Topics:** Fine-tuning & Model Customization · **Level:** intermediate

## Summary

Shares Kev-0.5B, a tiny open-source decision model similar to Jev, with a TypeSafe-compatible API. The quoted post says it is built on Qwen2.5-0.5B, and you can train and run it on a MacBook Pro. The model card and weights are on GitHub.

## Key points

- Kev-0.5B is a small decision model, about 0.5B parameters.
- The quoted post says the base is Qwen2.5-0.5B, but the GitHub repo title says Qwen3.5/3.8. Check the repo.
- Comes with a TypeSafe-compatible API.
- Small enough to train and run on a MacBook Pro.
- Model card and weights are on GitHub (jaredpalmer/kev).
