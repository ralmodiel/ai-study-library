## Summary

The creator installed Hermes Agent in both Telegram and Discord. He prefers Discord because the agent creates threads by default, which keeps conversations organized.

## Key points

- Hermes Agent can run inside chat apps such as Telegram and Discord.
- In Discord, Hermes creates threads by default, which keeps separate tasks apart.
