## Summary

NVIDIA's Nemotron 3 Ultra model can be used for free through OpenRouter. This is a cheap way to try a large open-weight model through one API.

## Key points

- Nemotron 3 Ultra is available on OpenRouter at no cost.
- OpenRouter gives one API for many models, including free ones.
- Free endpoints are handy for testing and prototyping.
