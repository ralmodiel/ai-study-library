## Summary

Melvin reacts to a leak saying Anthropic is building a Lovable-like feature for creating full-stack apps. He argues this would compete with app-builder startups such as bolt.new, Lovable and v0, and raises the platform risk of building on a model provider.

## Key points

- A leak suggests Anthropic is building a full-stack app builder similar to Lovable.
- This would compete directly with bolt.new, Lovable and v0.
- Platform risk: startups that build on a model provider's API can end up competing with that provider.
