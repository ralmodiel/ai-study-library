# Building a Jev Session-History Tool with Codex and Astra

Melvin Vivas · X post · 2026-09-29 · [Open on X](https://x.com/melvindvivas/status/2104907917560521090)

**Topics:** AI Dev Tools & Productivity, Portfolio Projects · **Level:** intermediate

## Summary

The creator is building a tool for Typesafe AI's Jev that keeps a history of Jev sessions and lets you run experiments. He built it with the AI coding tools Codex and Astra. The finished tool became the JevDev repo.

## Key points

- Goal of the tool: save a history of Jev sessions and run experiments on them.
- It was built with Codex and Astra.
- Jev comes from Typesafe AI (@typesafeai on X).
- The creator later published it as github.com/donvito/jev-dev.
