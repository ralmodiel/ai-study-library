# Make a motion-graphics showreel of your project with Claude Code

Melvin Vivas · X post · 2026-09-26 · [Open on X](https://x.com/melvindvivas/status/2103723422698373338)

**Topics:** AI Dev Tools & Productivity, Prompt & Context Engineering · **Level:** beginner

## Summary

The creator shares a ready-to-use prompt for Claude Code running Opus 5.5 on high effort. You run it inside your project's repo and it makes a 15-second motion-graphics video that shows off the project and its features. It shows that coding agents can make marketing videos for your projects, not only code.

## Key points

- Open a terminal in your project's repository so Claude Code can read the code and features.
- Pick the Opus 5.5 model with the 'high' effort setting.
- The prompt asks for a dynamic 15-second motion-graphics video and frames it like a motion designer's résumé showreel ('go all out').
- Name the product in the prompt (the example uses 'Coworker') so the video focuses on its features.
- Framing the prompt as a role-play ('show what an incredible motion designer you are') pushes the model to aim for higher-quality creative output.
