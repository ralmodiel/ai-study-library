Melvin Vivas · X post · 2026-05-13 · [Open on X](https://x.com/melvindvivas/status/2054290014696358166)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP, Portfolio Projects · **Level:** intermediate

## Summary

The creator built an unofficial Go version of the Cursor SDK, based on Cursor's official TypeScript SDK. He built it with Cursor and GPT 5.5 and tested it on his own repos. It shows how to port an SDK to another language with AI coding tools.

## Key points

- cursor-sdk-go is an unofficial Go SDK for Cursor.
- It was inspired by Cursor's official TypeScript SDK.
- It was built using Cursor with the GPT 5.5 model.
- The creator tested it against his own repositories.
