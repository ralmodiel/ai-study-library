# Building an Agent Command Centre with Hermes Agents in Docker

Melvin Vivas · X post · 2026-07-25 · [Open on X](https://x.com/melvindvivas/status/2080715551819899311)

**Topics:** AI Agents, Tool Use & MCP, LLMOps, Deployment & Monitoring · **Level:** intermediate

## Summary

The creator is running many Hermes agents in Docker containers to build a 'command centre' that manages multiple agents. It is a short pointer to a multi-agent setup.

## Key points

- Run many Hermes agent instances, each in its own Docker container.
- Containers let you scale the number of agents ('unlimited').
- A command centre is one place to manage and watch all the agents.
