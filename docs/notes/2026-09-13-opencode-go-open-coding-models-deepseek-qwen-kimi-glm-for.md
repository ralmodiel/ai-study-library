# OpenCode Go: Open Coding Models (DeepSeek, Qwen, Kimi, GLM) for $10/mo

Melvin Vivas · X post · 2026-09-13 · [Open on X](https://x.com/melvindvivas/status/2099099181327814984)

**Topics:** AI Dev Tools & Productivity, LLM Fundamentals · **Level:** beginner

## Summary

The creator recommends the OpenCode Go subscription as a cheap way to use leading open-weight models in the OpenCode coding agent. For $10 a month it gives access to DeepSeek, Qwen, Kimi and GLM models.

## Key points

- OpenCode Go bundles top open-weight models in one subscription.
- Models included: DeepSeek, Qwen, Kimi and GLM.
- Price is $10/month, which the creator calls a bargain.
- It's a low-cost way to try and compare open models in a coding agent.
