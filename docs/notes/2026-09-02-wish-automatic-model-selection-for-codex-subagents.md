# Wish: Automatic Model Selection for Codex Subagents

Melvin Vivas · X post · 2026-09-02 · [Open on X](https://x.com/melvindvivas/status/2095017628293320942)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator wants Codex to pick a model for each subagent automatically based on the task. Judging each task and choosing a model by hand adds mental load. The idea behind it is model routing in multi-agent systems.

## Key points

- Choosing a model for each subagent task by hand adds mental load.
- Routing tasks to models automatically by difficulty could cut both effort and cost.
