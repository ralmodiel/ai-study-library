## Summary

A quoted announcement says the next Claude Code version adds two built-in Skills, /simplify and /batch, which automate much of the work of getting a pull request to production. The creator jokes that Claude Code needs an /optimise skill for itself.

- Claude Code is adding two new Skills: /simplify and /batch.
- Together they automate much of the work of shepherding a pull request to production.
- Skills are invoked as slash commands inside Claude Code.
