# Single Agent vs Subagents in Codex: Trying Astra Only

Melvin Vivas · X post · 2026-09-10 · [Open on X](https://x.com/melvindvivas/status/2097897820061921319)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Melvin Vivas plans to work a full day in Codex using only the Astra model, with no subagents. Other users report this works better, and someone at OpenAI reportedly discouraged subagents. The open question is whether usage limits will last with a single strong agent.

## Key points

- Experiment: use only Astra in Codex for a full day, with no subagent orchestration.
- Community reports say a single strong model can do better than an orchestrator + subagents setup.
- A post from someone at OpenAI reportedly discouraged subagents in favor of Astra alone.
- The main risk is that usage limits run out with a single high-capability model.
