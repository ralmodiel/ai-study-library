# Let Claude Code or Codex handle Git commits, pushes and releases

Melvin Vivas · X post · 2026-08-27 · [Open on X](https://x.com/melvindvivas/status/2092701668362334622)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator answers a post asking for a 'GitHub for normies' (non-technical people). His point is that AI coding agents like Claude Code and Codex can now handle Git work for you. They can commit, push to GitHub and even publish app releases, so non-engineers can use GitHub without learning Git themselves.

## Key points

- Coding agents such as Claude Code and Codex can commit and push code to GitHub when you ask them.
- They can also create releases of your app.
- This makes GitHub usable for people who don't know Git.
