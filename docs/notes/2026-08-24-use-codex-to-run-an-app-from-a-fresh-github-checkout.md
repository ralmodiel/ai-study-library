## Summary

A short tip: give OpenAI Codex a freshly cloned GitHub repo and ask it to run the app. It finds the dependencies the project needs and installs them for you.

## Key points

- Clone a repo, then ask Codex to run the app.
- Codex finds the missing dependencies and installs them automatically.
- This saves you from setting up an unfamiliar project by hand.
