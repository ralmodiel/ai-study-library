# Ask Devin to Record a Demo Video to Verify Cloud Agent App Updates

## Summary

A short tip from Melvin Vivas: when you work with a cloud coding agent like Devin, ask it to record a demo video of the app changes it made. You can then check the update by watching the video, without downloading the code and running it on your own machine.

## Key points

- Cloud coding agents like Devin run your code in a remote environment, not on your machine.
- You can ask Devin to record a demo video showing the app after its changes.
- Watching the video lets you check UI and behavior changes without pulling the code and running it yourself.
- This speeds up the review loop when you delegate work to cloud agents.
- The 7-second video has no speech; the whole tip is in the caption.
