# Cohere's North Micro Vision: a small open-source vision model for documents

Melvin Vivas · X post · 2026-08-13 · [Open on X](https://x.com/melvindvivas/status/2087769941022069164)

**Topics:** LLM Fundamentals, Industry Trends & Job Market · **Level:** beginner

## Summary

Cohere released North Micro Vision, its smallest vision-language model so far. It is built for document understanding and is open-source under Apache 2.0. The weights are on Hugging Face, so you can try it locally.

## Key points

- North Micro Vision is Cohere's smallest vision-language model (VLM) so far.
- It is aimed at document understanding tasks.
- It is released open-source under the Apache 2.0 license, which allows commercial use.
- The model weights can be downloaded from Hugging Face.
