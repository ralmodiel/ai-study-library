# Building a production website with Opus 5.5 and TanStack

Melvin Vivas · X post · 2026-09-29 · [Open on X](https://x.com/melvindvivas/status/2104863802441585135)

**Topics:** AI Dev Tools & Productivity, Portfolio Projects · **Level:** beginner

## Summary

The creator says he built his business site aibackends.com using the Opus 5.5 model and the TanStack web framework with little effort. It is a short example of an AI coding agent plus a modern TypeScript stack shipping a real website.

## Key points

- aibackends.com was built with Opus 5.5 as the coding model
- TanStack was the web framework used
- The creator describes it as taking little effort, so agent plus TanStack is his preferred quick web stack
- aibackends.com is the creator's business for production AI workflow engineering
