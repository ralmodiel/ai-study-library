# Grok Build /goal: Long-Running Autonomous Tasks with Subagents

Melvin Vivas · X video post · 2026-06-23 · [Open on X](https://x.com/melvindvivas/status/2069159741167911258)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

xAI added a /goal command to Grok Build. It runs long tasks on its own, using several rounds of subagents to implement and then verify a single goal.

## Key points

- /goal runs long-running tasks autonomously
- It uses multiple rounds of subagents to implement and verify one goal
- Pattern: split the work into implementation and verification subagents for each objective
