# Claude desktop's built-in browser can import your Chrome profile

Melvin Vivas · X post · 2026-08-29 · [Open on X](https://x.com/melvindvivas/status/2093723324522348577)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

The creator praises the built-in browser in the Claude desktop app. It can import your Chrome profile, so you are logged in to your sites automatically when Claude browses for you.

## Key points

- The Claude desktop app has a built-in browser.
- It can import your Chrome profile.
- After the import, you are logged in to your sites automatically, so Claude can work on pages that need a login.
- Be careful: giving an AI agent your logged-in sessions has security and privacy risks.
