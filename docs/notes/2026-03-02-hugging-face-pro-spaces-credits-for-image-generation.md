## Summary

The creator recommends Hugging Face Pro because its Spaces credits let him generate lots of images with models hosted on Spaces. It is a quick tip on getting value from the HF Pro subscription.

## Key points

- Hugging Face Pro includes credits for running Spaces.
- The creator uses the credits to generate as many images as he can.
- Spaces host many image-generation models you can try without local hardware.
