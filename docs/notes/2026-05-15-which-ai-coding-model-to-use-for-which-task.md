# Which AI coding model to use for which task

Melvin Vivas · X post · 2026-05-15 · [Open on X](https://x.com/melvindvivas/status/2054966217698672859)

**Topics:** AI Dev Tools & Productivity, LLM Fundamentals · **Level:** beginner

## Summary

The creator shares the models he currently uses for coding, each matched to a type of task. He does most of his coding in Cursor and praises its new Agent Window.

## Key points

- GPT-5.5: big refactors and new features.
- Claude Opus 4.7: design tasks.
- Composer 2 (Cursor's model): asking questions, learning and medium-sized tasks.
- Keep a small set of models and pick by task type.
- He uses Cursor for most coding and likes the new Agent Window.
