## Summary

The creator's open-source jsonl-viewer tool can show which Codex traces are live and running. The tool views and edits .jsonl files, which are often used for fine-tuning and training datasets. That makes it handy both for checking agent sessions and for working with datasets.

## Key points

- jsonl-viewer is an open-source tool for viewing and editing .jsonl files.
- It can show which Codex session traces are live and still running.
- JSONL is a common format for fine-tuning and training datasets, so the same tool helps you check that data.
