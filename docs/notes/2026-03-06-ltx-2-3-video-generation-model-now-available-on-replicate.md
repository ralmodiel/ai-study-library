# LTX-2.3 Video Generation Model Now Available on Replicate

Melvin Vivas · X video post · 2026-03-06 · 0:39 · 121 views · [Open on X](https://x.com/melvindvivas/status/2029781573122544051)

## Summary

A short announcement that LTX-2.3, the video generation model from LTX (@ltx_model), can now be run on Replicate. The quoted release post lists what's new: sharper detail and on-screen text, better handling of complex prompts with several subjects, image-to-video from a start and end frame, cleaner audio, native portrait output, and 24/48 fps. There's no spoken explanation; the video is a 39-second demo with no speech.

## Key points

- LTX-2.3 is a video generation model from LTX (@ltx_model), and it can now be run through Replicate.
- Better fidelity: sharper detail and more readable on-screen text in the generated video.
- Complex prompts with several subjects are followed more reliably (the post says they 'stick').
- Image-to-video (I2V) can take both a start frame and an end frame, with smooth motion between them.
- Cleaner audio generation.
- Native portrait (vertical) output.
- Supports 24 and 48 fps output.
