# Use local Ollama models in ChatGPT Desktop (Codex app)

Melvin Vivas · X post · 2026-09-11 · [Open on X](https://x.com/melvindvivas/status/2098230113515266401)

**Topics:** AI Dev Tools & Productivity, LLM Fundamentals · **Level:** beginner

## Summary

ChatGPT Desktop (the Codex app) can now be set up, through a plugin, to use local models served by Ollama. You need Ollama 0.34 or later.

## Key points

- ChatGPT Desktop / the Codex app can use Ollama models through a plugin.
- Requires Ollama version 0.34 or later.
- Lets you run local models inside the ChatGPT/Codex desktop experience.
