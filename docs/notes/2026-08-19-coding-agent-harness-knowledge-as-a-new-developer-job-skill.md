# Coding agent harness knowledge as a new developer job skill

Melvin Vivas · X post · 2026-08-19 · [Open on X](https://x.com/melvindvivas/status/2089979485965992281)

**Topics:** Resume, Job Search & Interviews, AI Dev Tools & Productivity, Industry Trends & Job Market · **Level:** beginner

## Summary

The creator argues that developer job descriptions should now ask for knowledge of coding agent harnesses. In other words, knowing how to run and configure tools like Codex, Cursor or Claude Code is becoming a core engineering skill.

## Key points

- Coding agent harnesses are the tools that wrap an LLM with tools, loops and context, like Codex or Cursor agents.
- The creator thinks hiring should treat skill with these harnesses as a requirement.
- For learners: hands-on experience with agent harnesses is worth showing on your resume.
