# Local Data Studio: Inspect Private Datasets Without Hugging Face Pro

Melvin Vivas · X post · 2026-08-27 · [Open on X](https://x.com/melvindvivas/status/2092932800156782966)

**Topics:** Evaluation (Evals) & Testing, AI Dev Tools & Productivity · **Level:** beginner

## Summary

Hosting private datasets on Hugging Face needs a Pro subscription. As a free alternative, Melvin Vivas uses Local Data Studio, which Codex found for him. It is an open-source local tool for previewing and exploring JSONL, JSON, CSV, TSV and Parquet data.

## Key points

- Private datasets on Hugging Face require a Pro subscription.
- Local Data Studio lets you preview and explore datasets on your own machine for free.
- Supports JSONL, JSON, CSV, TSV and Parquet files.
- Features: scalable previews, image inspection, DuckDB SQL queries, exploratory data analysis (EDA), and Embedding Atlas.
- Coding agents like Codex can help you discover useful tools.
