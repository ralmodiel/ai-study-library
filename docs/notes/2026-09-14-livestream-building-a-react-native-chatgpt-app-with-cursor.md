## Summary

The creator is restarting his YouTube channel and shares an older full livestream where he builds a React Native ChatGPT app with Cursor, the OpenAI API and Expo. He notes that this was from the pre-agentic, copy-paste era of Cursor. He plans new live builds using Codex, agents and local models.

## Key points

- The livestream builds a React Native (iOS) ChatGPT-style app that integrates the OpenAI API.
- The tools used are Cursor (AI code editor), OpenAI and Expo.
- The linked timestamp (t=5160s, about 1:26:00) jumps into the middle of the build.
- It shows the older copy-paste workflow, before agentic coding tools.
- Upcoming content will cover live builds with Codex, agents and local models.
