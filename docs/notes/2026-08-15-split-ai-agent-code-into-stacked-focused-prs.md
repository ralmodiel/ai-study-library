# Split AI-agent code into stacked, focused PRs

Melvin Vivas · X post · 2026-08-15 · [Open on X](https://x.com/melvindvivas/status/2088346377491452182)

**Topics:** AI Dev Tools & Productivity · **Level:** intermediate

## Summary

A quoted tip: AI coding agents can build features quickly but often put everything into one huge pull request that is hard to review. The fix is to split the work into a stack of small, focused pull requests merged in order. The creator's 'who's gonna tell them' comment hints that many developers using AI agents don't do this yet.

## Key points

- AI coding agents tend to produce one giant, hard-to-review PR
- Split agent output into a stack of small, focused PRs
- Order the stacked PRs so each one builds on the one before
- Smaller PRs are easier for humans to review and safer to merge

- [ ] Next time an AI agent builds a feature, ask it to split the work into a stack of focused, ordered PRs
