**Topics:** LLM Fundamentals, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

OpenAI made GPT-5.3-Codex available to all developers through the Responses API. The creator notes this means you can now build agents on top of the Codex model.

## Key points

- GPT-5.3-Codex is available to all developers in the OpenAI Responses API.
- You can now build your own agents and coding tools on the Codex model.
- The model docs live on developers.openai.com.
