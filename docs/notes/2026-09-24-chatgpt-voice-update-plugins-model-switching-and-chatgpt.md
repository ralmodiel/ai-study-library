# ChatGPT Voice Update: Plugins, Model Switching and ChatGPT Work

Melvin Vivas · X video post · 2026-09-24 · 2:05 · 1,826 views · [Open on X](https://x.com/melvindvivas/status/2102848983655956911)

**Topics:** Industry Trends & Job Market, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Melvin Vivas shares OpenAI's announcement that ChatGPT Voice can now use plugins (email, calendar, Slack), switch between GPT-6 Astra, Sol and Luna, and run inside ChatGPT Work on web and mobile. In the demo video, someone gives spoken commands that turn into multi-step actions: booking calendar time, finding duplicate charges, sending emails, building a small website and checking the weather. The main point is that voice assistants are moving from answering questions to doing tasks with tools, like agents.

## Key points

- ChatGPT Voice can now call plugins such as email, calendar and Slack. It acts on your behalf instead of only answering questions.
- Voice mode supports switching models: GPT-6 Astra, Sol and Luna.
- Voice works inside ChatGPT Work on web and mobile, so you can create docs, decks, sites and spreadsheets or work through complex tasks by voice.
- Demo tasks: find a free 30-minute slot tomorrow and add it to the calendar; scan finances for duplicate charges, cancel one and email for a refund.
- More demo tasks: build a pottery-selling website and add a checkout page; email a marina to rent a boat, then check for the reply and book it.
- Lesson for AI engineers: voice is becoming a front end for agent loops with tool calls (read data, take actions, follow up across several turns).
