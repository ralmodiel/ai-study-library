## Summary

This short post shares the announcement that computer use now works inside Claude Code. Claude can open apps, click through the UI and test what it built, all started from the command line. The feature is a research preview for Pro and Max plan users. The video has no narration, so the note covers only what the caption says.

## Key points

- Computer use is now built into Claude Code, Anthropic's coding assistant that runs in the terminal.
- Claude can open your applications, click through the user interface and test what it built.
- Everything is started from the CLI, so Claude can write code and then check that it works end to end in a real UI.
- The feature is in research preview, so expect it to be limited or experimental.
- It is available only on the Claude Pro and Max subscription plans.
- The video has no speech; the details come only from the quoted announcement.
