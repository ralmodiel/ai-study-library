# Hy-MT1.5-1.8B-1.25bit: A 440MB Offline Phone Translation Model

Melvin Vivas · X video post · 2026-04-30 · [Open on X](https://x.com/melvindvivas/status/2049539051683004489)

**Topics:** LLM Fundamentals, Industry Trends & Job Market · **Level:** intermediate

## Summary

An open-sourced 1.8B-parameter translation model, quantized to 1.25 bits so it takes only 440MB, runs fully offline on a phone. It supports 33 languages and, according to its makers, beats Google Translate on standard benchmarks.

## Key points

- 1.8B parameters, quantized to 1.25 bits, for a 440MB model.
- Runs fully offline on a phone.
- Supports 33 languages.
- Claimed to match commercial translation APIs and 235B-scale models on standard benchmarks.
- Shows how far extreme quantization can push small on-device models.
