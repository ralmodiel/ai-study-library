MLflow 3.17.0: Jev models as LLM judges in GenAI evaluate

This note summarises a post by Melvin Vivas on X, posted 12 October 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Melvin Vivas · X post · 2026-10-12 · Open on X

Topics: Evaluation (Evals) & Testing, LLMOps, Deployment & Monitoring · Level: intermediate

Summary

MLflow 3.17.0 adds 'Jev Decisions'. You can now use TypeSafe's Jev models as judges in mlflow.genai.evaluate() for yes/no and fixed-category checks. These judge calls work with MLflow Tracing and AI Gateway, so you can inspect and govern them in one place.

Key points

  • MLflow 3.17.0 adds 'Jev Decisions' for evaluating GenAI apps.
  • TypeSafe's Jev models can be used as judges inside mlflow.genai.evaluate().
  • Built for yes/no checks and checks with a fixed set of categories.
  • Judge calls work with MLflow Tracing, so you can inspect them.
  • AI Gateway support lets you govern judge calls in one place.
