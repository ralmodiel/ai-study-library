Summary

Building evals takes real effort, mostly in finding existing datasets or generating synthetic ones. Coding agents like Claude Code or Codex can help with that work.

Key points

  • Searching for eval datasets takes a lot of time.
  • Generating synthetic eval data is another option, but it also takes time.
  • Use Claude Code or Codex to help find or generate datasets.
