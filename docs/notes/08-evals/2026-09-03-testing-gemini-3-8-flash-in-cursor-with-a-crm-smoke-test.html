Testing Gemini 3.8 Flash in Cursor with a CRM Smoke Test

Summary

The creator tested Gemini 3.8 Flash in Cursor using his own CRM app 'smoke test'. It was fast and built every requested feature, but it made a UI mistake on a modal background. He finds it worth trying and will keep testing it on real work.

Key points

  • Keep a personal smoke-test app (here a CRM) for judging new models the same way each time.
  • Pros: Gemini 3.8 Flash is fast and implemented all the requested features.
  • Cons: it made a UI mistake on the modal background, which he says frontier models shouldn't make anymore.
  • Verdict: worth trying; keep testing on real work before switching.
