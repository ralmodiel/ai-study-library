OpenAI Retires Its Evals Platform and Recommends promptfoo

This note summarises a post by Melvin Vivas on X, posted 6 October 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Melvin Vivas · X post · 2026-10-06 · Open on X

Topics: Evaluation (Evals) & Testing, AI Safety, Security & Guardrails, LLMOps, Deployment & Monitoring · Level: intermediate

Summary

The post says OpenAI is retiring its evals platform and recommends promptfoo as the replacement. promptfoo is an open-source tool for testing prompts, agents and RAG pipelines. It also covers red teaming and vulnerability scanning, and it can compare models such as GPT, Claude, Gemini and DeepSeek.

Key points

  • OpenAI is retiring its evals platform.
  • OpenAI suggests moving to promptfoo instead.
  • promptfoo is open source and tests prompts, agents and RAG pipelines.
  • It also does red teaming, pentesting and vulnerability scanning for AI apps.
  • It compares results across GPT, Claude, Gemini, DeepSeek and other models.
  • Tests are written as simple declarative configs, so they fit into regression testing.

Try this

  • If you use OpenAI's evals platform, move your evals to promptfoo.
  • Set up a promptfoo test suite that compares GPT, Claude and Gemini on your own prompts or RAG pipeline.
