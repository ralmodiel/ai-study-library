Summary

Code Arena added a fullstack benchmark that ranks AI models on full-stack web development tasks: multi-step reasoning, tool use and building complete apps. Kimi K3 (Max) took first place, ahead of GPT 5.6 Sol (xHigh) and Claude Fable 5.

Key points

  • Code Arena now measures fullstack capability: multi-step reasoning, tool use and end-to-end app generation.
  • #1 Kimi K3 (Max), #2 GPT 5.6 Sol (xHigh), #3 Claude Fable 5.
  • Use task-specific leaderboards like this when choosing a model for coding agents.
