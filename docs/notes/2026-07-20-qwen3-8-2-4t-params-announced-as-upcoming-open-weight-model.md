# Qwen3.8 (2.4T params) Announced as Upcoming Open-Weight Model

Melvin Vivas · X post · 2026-07-20 · [Open on X](https://x.com/melvindvivas/status/2079123662779875743)

**Topics:** Industry Trends & Job Market, LLM Fundamentals · **Level:** beginner

## Summary

Melvin Vivas reacts to Qwen announcing Qwen3.8. The quoted post says it has 2.4T parameters and will soon be released with open weights. Qwen says it is close to frontier models and second only to Fable 5. These are the vendor's own claims, so treat them as unverified.

## Key points

- Qwen3.8 is said to have about 2.4 trillion parameters.
- Qwen says the model will become open-weight soon.
- Qwen calls it second only to Fable 5 among current models.
- The creator reads this as Chinese open models closing the gap with frontier models.
