# Running Parallel Agents With Different Models in Cursor Mobile

Melvin Vivas · X post · 2026-07-19 · [Open on X](https://x.com/melvindvivas/status/2078688456251998567)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

The creator starts several coding agents from the Cursor mobile app, each on a different model (Fable 5, GPT 5.6 Sol and Grok 4.5). The idea is to send the same work to several models at once and compare the results, even from a phone.

## Key points

- Cursor mobile can start background/cloud agents away from your desk
- You can pick a different model for each agent
- Running the same task on several models lets you compare their output
- Models used: Fable 5, GPT 5.6 Sol, Grok 4.5
