## Summary

Melvin Vivas released Agent Monitor on GitHub. It is a dashboard of the main Codex agent and its subagents that shows token usage and estimated cost. It is still in development but already usable, and it also supports Claude Code subagents.

## Key points

- Shows a dashboard of the main Codex agent and its subagents.
- Displays token usage and estimated cost.
- The repo says it also visualizes Claude Code subagents and has an advanced traces view.
- Still in development, but you can already use it.
