# Codex Astra/Luna Orchestrator: Reasoning Defaults for Pro vs Plus

Melvin Vivas · X post · 2026-09-10 · [Open on X](https://x.com/melvindvivas/status/2097894853652930923)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Melvin Vivas updated the reasoning defaults in his open-source Codex orchestrator config (Astra/Luna) to match his Pro setup. For Plus users, everything defaults to the conservative Luna model, because using Astra at low reasoning as the orchestrator burned Plus limits fast. With Plus limits this low, he suggests skipping orchestration and working task by task with small, contained changes.

## Key points

- The repo provides an orchestrator/subagent setup for Codex using the Astra, Luna and Sol models.
- Pro defaults were updated to match the creator's current setup.
- Plus defaults are all Luna, which is conservative, because Astra-low orchestration burned Plus limits fast.
- Plus users can switch the orchestrator to Astra or Sol and report which reasoning levels work.
- On Plus, consider skipping orchestration and working per task with small, contained changes.
- Fork the repo and customize the defaults to suit your plan.
