# Codex setup: Astra orchestrator with Luna subagents

Melvin Vivas · X post · 2026-09-09 · [Open on X](https://x.com/melvindvivas/status/2097660477841224144)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator shares a GitHub repo that sets up Codex so a large model (Astra or Sol) orchestrates and smaller Luna models run as subagents. He invites people to fork it and share their own setups.

## Key points

- Pattern: a strong model (Astra or Sol) plans and coordinates.
- Narrower tasks go to cheaper Luna subagents.
- This lowers cost and helps you stay under usage limits.
- The repo is meant to be forked and adapted to your own setup.
