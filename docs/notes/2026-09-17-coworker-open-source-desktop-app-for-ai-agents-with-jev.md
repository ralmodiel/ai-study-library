# Coworker: Open-Source Desktop App for AI Agents, with Jev

Melvin Vivas · X post · 2026-09-17 · [Open on X](https://x.com/melvindvivas/status/2100609316927742074)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator links his open-source Coworker app, a desktop app where AI agents do work for you using local or cloud models. He says TypeSafe AI's Jev would be a good fit for it.

## Key points

- Coworker is an open-source desktop app where AI agents do tasks for the user.
- It supports both local and cloud models.
- The creator plans to add Jev by TypeSafe AI to Coworker.
