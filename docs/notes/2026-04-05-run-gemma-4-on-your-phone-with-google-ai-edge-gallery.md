## Summary

Shows that you can run Google's open Gemma 4 model directly on an iPhone or Android phone using the Google AI Edge Gallery app. This lets you run AI locally on the device, with no cloud.

## Key points

- Gemma 4 can run on iPhone and Android phones.
- Download the Google AI Edge Gallery app to try it.
- Running the model on the phone means no cloud calls, so your data stays private and it can work offline.
