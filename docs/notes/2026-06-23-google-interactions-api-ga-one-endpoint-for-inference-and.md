# Google Interactions API GA: one endpoint for inference and agents

Melvin Vivas · X post · 2026-06-23 · [Open on X](https://x.com/melvindvivas/status/2069112372078555213)

**Topics:** LLM Fundamentals, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

Google's Interactions API is now generally available. It has a stable schema and a single /interactions endpoint, and it is now Google's standard interface for both model inference and autonomous agents. New features include Managed Agents, which run in a secure remote Linux environment.

## Key points

- The Interactions API is GA with a stable schema.
- One /interactions endpoint handles both model inference and autonomous agents.
- Managed Agents can spin up a secure, remote Linux environment.
