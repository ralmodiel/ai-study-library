## Summary

Hermes Desktop from Nous Research now has a built-in browser. The Hermes agent can control it and is aware of what it shows. Browser control lets the agent work on the web inside the app.

## Key points

- Hermes Desktop now includes an in-app browser.
- The Hermes agent can control the browser and is aware of its content.
- Hermes is made by Nous Research.
- Browser use is an important tool capability for desktop agents.
