# Instant Docs for Any GitHub Repo with Devin DeepWiki

Melvin Vivas · X post · 2026-06-22 · [Open on X](https://x.com/melvindvivas/status/2068945208302309833)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

DeepWiki from Devin (Cognition) creates documentation for any public GitHub repo. Replace github.com with deepwiki.com in a repo's address (deepwiki.com/owner/repo). It works on your own repos and is a fast way to understand other people's code.

## Key points

- DeepWiki creates documentation automatically for GitHub repositories.
- URL pattern: https://deepwiki.com/owner/repo.
- It works with any GitHub repo, including your own and other people's.
- Useful for getting to know a new codebase quickly or documenting your own project.
