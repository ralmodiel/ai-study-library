Melvin Vivas reshares Cursor's announcement of /orchestrate, a skill that keeps spawning sub-agents to break up and work through large, ambitious tasks. It's built on the Cursor SDK. Cursor says it used the skill internally to auto-research its own skills, cutting token use by 20% while scoring better on evals, and to cut backend cold-start times by 80%. ## Key points

- /orchestrate is a Cursor skill that keeps spawning sub-agents to split up and handle large tasks (a multi-agent, orchestrator-worker pattern).
- It is built on the Cursor SDK, which lets you control Cursor's agents from code.
- Cursor reports using it to auto-research and improve its internal skills: 20% fewer tokens with better eval scores.
- Cursor also reports using it to cut cold-start times on its internal backend by 80%.
- Lesson: automated agent research works best when it is tied to evals. Measure quality alongside token cost so the improvements are real.
- The post has no tutorial or narration. Check Cursor's official docs to see how to use it.
