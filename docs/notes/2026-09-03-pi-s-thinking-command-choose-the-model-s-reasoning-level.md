# Pi's /thinking Command: Choose the Model's Reasoning Level

Melvin Vivas · X video post · 2026-09-03 · [Open on X](https://x.com/melvindvivas/status/2095211505461682411)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The Pi coding agent now has a thinking level selector. You open it with the /thinking slash command and can save a default or change the level during a session.

## Key points

- Run /thinking in Pi to choose a thinking level.
- Pick a level and press Ctrl+S to make it your startup default.
- Press Shift+Tab to cycle through levels during a session.
