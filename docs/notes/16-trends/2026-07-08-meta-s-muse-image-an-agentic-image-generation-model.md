## Summary

Quotes Meta's announcement of Muse Image, the first image generation model from Meta Superintelligence Labs (MSL). It is agentic: it works with Muse Spark to reason through the prompt, search the web and plan before generating, so users get what they meant on the first try. It is live in the Meta AI app.

## Key points

- Muse Image is MSL's first image generation model.
- It is agentic: it pairs with Muse Spark to reason, search the web and plan before generating.
- The goal is to get the intended image on the first try.
- Available now in the Meta AI app.
- Trend: image generators are adding reasoning and tool-use (agent) steps before generating.
