## Summary

The post says Cursor's Composer 2 coding model uses Moonshot's open-source Kimi K2.5 as its base model. It shows that commercial coding tools are building on open-weight models.

## Key points

- Cursor Composer 2 is built on top of Kimi K2.5.
- Kimi K2.5 is an open-source model from Moonshot AI.
- Open-weight base models are now strong enough to power commercial coding agents.
