Summary

This is a short news post. Melvin Vivas points out that another image model has been released: FLUX 3 Image Klein from Black Forest Labs. He quotes an announcement saying ComfyUI now supports it natively. The post lists the model's size, says the weights are open, and names its main features. It has no tutorial content.

Key points

  • FLUX 3 Image Klein is an image model from Black Forest Labs (@bfl_ai).
  • It has 5.6B parameters.
  • Open weights are available for both a base version and a distilled version.
  • ComfyUI now supports it natively.
  • Listed features: native 4K generation, bounding boxes for layout control, multi-reference generation, pixel-perfect editing and text rendering.
  • The creator sees it as one of many recent image model releases.
