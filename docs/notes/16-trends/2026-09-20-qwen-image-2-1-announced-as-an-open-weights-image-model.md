# Qwen-Image-2.1 Announced as an Open-Weights Image Model

Melvin Vivas · X post · 2026-09-20 · [Open on X](https://x.com/melvindvivas/status/2101515595275731298)

**Topics:** Industry Trends & Job Market, LLM Fundamentals · **Level:** beginner

## Summary

The post shares news that Qwen will open-source Qwen-Image-2.1 on ModelScope, releasing both the weights and the code. Learners can download it, run it themselves and build on it.

## Key points

- Qwen-Image-2.1 is an image-generation model from the Qwen team.
- The release includes both the model weights and the code.
- It will be hosted on ModelScope under the Qwen organization.
