OpenRouter serves image models, including FLUX 3 Image Klein

Summary

A reminder that OpenRouter serves image and video models as well as LLMs. The quoted post lists new Black Forest Labs releases on OpenRouter: FLUX 3 Image Klein, a cheaper FLUX Video Upscale, and 4K text-to-video with FLUX 3 Video.

Key points

  • OpenRouter serves image models, not just text LLMs
  • FLUX 3 Image Klein is an open-weights image model that runs on one consumer GPU
  • An improved FLUX Video Upscale (early access) turns any video into 4K for $0.28/s, down from $0.59/s
  • FLUX 3 Video can now generate 4K videos from a prompt
  • All of these come from Black Forest Labs (@bfl_ai)
