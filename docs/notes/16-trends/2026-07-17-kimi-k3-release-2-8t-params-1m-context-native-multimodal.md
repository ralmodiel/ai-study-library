# Kimi K3 release: 2.8T params, 1M context, native multimodal

Melvin Vivas · X post · 2026-07-17 · [Open on X](https://x.com/melvindvivas/status/2077846413330034947)

**Topics:** Industry Trends & Job Market, LLM Fundamentals · **Level:** intermediate

## Summary

Announces that Moonshot's Kimi K3 model has been released and lists its reported specs. It's useful as a trend snapshot of frontier open-weight model scale and new attention variants. The creator also asks where people can access it.

## Key points

- Kimi K3 reportedly has more than 2.8 trillion parameters.
- It has a 1 million token context window.
- It is natively multimodal.
- It uses architecture changes called Kimi Delta Attention and Attention Residual.
- Access options were still unclear when it was posted.
