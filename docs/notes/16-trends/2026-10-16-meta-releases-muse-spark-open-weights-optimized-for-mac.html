Summary

Melvin welcomes Meta releasing Muse Spark Open as an open model. The quoted post says the weights are out and the model runs well on new Mac Studios, thanks to work with Apple. That means a frontier-scale open model can run on high-end local hardware.

Key points

  • Meta released the Muse Spark Open weights openly.
  • The model is optimized to run on new Apple Mac Studios through a collaboration with Apple.
  • Open weights let you run and customize the model locally instead of only through an API.
