# Claude Plans Get Monthly Credit for Agent SDK and claude -p

Melvin Vivas · X post · 2026-05-14 · [Open on X](https://x.com/melvindvivas/status/2054641607899840956)

**Topics:** Industry Trends & Job Market, AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The quoted announcement says that from June 15, paid Claude plans can claim a dedicated monthly credit for programmatic usage. The credit covers the Agent SDK, claude -p, Claude Code GitHub Actions and third-party apps built on the Agent SDK. The creator's comment, 'the end of claude agent sdk', suggests he sees this as a limit on that use.

## Key points

- Starts June 15: paid Claude plans can claim a dedicated monthly credit for programmatic usage.
- The credit covers the Claude Agent SDK.
- It also covers headless claude -p usage.
- It also covers Claude Code GitHub Actions.
- It also covers third-party apps built on the Agent SDK.
- The creator reads the change as bad news for the Agent SDK ('the end of claude agent sdk').
