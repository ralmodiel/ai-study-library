Summary

The creator compared the newly released Grok 4.5 with Fable on the same tasks and found the outputs comparable. He calls it 'Opus level'. The quoted announcement says Grok 4.5 was trained in partnership with SpaceXAI and is the first model they built for more than software engineering.

Key points

  • Grok 4.5 was released and the creator rates it as 'Opus level' for coding.
  • Side-by-side test against Fable gave comparable output.
  • He plans to use it in Cursor for complex projects.
  • The quoted announcement says it was trained with SpaceXAI and built for more than software engineering.
