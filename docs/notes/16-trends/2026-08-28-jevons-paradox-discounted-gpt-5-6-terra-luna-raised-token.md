# Jevons Paradox: Discounted GPT 5.6 Terra/Luna Raised Token Use 13.8x

Melvin Vivas · X post · 2026-08-28 · [Open on X](https://x.com/melvindvivas/status/2093351769351074249)

**Topics:** Industry Trends & Job Market, LLM Fundamentals, LLMOps, Deployment & Monitoring · **Level:** beginner

## Summary

When OpenRouter heavily discounted GPT 5.6 Terra and Luna, token usage went up 13.8x. The post uses this to explain Jevons Paradox: making a resource cheaper or more efficient raises total use of it. The creator adds that users clearly preferred Luna over Terra.

## Key points

- GPT 5.6 Terra and Luna were heavily discounted on OpenRouter.
- Token usage went up 13.8x after the discount.
- Jevons Paradox: when using a resource gets more efficient, total use goes up, not down.
- Users preferred Luna over Terra.
- Lesson for cost planning: cheaper tokens tend to mean more usage, so total spend may not drop.
