Summary

Shares the GLM-5.1 launch announcement. The quoted post says it ranks #1 among open-source models and #3 overall on SWE-Bench Pro, Terminal-Bench and NL2Repo. It is built for long tasks and can run on its own for 8 hours, improving its approach over thousands of iterations.

Key points

  • GLM-5.1 is described as 'the next level of open source'.
  • It ranks #1 among open-source models and #3 overall on SWE-Bench Pro, Terminal-Bench and NL2Repo.
  • It is built for long tasks and can run on its own for about 8 hours.
  • It improves its approach over thousands of iterations, which makes it a good fit for agent workflows.
