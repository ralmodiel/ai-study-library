# Cloud Coding Agents: Moving Code Agents Off the Laptop

Melvin Vivas · X post · 2026-06-28 · [Open on X](https://x.com/melvindvivas/status/2071145200945377323)

**Topics:** Industry Trends & Job Market, AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

A short opinion post. It quotes a prediction that most developers will move their coding agents from laptops to the cloud in about 6 months, and the creator says Cursor and Devin's cloud agents are nearly ready for that. It is a signal about where AI coding tools are heading, not a tutorial.

## Key points

- Quoted prediction: about 6 months until most devs run their code agents in the cloud instead of on their laptops.
- The creator thinks Cursor and Devin's cloud offerings are 'almost there'.
- Trend to watch: coding agents running as cloud workloads, not local IDE sessions.
