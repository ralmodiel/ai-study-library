Summary

The creator highlights Muse Voice Transcribe from Meta Superintelligence Labs, a real-time audio model. It does streaming speech recognition, speaker diarization for 20+ speakers, and endpointing, and handles multiple languages, including switching languages mid-sentence.

Key points

  • Real-time streaming speech-to-text (ASR)
  • Tells apart 20+ speakers (diarization)
  • Endpointing: detects when a speaker has finished
  • Handles multiple languages, including switching mid-sentence (code-switching)
  • Meta Superintelligence Labs' first real-time audio perception model
