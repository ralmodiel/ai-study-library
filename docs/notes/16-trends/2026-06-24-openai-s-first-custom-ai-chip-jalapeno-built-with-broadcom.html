OpenAI's first custom AI chip: Jalapeño, built with Broadcom

Summary

Quotes OpenAI's announcement of Jalapeño, its first in-house AI chip, built for LLM workloads and taken to production with Broadcom. The creator jokes that it distracts from GPT 5.6. It's a sign that AI labs are moving into custom hardware.

Key points

  • OpenAI designed Jalapeño itself and took it to production with Broadcom.
  • It is built for the LLM workloads behind ChatGPT, Codex, the API and future agent products.
  • Trend: frontier AI labs are building their own chips instead of relying only on general-purpose GPUs.
