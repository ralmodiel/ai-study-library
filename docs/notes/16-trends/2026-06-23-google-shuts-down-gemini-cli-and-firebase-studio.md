## Summary

The creator reports that Google recently shut down two developer projects: Gemini CLI and Firebase Studio. It is a reminder that AI dev tools can be discontinued, so learners should not lock themselves into a single tool.

## Key points

- According to the creator, Google discontinued Gemini CLI.
- According to the creator, Google discontinued Firebase Studio.
- AI developer tools change fast, so check that a tool is still active before you build on it.
