Summary

Z.ai has introduced GLM-Legal, a legal-domain model built on GLM-5.3-Flash. Z.ai says it matches frontier models on mainstream legal benchmarks. It is designed for real legal work such as contract review, evidence analysis and compliance. There is a tech blog, and API access is by application.

Key points

  • GLM-Legal is built on GLM-5.3-Flash, a smaller and faster base model.
  • Z.ai claims it matches frontier models on mainstream legal benchmarks.
  • Target uses: contract review, evidence analysis and compliance.
  • API access is by application.
  • This is another example of domain-specialized models built on top of a smaller base model.
