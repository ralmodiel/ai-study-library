OpenAI DevDay recap: Dots, GPT-6.1 Sol, Codex Cloud, Agents API

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Melvin Vivas · X post · 2026-09-30 · Open on X

Topics: Industry Trends & Job Market, AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · Level: beginner

Summary

A full list of OpenAI DevDay launches: Dots agents powered by Astra, Codex Spaces, Codex Cloud and Codex Security Cloud, GPT-6.1 Sol, Ultrafast inference, new Pro plans, the Decisions API and Agents API, Sign in with ChatGPT, Plugin Extensions, OpenAI Marketplace and a banked usage reset. Use it as a map of what's new on OpenAI's agent and developer platform.

Key points

  • Dots: agent teammates powered by the Astra model, compared to xAI's Grok Bot
  • Codex Spaces is where you work with Dots. Codex Cloud runs tasks remotely, so you can close your laptop
  • GPT-6.1 Sol: about 1/5 the price of Astra with near-Astra intelligence
  • Ultrafast mode: 300 tokens/s, 8x faster on Astra
  • Plans: Pro 500 gives 25x Plus usage, and Pro 200 is back
  • New developer APIs: Decisions API and Agents API, plus Codex Security Cloud
  • Sign in with ChatGPT lets you use ChatGPT credits in third-party tools (Devin, Hermes, T3Code)
  • Also launched: Plugin Extensions, OpenAI Marketplace and a banked Codex usage reset
