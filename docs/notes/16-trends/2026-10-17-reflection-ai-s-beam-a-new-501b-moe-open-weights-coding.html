Reflection AI's Beam: a new 501B MoE open-weights coding model

Summary

The creator points to Beam, an agentic open model from Reflection AI. It is a mixture-of-experts model with 501B total parameters, of which 23B are active. Reflection says it was trained end-to-end from scratch, is very efficient at reasoning, and pushes the Western open-model frontier on coding and agentic tasks. The full weights are due to be released this month.

Key points

  • Beam is an open-weights model built for coding and agentic tasks
  • It has 501B total parameters but only 23B active per token, a mixture-of-experts design
  • Reflection says it was trained end-to-end from scratch
  • It's pitched as highly efficient at reasoning
  • Reflection claims it advances the Western open frontier on coding and agentic benchmarks
  • The full weights are promised for release this month
