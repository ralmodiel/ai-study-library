# GLiDE: Fastino's Decision Model with Adaptive Thinking

Melvin Vivas · X post · 2026-10-02 · [Open on X](https://x.com/melvindvivas/status/2105893635925680604)

**Topics:** Industry Trends & Job Market, LLM Fundamentals · **Level:** intermediate

## Summary

Fastino Labs released GLiDE, which it calls the first decision model that thinks. It ranks #1 on the Decision Index, 6.9 points ahead of the runner-up. GLiDE uses adaptive thinking: it first computes a fast probability distribution over answers and only reasons further when the top answer is uncertain.

## Key points

- GLiDE is a decision model from Fastino Labs.
- It ranks #1 on the Decision Index, 6.9 points ahead of the next model.
- Adaptive thinking: it first computes a fast probability distribution over possible answers.
- It switches to reasoning only when the leading answer is uncertain, which saves compute on easy decisions.
