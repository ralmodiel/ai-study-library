Summary

The creator shares numbers on how fast open-source AI is growing: 5.6 million AI projects on GitHub and Hugging Face uploads tripling since 2023. U.S.-based projects still get the most engagement. The original source isn't linked.

Key points

  • 5.6 million open-source AI projects on GitHub.
  • Hugging Face uploads have tripled since 2023.
  • U.S.-based projects get the most engagement: 30 million total GitHub stars across projects with more than 10 stars.
  • The post names no source, so treat the numbers with care.
