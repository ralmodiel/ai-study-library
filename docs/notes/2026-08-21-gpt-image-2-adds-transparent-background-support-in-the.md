# GPT Image 2 Adds Transparent Background Support in the OpenAI API

Melvin Vivas · X video post · 2026-08-21 · 0:28 · 320 views · [Open on X](https://x.com/melvindvivas/status/2090712735600562200)

**Topics:** LLM Fundamentals, Industry Trends & Job Market · **Level:** beginner

## Summary

This is a short announcement. OpenAI's GPT Image 2 model can now generate images with transparent backgrounds through the API, currently in preview. That means generated images can be placed on any background as reusable assets, for example product images, graphic design, website mockups, marketing material, stickers and game sprites. Semi-transparent results, such as a ghost, are also supported.

## Key points

- Transparent backgrounds are now available in preview for GPT Image 2 in the OpenAI API.
- Before this, transparency was the most-requested missing feature. Without it, use cases like sticker mockups were 'impossible'.
- Transparent outputs are reusable assets you can place on any background.
- Suggested uses: product imagery, graphic design, website mockups, marketing campaigns and web design.
- Semi-transparent images are supported too, such as a see-through ghost.
- It lets apps have users generate their own sprites in a game.
