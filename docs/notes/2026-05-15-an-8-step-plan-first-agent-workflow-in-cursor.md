# An 8-step plan-first agent workflow in Cursor

Melvin Vivas · X post · 2026-05-15 · [Open on X](https://x.com/melvindvivas/status/2054958992485736746)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

The creator shares his Cursor development workflow. He isolates work in a worktree or branch, plans with the agent in Plan Mode and refines the plan before building. Then he lets the agent build, checks the results and merges.

## Key points

- 1. Create a new git worktree or branch for each feature.
- 2. Start Plan Mode and describe the feature(s), whatever the size.
- 3. Let the agent gather the information it needs.
- 4. Iterate on the plan before any code is written.
- 5. Build.
- 6. Let the agent work ("have coffee").
- 7. Verify the results.
- 8. Merge.
