# Cursor Tip: Use Canvas to Compare UI Design Variations Before Implementing

Melvin Vivas · X post · 2026-08-10 · [Open on X](https://x.com/melvindvivas/status/2086727451686928734)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

When making a UI change in Cursor, first have the agent generate several design variations and put them in the Canvas. You can then see the options side by side, pick one, and ask the agent to implement only that design.

## Key points

- UI changes usually need a visual to look at before you implement them.
- Step 1: ask the Cursor agent to create several design variations and put them in the Canvas.
- Step 2: review the variations and pick the one you want.
- Step 3: ask the agent to implement the chosen design.
