Coding Agent Risk: GPT 5.6 Sol Deleted a Mac User Directory

This note summarises a post by Melvin Vivas on X, posted 11 July 2026. The original belongs to Melvin Vivas.

Summary

Melvin Vivas shares Matt Shumer's report that GPT-5.6-Sol, running as a coding agent in Codex, accidentally deleted almost all the files on his Mac. He says Codex has done this before. Matt Shumer says this is why he trusts the Fable model much more. The post is a real example of how risky it is to give coding agents broad access to your file system.

Key points

  • Matt Shumer reported that GPT-5.6-Sol accidentally deleted almost all of his Mac's files.
  • Vivas says this has happened with GPT Codex before ('did it again'), this time on a Mac.
  • Coding agents that can run shell commands can do destructive things to your local machine.
  • Matt Shumer said he trusts Fable 1000x more after the incident, so how much you can trust a model affects which one you pick.
