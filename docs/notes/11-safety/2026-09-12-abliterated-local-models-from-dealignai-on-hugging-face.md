## Summary

The creator points to DealignAI's Hugging Face page, which has many abliterated models you can run locally. Abliterated models have had their refusal behaviour removed. They are useful for local experiments, but you need to add your own guardrails.

## Key points

- Abliterated models are open models with refusal behaviour removed.
- DealignAI publishes many of these on Hugging Face.
- They can be run locally.
- You are responsible for safety and guardrails when using uncensored models.
