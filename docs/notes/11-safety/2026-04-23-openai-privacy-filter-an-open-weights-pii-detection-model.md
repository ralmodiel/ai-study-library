# OpenAI Privacy Filter: An Open-Weights PII Detection Model

Melvin Vivas · X post · 2026-04-23 · [Open on X](https://x.com/melvindvivas/status/2046985434522390539)

**Topics:** AI Safety, Security & Guardrails · **Level:** beginner

## Summary

OpenAI released Privacy Filter, an open-weights model for detecting personally identifiable information (PII). It has 1.5B total parameters with 50M active and is available on Hugging Face.

## Key points

- Privacy Filter is OpenAI's open-weights model for detecting PII.
- It has 1.5B total parameters but only 50M active (a sparse design).
- It is available on Hugging Face.
