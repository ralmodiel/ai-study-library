# Turn off Grok Build's default data sharing with /privacy

Melvin Vivas · X post · 2026-07-14 · [Open on X](https://x.com/melvindvivas/status/2076727820454330742)

**Topics:** AI Safety, Security & Guardrails, AI Dev Tools & Productivity · **Level:** beginner

## Summary

A quick warning that Grok Build shares your data by default. The fix is to turn it off with the `/privacy` command in the CLI.

## Key points

- Grok Build shares user data by default.
- Turn sharing off with the `/privacy` command.
- Check privacy settings on coding agents before using them on sensitive code.
