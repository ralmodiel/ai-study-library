A short reel listing six AI-related career paths open to software engineers and the main focus of each: AI Engineer, Forward Deployed Engineer, AI Solutions Engineer, Machine Learning Engineer, AI Platform Engineer and AI Security Engineer. It ends by promoting the creator's Skool community (BASWE.Ai Engineer), which offers project, resume and interview help aimed at $100k–$200k+ AI roles.

## Key points

- AI Engineer: builds AI applications with LLMs, RAG, agents and evaluation pipelines.
- Forward Deployed Engineer: works directly with customers to build and deploy solutions to their problems.
- AI Solutions Engineer: helps customers pick the right AI solution through discovery, architecture, demos and prototypes.
- Machine Learning Engineer: prepares data, trains models, evaluates performance and deploys models to production.
- AI Platform Engineer: builds the infrastructure that runs AI systems, such as model serving, cloud platforms and monitoring.
- AI Security Engineer: secures AI applications against prompt injection, data exposure and unsafe agent behavior.
- Each path needs a different skill set, so choose one and learn the skills for that path.
