**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator uses Codex for small non-coding chores, such as reducing a photo's file size for his YouTube channel. He finds this easier than doing it in Canva.

## Key points

- Coding agents can do small file-manipulation jobs like resizing or compressing images.
- Asking the agent can be faster than opening a design tool such as Canva.
- The agent can write and run the script for you, so you don't have to.
