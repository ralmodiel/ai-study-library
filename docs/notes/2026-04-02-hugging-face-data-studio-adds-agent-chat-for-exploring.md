## Summary

Hugging Face's Data Studio now has an Agent chat feature. You can explore and query datasets by chatting with it, and the creator finds it very useful.

## Key points

- Hugging Face Data Studio now includes an Agent chat.
- Use it to explore datasets in natural language before training or fine-tuning.
