**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity, Prompt & Context Engineering · **Level:** intermediate

## Summary

Hugging Face Spaces now include an AGENTS.md file. It gives coding agents instructions and context for working with each Space.

## Key points

- Every Hugging Face Space now has an AGENTS.md file.
- AGENTS.md is a markdown file that gives coding agents project context and instructions.
- This makes it easier for coding agents to understand and change Spaces.
