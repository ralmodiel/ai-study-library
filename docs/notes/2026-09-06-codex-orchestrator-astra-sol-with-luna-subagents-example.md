# Codex orchestrator (Astra/Sol) with Luna subagents: example repo

Melvin Vivas · X post · 2026-09-06 · [Open on X](https://x.com/melvindvivas/status/2096271014607061307)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator shares a repo that sets up Codex with Astra or Sol as the orchestrator and Luna models as subagents. This is a common multi-agent pattern: a strong model plans and hands off work, and cheaper models do it. The setup is still being tested.

## Key points

- Orchestrator: GPT-6 Astra (or Sol) plans and hands work to subagents.
- Subagents: Luna models do the delegated tasks.
- The setup is set up for Codex and published as an open repo.
- The creator says it is still being tested, so expect it to change.
