# GPU devbox Docker image with coding agents on Runpod

Melvin Vivas · X post · 2026-09-03 · [Open on X](https://x.com/melvindvivas/status/2095503029437190181)

**Topics:** AI Dev Tools & Productivity, LLMOps, Deployment & Monitoring, Fine-tuning & Model Customization · **Level:** intermediate

## Summary

Melvin Vivas shares a GPU-ready Docker 'devbox' image for ML work that he runs on Runpod. It is based on the official Runpod PyTorch 2.8 + CUDA 12.8 template and comes with coding agents (Codex, Claude Code, Pi, Grok, Cursor, Herdr) and tools such as the Hugging Face CLI and nvtop. With it you can use agentic coding tools directly on a rented GPU.

## Key points

- Base image: the official Runpod PyTorch 2.8 + CUDA 12.8 template.
- Pre-installed coding agents: Codex, Claude Code, Pi (@pidotdev), Grok, Cursor and Herdr (@herdrdev).
- Also includes the Hugging Face CLI for models and datasets, and nvtop for GPU monitoring.
- Lets you run Codex and other coding agents for ML work inside a GPU cloud pod.
- The creator built it for his own use and shared it publicly.
- The excerpt doesn't include the image link. It is in the quoted post.
