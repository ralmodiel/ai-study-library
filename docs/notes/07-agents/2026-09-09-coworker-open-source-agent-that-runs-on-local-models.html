Coworker: open-source agent that runs on local models

This note summarises a post by Melvin Vivas on X, posted 9 September 2026. The original belongs to Melvin Vivas.

Topics: AI Agents, Tool Use & MCP, Portfolio Projects · Level: intermediate

Summary

The creator shares Coworker, his open-source personal agent project. It can run on local models through Ollama or LM Studio, and he recently added pairing with a Telegram bot. He invites people to fork it on GitHub and customize it.

Key points

  • Coworker can run on local models served by Ollama or LM Studio.
  • It has a new feature to pair it with a Telegram bot.
  • It's a solo side project with no funding, mainly for the creator's own use.
  • You can fork the GitHub repo and customize it.
