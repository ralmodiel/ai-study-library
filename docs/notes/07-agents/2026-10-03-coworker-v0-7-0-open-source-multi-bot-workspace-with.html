Coworker v0.7.0: Open-Source Multi-Bot Workspace with Primary Bot and Web Search

Summary

Melvin Vivas announces version 0.7.0 of Coworker, his open-source workspace for running several AI bots at once. This release adds a pinnable Primary bot that you can use to tag your other bots, plus free web search through Firecrawl and a redesigned dashboard that shows every bot's messages on one timeline. Coworker works with any open model through OpenRouter or with local models, and he recommends GPT-6 Luna on OpenRouter as a cheap model that performs well.

Key points

  • Coworker is an open-source multi-bot workspace. Its dashboard gives you an overview of everything your bots are doing, which the creator says rival bots (Dots, Grok Bot) don't offer.
  • You can now create a Primary bot, pin it, and tag your other bots from it, so one main agent hands work to the others.
  • Free web search is built in through Firecrawl.
  • The workspace dashboard was redesigned to show bot messages on a single timeline.
  • It works with any open model through OpenRouter, or with local models.
  • The model library was upgraded to pi-ai v1.0 (from @pidotdev).
  • Recommended model: GPT-6 Luna on OpenRouter, at about $0.10 per 1M input tokens and $0.50 per 1M output tokens.
