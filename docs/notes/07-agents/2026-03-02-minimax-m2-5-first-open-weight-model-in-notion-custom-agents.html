MiniMax M2.5: first open-weight model in Notion Custom Agents

Summary

MiniMax M2.5 is now available inside Notion Custom Agents, the first open-weight model offered there. It is tuned for lightweight agent workflows that run often. The creator sees this as a sign that open-weight models are entering products where scale and cost matter most.

Key points

  • MiniMax M2.5 is the first open-weight model supported in Notion Custom Agents.
  • It is optimized for lightweight agent workflows that run often.
  • Open-weight models are being adopted where scale and per-call cost matter most.
  • Model choice for agents is a cost/frequency trade-off: cheaper models suit high-volume, simple agent tasks.
