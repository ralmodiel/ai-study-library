Summary

The creator points OpenClaw users to Hannes Rudolph, OpenClaw's new Community Manager. Hannes's quoted post admits that OpenClaw has had stability problems. Useful only if you use OpenClaw and need support.

Key points

  • OpenClaw has publicly acknowledged stability problems ('We've broken your claws').
  • Hannes Rudolph is the new OpenClaw Community Manager and a contact for OpenClaw issues.
  • The official @OpenClaw account on X is where updates are posted.
