Summary

Coworker, the creator's open-source desktop AI assistant, supports reminders and scheduled jobs. It works with any model you choose, local or cloud, including Grok 4.7. It can also search the web, create files and use memory.

Key points

  • Coworker supports reminders and scheduled jobs.
  • It works with any model, local or cloud (for example Grok 4.7).
  • Other features: web search, file creation and memory.
  • It is open source on GitHub (donvito/coworker).
