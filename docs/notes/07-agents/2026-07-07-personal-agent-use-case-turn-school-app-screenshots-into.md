# Personal Agent Use Case: Turn School-App Screenshots into Calendar Events

Melvin Vivas · X post · 2026-07-07 · [Open on X](https://x.com/melvindvivas/status/2074371308557656365)

**Topics:** AI Agents, Tool Use & MCP, Portfolio Projects · **Level:** beginner

## Summary

The creator sends a screenshot of a school-app message to his Hermes agent. The agent reads the event details and adds the event, with a reminder, to the family calendar. This replaces copying and pasting the details by hand.

## Key points

- Workflow: screenshot message → send to agent → agent extracts the event → creates a calendar entry with a reminder.
- Multimodal (image) input removes the need to copy and paste text.
- Connecting the agent to a calendar tool turns a chat request into a real action.
- Small household automations like this are an easy way to show non-technical people what agents can do.
