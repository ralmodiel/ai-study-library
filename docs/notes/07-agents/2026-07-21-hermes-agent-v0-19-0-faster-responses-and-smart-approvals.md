# Hermes Agent v0.19.0: faster responses and smart approvals

Melvin Vivas · X post · 2026-07-21 · [Open on X](https://x.com/melvindvivas/status/2079297197884178605)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Shares the release notes for Hermes Agent v0.19.0. The update makes first responses much faster on every interface, speeds up the desktop app, streams reasoning live by default and turns on smart approvals by default.

## Key points

- First response is about 80% faster across CLI, desktop, TUI and gateway
- Desktop app: 14x faster markdown rendering, virtualized diffs and quicker session switching
- Reasoning now streams live by default
- Smart approvals (automatic approval of tool actions) is now the default
- New /subscription billing command
