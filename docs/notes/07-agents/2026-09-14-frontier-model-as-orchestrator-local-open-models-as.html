Summary

The creator describes a chat-and-code app he is building with Codex's help. A frontier model acts as the orchestrator and hands work to local or open models running as subagents, which keeps costs down while the strong model handles planning.

Key points

  • Architecture: a frontier model orchestrates and plans, and delegates subtasks to subagents.
  • The subagents run on local or open-weight models to cut cost and API usage.
  • The app supports both chat and coding workflows.
  • The creator is using Codex to build it.
