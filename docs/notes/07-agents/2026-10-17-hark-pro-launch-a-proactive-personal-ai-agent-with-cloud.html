Hark Pro Launch: A Proactive Personal AI Agent with Cloud Computer Use

Summary

Melvin Vivas shares the launch video for Hark Pro and asks whether anyone has tried it. Hark calls itself an "operating system for your life." It connects to your email and other accounts, then does web tasks for you on a cloud virtual computer (a feature called Handoff). It also suggests next steps through proactive cards and lets you build custom mini-app "panels." This is mainly a product ad, but it shows how consumer agent products are being designed around computer use, memory, proactivity and a single chat thread.

Key points

  • Hark Pro is available on web, iOS and Android. It has a free tier and paid plans at $20 or $100 per month.
  • The demo shows 9 tasks from voice commands: reordering on Target, making a presentation, sending receipts to Ramp, LinkedIn outreach, calling an Uber, printing an Amazon return label, ordering on DoorDash, searching Google Drive and canceling a ChatGPT subscription.
  • Handoff is an always-on private virtual computer in the cloud that does web tasks from start to finish. Hark says it is 'independently verified' as the best computer-use model.
  • Onboarding starts by connecting your email, which serves as the main source of personal context. More service connections are suggested after that.
  • The design treats a single chat thread as the core interface, like a messaging app, rather than juggling many agents. A separate Projects tab holds long-running tasks.
  • Proactive cards on a homepage include action buttons the agent creates (for example, confirm an appointment, request late checkout, pay a bill). Dismissing a card is meant to train the system not to show that kind of suggestion again.
  • Panels are custom mini-apps built from a component library, for example a spending tracker, workout log or surf conditions.
  • On privacy, Hark says it never sells your data or uses it for ads, deleted data is really deleted, and logins and cards are stored encrypted on a secure server ('Secured by Hark').
