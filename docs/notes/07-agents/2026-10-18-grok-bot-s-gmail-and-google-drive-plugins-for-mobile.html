Summary

The creator praises Grok Bot's plugin integration with Gmail and Google Drive. After granting extra access, it worked smoothly on his iPhone. He set up an automation while he was out.

Key points

  • Grok Bot has plugin integrations with Gmail and Google Drive.
  • The integrations need extra access permissions before they work.
  • It worked smoothly from an iPhone, so you can set up automations while away from your desk.
  • Example use case: connecting an assistant agent to email and docs for personal automations.
