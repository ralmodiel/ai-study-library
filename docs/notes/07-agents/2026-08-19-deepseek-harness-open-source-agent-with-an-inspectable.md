# DeepSeek harness: open-source agent with an inspectable trajectory view

Melvin Vivas · X post · 2026-08-19 · [Open on X](https://x.com/melvindvivas/status/2089963201198964760)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity, Evaluation (Evals) & Testing · **Level:** advanced

## Summary

The creator highlights the DeepSeek harness, an MIT-licensed open-source agent harness. Everything in it is a plugin, it works with any model, and it has a detailed trajectory view of the event stream. He suggests collecting these traces so a harness can improve itself based on how you use it.

## Key points

- DeepSeek harness is fully open source under the MIT license.
- Everything is a plugin that you can customize on the fly by prompting.
- The trajectory view shows a very detailed event stream, so you can inspect what the agent did.
- It works with any model (GPT, Claude, etc.).
- Idea: collect the traces and use them to make your harness self-improve based on your usage.
