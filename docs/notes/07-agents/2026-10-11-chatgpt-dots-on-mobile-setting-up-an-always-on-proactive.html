ChatGPT Dots on Mobile: Setting Up an Always-On Proactive Agent

Summary

A short OpenAI product demo, quoted and shared by Melvin Vivas. Alex from the Dots for Mobile team shows how to set up a "dot", an always-on proactive agent, from the ChatGPT app on iOS and Android. He personalizes it, connects calendar and email so it has more context, then uses voice to have it start a Codex thread to prototype an iOS widget and find the right Slack colleagues to work with. It's a quick look at how consumer agents use connected context and tools to hand off tasks.

Key points

  • Dots are always-on proactive agents in ChatGPT. Before this update they could only be set up on desktop and web; now they also work on iOS and Android.
  • Setup: open the ChatGPT app and tap 'Meet Dot' in the top-left corner. This opens a thread with your dot, which mostly sets itself up.
  • The dot may ask for calendar and email access. Connecting both is recommended because more context lets the agent take more tasks off your plate.
  • You can personalize a dot with a name and an avatar: a preset, your CodexPet, or a custom avatar.
  • A dot has its own computer and can also access yours, which lets it handle complex tasks like coding and prototyping.
  • In the demo, a voice call asks the dot to prototype an iOS widget (avatar, name, status). It starts a Codex thread to build it.
  • The dot also checks Slack to see who else is working on the widget, offers to open a Slack thread with them, and drafts a reply for the user to approve before sending.
  • The pattern shown: hand off long-running work, let the agent 'cook', and review results such as screenshots later.
