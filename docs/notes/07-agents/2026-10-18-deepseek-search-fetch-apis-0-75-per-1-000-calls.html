DeepSeek Search & Fetch APIs: $0.75 per 1,000 calls

Summary

DeepSeek opened its Search and Fetch APIs to everyone. They run on its in-house search engine and are available as server-side tools. Each endpoint costs $0.75 per 1,000 calls, and the creator asks whether that's cheap, which is useful pricing context for web-grounded agents.

Key points

  • DeepSeek Search & Fetch APIs are now open to everyone.
  • They run on DeepSeek's in-house search engine, which serves hundreds of millions of requests a day.
  • Pricing: $0.75 per 1,000 calls for each endpoint.
  • You can call Search and Fetch as server-side tools in the DeepSeek API.
  • Useful for giving agents or RAG pipelines live web search and page fetching.
