Summary

The creator shares his open-source tool agent-monitor. It visualizes subagents spawned by Codex and Claude Code, with a traces view, token breakdown and cost tracking. It came in reply to his observation that GPT-6 Sol Ultra spawns Ultra-level subagents that use up limits quickly.

Key points

  • Coding agents like GPT-6 Sol Ultra can spawn many subagents at the same high reasoning level, which uses up usage limits fast.
  • agent-monitor visualizes Codex and Claude Code subagents.
  • It offers an advanced traces view, a token breakdown and cost tracking.
  • Watching subagents helps you find where tokens and cost are going.
