Summary

The creator had Grok Bot run 10 local video generations overnight. It used the Minimax H3 model through ComfyUI on his own PC. Each video took about 15 minutes, so he handed the long-running batch to the bot and went to sleep.

Key points

  • Video model used locally: Minimax H3, run through ComfyUI on a personal PC
  • Each video took about 15 minutes, so 10 videos is a roughly 2.5-hour batch
  • Hand slow, repetitive generation jobs to an agent so they run unattended
  • The personal assistant bot (Grok Bot) orchestrated the local ComfyUI workflow
