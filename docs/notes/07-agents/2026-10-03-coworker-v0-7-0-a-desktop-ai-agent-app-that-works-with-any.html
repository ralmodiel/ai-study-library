Coworker v0.7.0: A Desktop AI Agent App That Works With Any Model via OpenRouter

Summary

Melvin Vivas announces version 0.7.0 of Coworker, his own desktop AI agent app. He pitches it as an alternative for people on a Codex Plus plan or without a "Grok Bot" subscription. It can run any model, including open models, through OpenRouter, and he says it is easier to install than Hermes or OpenClaw. The release adds a primary bot, free web search out of the box, and a dashboard that shows everything the agent is doing.

Key points

  • Coworker v0.7.0 is a desktop agent app made by the creator, Melvin Vivas.
  • It is aimed at Codex Plus users and at people without a 'Grok Bot' subscription.
  • It works with any model, including open models, through OpenRouter, which gives one API to many LLM providers.
  • The creator says it is easier to install than the agent tools Hermes and OpenClaw.
  • New in v0.7.0: a 'Primary Bot' and free web search that works out of the box.
  • A dashboard gives a bird's-eye view of all agent activity. The creator says 'Dots' and 'Grok Bot' don't have this feature.
  • The video has no speech, so everything here comes from the post text.
