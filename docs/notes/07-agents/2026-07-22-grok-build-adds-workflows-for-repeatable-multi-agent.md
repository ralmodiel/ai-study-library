# Grok Build Adds Workflows for Repeatable Multi-Agent Pipelines

Melvin Vivas · X post · 2026-07-22 · [Open on X](https://x.com/melvindvivas/status/2079852326735802878)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Grok Build now has a Workflows feature. You create a workflow with the /create-workflow command. Workflows are meant for multi-agent pipelines that you run repeatedly with a fixed structure.

## Key points

- Grok Build now supports Workflows.
- Create one with the /create-workflow command.
- Use workflows for multi-agent pipelines with a fixed structure that you run repeatedly.
