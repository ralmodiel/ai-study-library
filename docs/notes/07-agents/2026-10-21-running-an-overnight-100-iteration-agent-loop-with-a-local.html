Running an Overnight 100-Iteration Agent Loop with a Local Qwen Model

Summary

Melvin Vivas shares a small experiment. He runs a coding agent on its own overnight, using a quantized local model on one consumer GPU. The setup is Pi agent with a loop plugin, running 100 times. Each time, the agent reviews the code, finds an improvement, makes it and checks it. The post only shows the setup. The results aren't shared yet.

Key points

  • Model: Qwen3.8-27B in the Q4_K_M quantization, published by Unsloth. It runs fully on local hardware.
  • Hardware: a single NVIDIA RTX 3090 (24 GB VRAM). A 4-bit quantized 27B model fits on this kind of consumer GPU.
  • Agent harness: Pi agent with a loop plugin, set to 100 iterations so it runs unattended.
  • The task given each time: check the code, work out what can be improved, make the change and verify it.
  • Adding a verification step to every iteration is meant to stop the agent from piling up broken changes over many cycles.
  • Running locally means overnight autonomous runs cost no API fees. The trade-off is that a local model is slower and may be less capable.
  • Results weren't shared in the post. The output was to be reviewed the next morning.

Try this
