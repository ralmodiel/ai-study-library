Summary

Melvin Vivas shares Coworker, his open-source desktop app where AI agents do work for you. According to the repo, it is easy to use and supports both local and cloud models.

Key points

  • Coworker is a desktop app where AI agents carry out tasks for the user.
  • It supports both local models and cloud models.
  • The source code is on GitHub at donvito/coworker.
  • The creator thinks of the agents as coworkers rather than bots.
