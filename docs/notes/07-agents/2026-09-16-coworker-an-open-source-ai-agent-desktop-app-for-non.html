Summary

The creator introduces Coworker, an open-source desktop app of personal and work AI agents built for non-technical people. It is easy to install and configure, and it supports both local and cloud models.

Key points

  • Coworkers are personal/work AI agents designed for non-technical people
  • Coworker is a desktop app that is easy to install and configure
  • It supports both local and cloud models
