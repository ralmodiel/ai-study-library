## Summary

The creator recommends Docker Sandboxes, isolated environments for running coding agents locally. He notes that Docker may also offer a cloud version, which he hasn't tried.

## Key points

- Docker Sandboxes give coding agents isolated environments to run in.
- The version he recommends runs locally.
- A cloud option may also exist, but he hasn't tried it.
- Sandboxing agents limits what they can do to your host machine.
