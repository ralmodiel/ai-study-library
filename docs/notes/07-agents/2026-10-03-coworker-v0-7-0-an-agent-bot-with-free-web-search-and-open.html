Coworker v0.7.0: An Agent Bot with Free Web Search and Open Models

This note summarises a video post by Melvin Vivas on X, posted 3 October 2026. The original belongs to Melvin Vivas.

Summary

Melvin Vivas announces Coworker v0.7.0, his agent/bot tool, and pitches it as "Dots and Grok Bot for the masses." This release adds a Primary Bot and free web search that work without extra setup. It also has a dashboard that shows all bot activity in one place, and it runs on any open model through OpenRouter. The 32-second video has no speech, so the caption is the only source and there is little to learn beyond the product features.

Key points

  • Coworker v0.7.0 adds a 'Primary Bot' that works without extra setup.
  • Free web search is built in, so the agent can look things up without a paid search API.
  • A dashboard shows everything the bots are doing in one place. The creator says Dots and Grok Bot don't have this.
  • Coworker works with any open model through OpenRouter, so you can switch models without changing providers.
  • The creator presents it as a more accessible alternative to Dots and Grok Bot.
