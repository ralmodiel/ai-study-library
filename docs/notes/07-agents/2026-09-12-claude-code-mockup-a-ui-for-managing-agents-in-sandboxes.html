Summary

The creator asked Claude Code to design a UI for a 'software factory' app. The idea is to manage coding agents running in sandboxes from one control interface, instead of a kanban board or today's agent views. He says it looks hard to build.

Key points

  • You can use Claude Code to quickly prototype UI concepts for new agent tools.
  • 'Software factory' idea: many coding agents, each running in its own sandbox, managed from one interface.
  • This would replace kanban boards and the agent views that tools offer today.
  • The creator thinks building it for real would be a lot of work.
