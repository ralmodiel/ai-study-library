## Summary

The creator runs Hermes Agent with GPT-5.5 through Codex as its main model. He asks experienced users whether they route different tasks to different models, raising the question of choosing models for each task in an agent.

## Key points

- Hermes Agent can use GPT-5.5 through Codex as its main model.
- An open question: whether to use different models for different agent tasks (model routing).
