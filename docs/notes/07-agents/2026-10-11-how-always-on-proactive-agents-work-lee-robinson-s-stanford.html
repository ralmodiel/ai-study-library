Summary

Melvin shares a Stanford CS146S lecture by Lee Robinson (LeeRob) on how always-on, proactive agents like Grok Bot work. Per the chapter list, the lecture covers how these agents came about, what changed in the models, how an always-on agent works inside, the agent harness, context engineering, and where the field is heading.

Key points

  • The lecture explains how always-on, proactive agents (e.g. Grok Bot) work, as opposed to chat agents that only respond when asked.
  • Chapter 2:35 – How we got here: the history behind proactive agents.
  • Chapter 6:13 – What changed in the models to make always-on agents possible.
  • Chapter 10:06 – Inside an always-on agent: its parts and how it runs.
  • Chapter 18:07 – The harness: the scaffolding around the model that runs the agent loop.
  • Chapter 27:26 – Context engineering: managing what goes into the agent's context.
  • Chapter 34:26 – Where this is going.
