# Running DeepSeek V4 Pro on Baseten with the Pi Agent Harness

Melvin Vivas · X video post · 2026-08-20 · [Open on X](https://x.com/melvindvivas/status/2090112612805841007)

**Topics:** AI Agents, Tool Use & MCP, LLMOps, Deployment & Monitoring, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Melvin shows DeepSeek V4 Pro (0813) served on Baseten and used inside the Pi coding-agent harness. He points out how fast it is. The post shows that you can pair an open model hosted by an inference provider with any agent harness.

## Key points

- Model: DeepSeek V4 Pro, 0813 release.
- Hosted on Baseten.
- Run through the Pi (@pidotdev) agent harness.
- The creator was struck by DeepSeek's speed on this setup.
- You can mix and match the model, the host and the agent harness.
