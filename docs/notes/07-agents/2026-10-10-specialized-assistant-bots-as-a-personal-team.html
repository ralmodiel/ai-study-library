Specialized assistant bots as a personal 'team'

Summary

The creator says he no longer opens many separate apps. Instead he messages several Grok Bots, each with its own job: writing, research, email and coding. The idea is to split work across specialized agents so it feels like a team rather than a set of software tools.

Key points

  • Set up one bot per job: a writer, a researcher, an email handler and a coder.
  • You reach every bot through chat messages instead of switching between many apps.
  • The creator expects this agent-as-teammate pattern to become common soon.
