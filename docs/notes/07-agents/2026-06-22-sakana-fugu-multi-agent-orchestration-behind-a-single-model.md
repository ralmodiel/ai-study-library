## Summary

Sakana AI released Fugu, a full multi-agent orchestration system that you call through a single model API. Sakana claims its Fugu Ultra model matches Fable and Mythos without export-control risk. The creator is waiting for independent checks of that claim.

- It is positioned as avoiding export-control risk
- The creator is waiting for independent verification of the performance claims
