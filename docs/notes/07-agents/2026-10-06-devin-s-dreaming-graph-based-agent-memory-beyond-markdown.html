Devin's "Dreaming": Graph-Based Agent Memory Beyond Markdown Files

Summary

Melvin Vivas reshares Cognition's announcement of "Dreaming", a Devin feature that builds a memory graph of how you like to work, across sessions. Overnight, Devin cleans up that memory by removing stale records and finding hidden ("latent") information. Cognition says it is creating an open-source standard for this called Agent Memory Repo. Vivas asks whether this means the end of using Markdown files (like CLAUDE.md or AGENTS.md) as agent memory.

Key points

  • Many coding agents today store memory in plain Markdown files. Vivas asks whether that approach is now outdated.
  • Devin's Dreaming feature builds a memory graph of your work preferences across sessions, so memory carries over instead of resetting each session.
  • The memory graph stores structured, connected facts about how you like to work, not just a flat text file.
  • The name refers to offline consolidation: at night, Devin improves its own memory while it isn't working on a task.
  • Consolidation does two things: it prunes stale or outdated records and it discovers latent information, meaning facts that can be inferred but were never stated directly.
  • Cognition is proposing an open-source standard called Agent Memory Repo, aimed at making agent memory portable and shared across tools.
  • Design lesson: long-term agent memory needs regular maintenance (removing stale entries, combining overlapping ones, drawing inferences), not just appending new notes.

Try this

  • Look up Cognition's Agent Memory Repo standard. The caption link is cut off, so search for it on Cognition's site.
  • Compare your current Markdown-file agent memory (e.g., CLAUDE.md or AGENTS.md) with a graph-based memory approach.
  • Build a nightly 'dreaming' job for your own agent that reviews its memory store, removes stale entries, combines duplicates, and writes out inferred facts.
  • Turn a Markdown memory file into a small memory graph of entities, preferences and relationships, then compare how well the agent recalls information with each approach.
