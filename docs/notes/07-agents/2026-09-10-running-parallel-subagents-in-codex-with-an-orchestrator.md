## Summary

Melvin Vivas shares a Codex skill that makes it easy to run work in parallel with subagents. A stronger model (Astra or Sol) acts as the orchestrator and hands work to Luna subagents. You use it by mentioning the skill in your instruction.

## Key points

- Codex supports subagents, so work can run in parallel.
- Pattern: a stronger model (Astra or Sol) orchestrates, and cheaper Luna models run as subagents.
- Packaged as a skill: just mention the skill in your instruction to use it.
