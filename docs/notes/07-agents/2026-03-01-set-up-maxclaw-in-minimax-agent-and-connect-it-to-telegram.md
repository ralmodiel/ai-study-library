# Set Up MaxClaw in MiniMax Agent and Connect It to Telegram

## Summary

A 1-minute walkthrough of MaxClaw, a hosted agent feature inside MiniMax Agent. It shows how to start MaxClaw, pick either the default OpenClaw-based agent or one of MiniMax's pre-built "experts", and connect the agent to a messaging app (Telegram in the demo) so you can chat with it there. The demo uses the Visual Lab expert to generate a logo image from Telegram, then shows how to switch experts.

## Key points

- MaxClaw is opened from the left sidebar in MiniMax Agent; click MaxClaw, then 'Start Now'.
- You pick a starting 'expert'. The default connects directly to OpenClaw; pre-built MiniMax experts (e.g. Visual Lab Expert) are more specialised.
- After you click 'I'm Ready', MaxClaw takes about a minute to start, then opens its dashboard.
- Supported messaging apps: Telegram, Discord, Slack and WhatsApp. The demo uses Telegram and follows the setup steps shown in MiniMax Agent.
- Connecting a messaging app takes a few minutes; after that you can chat with the agent directly inside the app.
- Example: with the Visual Lab expert, asking it to generate a logo for a tech startup returns images in the chat.
- To switch experts, click the Settings icon (top right), open the configuration, and choose a different expert.

## Try this

- [ ] In MiniMax Agent, click MaxClaw in the left sidebar, then 'Start Now'.
- [ ] Pick the default (OpenClaw) or a pre-built expert such as Visual Lab Expert, then click 'I'm Ready'.
- [ ] Connect a messaging app (Telegram, Discord, Slack or WhatsApp) by following the steps shown in MiniMax Agent.
- [ ] Chat with the agent from that app, e.g. ask it to generate a logo.
- [ ] To switch experts, use the Settings icon and open the configuration.
- [ ] Generate a logo for your tech startup by chatting with the Visual Lab expert through Telegram.
