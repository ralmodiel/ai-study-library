Coworker: An Open-Source Personal AI Assistant Desktop App (Not a Coding Agent)

Summary

Melvin Vivas explains that Coworker, his open-source desktop app, is a personal and work assistant, not a coding agent. It is in the same category as OpenClaw, Dots and the assistant features of Hermes. He lists what it does: a dashboard of bot activity, web search, file creation, scheduled jobs, approvals, simple memory, Skills for each bot, and Telegram/Discord pairing. It works with local, Chinese and free OpenRouter models. He invites people to fork it and build personal AI apps that fit their own needs.

Key points

  • Coworker is a personal or work assistant desktop app, not a coding agent. It is closer to OpenClaw, Dots, Grok Bot or Hermes' assistant features (not Hermes' coding features).
  • Features: a dashboard of all bot activity, web search, file creation, scheduled jobs, human approvals, simple memory, and Skills for each bot.
  • Each bot can be paired with Telegram or Discord for mobile access, similar to Hermes.
  • Folder access is read-only for safety. Generated files are saved to the app folder and can be downloaded or opened from the app.
  • It is built to work with local models and cheaper models, including Chinese ones. The author's experience is that you don't need very expensive models.
  • He tests it with free OpenRouter models. They work, but availability and performance are less reliable.
  • It was built by a solo developer using Codex, Claude Code, Cursor and Devin credits, and it is still early-stage.
  • Message: fork open-source assistants and make your own AI apps that match your preferences.

Try this

  • Try out or fork the Coworker repo on GitHub.
  • Customize the fork to your own preferences and own your AI assistant.
  • Try free OpenRouter models or local models instead of expensive ones, and accept the tradeoffs.
  • Build your own personal AI assistant desktop app with bots, memory, Skills, scheduled jobs, approvals and Telegram/Discord access, using local or low-cost models.
