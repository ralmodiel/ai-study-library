# TanStack AI Adds Subagents for Streaming Multi-Agent UIs

Melvin Vivas · X video post · 2026-09-24 · [Open on X](https://x.com/melvindvivas/status/2103097520461369622)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator recommends TanStack AI now that it supports subagents. You define agents once and pass them to chat(), and each agent streams its own card in the UI. A router sends each message to the right agents, either in parallel or in sequence.

## Key points

- TanStack AI now supports subagents.
- Define agents once, then pass them to chat().
- Each subagent streams its own UI card, so you can see multi-agent output separately.
- Messages are routed to the right agents, which can run in parallel or in order.
- The creator thinks the framework is worth evaluating for agentic web apps.
