Summary

The creator says they never set up their Hermes jobs by hand. They asked the agent in chat to create them, and the agent set up the jobs itself. Being able to set up automations in plain language is the main reason they like Hermes.

Key points

  • Hermes can create its own scheduled jobs from a plain chat request
  • No manual job configuration needed
  • Describe the automation you want in plain language and let the agent set it up
