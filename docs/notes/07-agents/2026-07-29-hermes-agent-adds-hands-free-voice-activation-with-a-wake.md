# Hermes Agent Adds Hands-Free Voice Activation with a Wake Word

Melvin Vivas · X video post · 2026-07-29 · 0:20 · 87 views · [Open on X](https://x.com/melvindvivas/status/2082515491340570807)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** beginner

## Summary

Melvin Vivas reacts to a quoted announcement: Nous Research's Hermes Agent now supports voice activation. When you say the wake word, Hermes opens a new session and listens for your command. This works hands-free in the CLI, the TUI and the desktop app. In the 20-second demo he says "Hey Hermes" and the agent answers "How may I help you?"

## Key points

- Hermes Agent (by Nous Research) now has a wake-word / voice-activation feature.
- Saying the wake word opens a new agent session and the agent listens for a spoken command.
- It works hands-free in the CLI, the TUI (terminal UI) and the desktop app.
- Wake-word detection runs locally on your machine, so audio isn't sent to the cloud just to detect the wake word.
- The feature is off by default, so you have to turn it on yourself.
- Demo: the user says "Hey Hermes" and the agent replies "How may I help you?"
- Setup is covered in the Hermes Agent user guide under features/wake-word. The shortened link in the post leads to a broken page; the full path is hermes-agent.nousresearch.com/docs/user-guide/features/wake-word.
