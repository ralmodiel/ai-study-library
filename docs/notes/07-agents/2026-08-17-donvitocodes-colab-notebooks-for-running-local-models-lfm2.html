Summary

The creator added a Notebooks section to his website, where he'll post Google Colab notebooks for running local models. The first notebook shows chat and tool calling with Liquid AI's small LFM2.5-2.6B model.

Key points

  • Notebooks run in Google Colab, so you don't need a local GPU.
  • First notebook: chat and tool calling with LFM2.5-2.6B.
  • More notebooks for running local models are planned, so bookmark the page.
