Prompting an Autonomous Agent Loop: Be Specific, Show Visible Progress

This note summarises a post by Melvin Vivas on X, posted 22 October 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Melvin Vivas · X post · 2026-10-22 · Open on X

Topics: AI Agents, Tool Use & MCP, Prompt & Context Engineering · Level: intermediate

Summary

The creator restarted the 100-iteration local agent loop (Qwen3.8-27B Unsloth quant on an RTX 3090, run through Pi agent's loop plugin) because the first prompt was too conservative and general. The new prompt asks for UI changes so progress can be seen in the browser. The lesson: give autonomous loops specific goals whose results you can see.

Key points

  • A vague, conservative prompt led to weak progress across the loop's iterations.
  • The revised prompt asks for UI changes so each iteration's progress shows up in the browser.
  • Setup: Qwen3.8-27B-Q4_K_M (Unsloth) on a local RTX 3090, with Pi agent's loop plugin set to 100 iterations.
  • The per-iteration task is to check the code, find an improvement, and verify it.
  • At the time of posting, the restarted loop was on iteration 5 of 100.

Try this

  • Make autonomous-loop prompts specific, and ask for changes you can see so progress is easy to check.
