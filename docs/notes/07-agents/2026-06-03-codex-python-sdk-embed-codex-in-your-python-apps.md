# Codex Python SDK: embed Codex in your Python apps

Melvin Vivas · X post · 2026-06-03 · [Open on X](https://x.com/melvindvivas/status/2061961486705062019)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

OpenAI released a Codex Python SDK that lets developers embed the Codex coding agent in their Python apps and workflows. It supports threads, turns, streaming, session resumption, image inputs and sandbox control, and it reuses your existing Codex auth.

## Key points

- The Codex Python SDK embeds the Codex agent directly into Python apps and workflows.
- Start threads and run turns programmatically.
- Stream progress events while the agent works.
- Resume previous sessions.
- Pass images as input.
- Control sandbox access for safety, and reuse your existing Codex authentication; install it with pip.
