# Codex orchestrator/subagent skill: Astra or Sol leads, Luna subagents

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator shares a Codex skill for multi-agent setups. Astra or Sol acts as the orchestrator and Luna models run as subagents. He says that with this skill, subagents always report back to the orchestrator.

## Key points

- Orchestrator pattern: a stronger model (Astra or Sol) coordinates and cheaper Luna models do the subtasks.
- The skill is meant to fix subagents failing to report results back to the orchestrator.
- It's packaged as a Codex skill in a public GitHub repo.
