**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator launched skillsbento, a free, open-source marketplace for AI agent skills. It is aimed at both non-technical and technical users who want to use skills with Claude and other tools, and is currently an MVP stocked with skills the creator wrote.

## Key points

- skillsbento collects free, open-source agent skills.
- It works with Claude and other AI tools.
- It is aimed at both non-technical and technical users.
- It is an MVP that currently lists the creator's own skills.
