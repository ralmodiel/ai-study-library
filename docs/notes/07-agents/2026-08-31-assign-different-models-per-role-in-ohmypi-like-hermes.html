Assign Different Models per Role in ohmypi (Like Hermes)

Summary

The ohmypi coding agent lets you assign a different LLM to each role, as the Hermes agent does. This lets you balance cost and capability by giving each role a model that fits it.

Key points

  • ohmypi supports setting a separate model for each agent role.
  • Hermes has a similar per-role model setting.
  • Matching models to roles (for example, cheap models for simple roles and strong models for hard ones) helps control cost.
