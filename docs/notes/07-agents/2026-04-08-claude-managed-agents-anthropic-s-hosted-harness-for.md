This short announcement post introduces Claude Managed Agents, launched in public beta on the Claude Platform. The product combines an agent harness tuned for performance with production infrastructure. The pitch is that teams can go from a prototype agent to a production launch in days, without building their own agent loop and hosting stack. ## Key points

- Claude Managed Agents is pitched as 'everything you need to build and deploy agents at scale'.
- It has two parts: an agent harness (the loop that runs the agent and its tools) tuned for performance, and production infrastructure to run it.
- The stated goal is to go from prototype to launch in days.
- Status as of 2026-04-08: public beta, available on the Claude Platform.
- Why it matters: a managed harness is an alternative to building your own agent loop and deployment stack, for example with an open-source framework you host yourself.
