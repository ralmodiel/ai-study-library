# LLM Council Agent in Pi Using Codex and Claude Models

Melvin Vivas · X post · 2026-10-01 · [Open on X](https://x.com/melvindvivas/status/2105623208875761959)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator runs an 'LLM council' agent in Pi, where several models work on the same task together. He used two models because he connected both his Codex (OpenAI) and Claude accounts.

## Key points

- An LLM council has multiple models deliberate or answer together, which can produce stronger results.
- Pi lets you connect existing Codex and Claude accounts and use those models in one agent.
- The number of council members depends on how many provider accounts you connect (two here).
