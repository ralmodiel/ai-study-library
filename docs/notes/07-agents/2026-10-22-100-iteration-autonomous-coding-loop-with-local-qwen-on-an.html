100-Iteration Autonomous Coding Loop with Local Qwen on an RTX 3090

Summary

The creator runs an autonomous agent loop that improves a CRM app for 100 iterations, using a local quantized Qwen model at no cost. The setup is Qwen3.8-27B-Q4_K_M (Unsloth quant) on one RTX 3090, driven by Pi agent and its loop plugin. After about 6 hours (counted from a restart to change the prompt) it was on iteration 21 of 100.

Key points

  • Model: Qwen3.8-27B in Unsloth's Q4_K_M quantization, running locally on one RTX 3090 (24 GB).
  • Harness: Pi agent with the loop plugin, set to 100 iterations.
  • Prompt for each iteration: check the code, find an improvement, make it, and verify it.
  • Speed: about 21 iterations in about 6 hours, so roughly 17 minutes per iteration.
  • Running locally makes an overnight loop free apart from electricity.
  • Rewriting the prompt meant restarting the loop, so get the prompt right early.
