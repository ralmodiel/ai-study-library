# Coworker: A Subscription-Free AI Agent on Local LFM2.5-2.6B

Melvin Vivas · X post · 2026-08-26 · [Open on X](https://x.com/melvindvivas/status/2092525819084386315)

**Topics:** AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Shows Coworker, the creator's AI agent app for work, running locally with Liquid AI's LFM2.5-2.6B model. The pitch is an AI coworker that needs no subscription because it runs on a local model.

## Key points

- Coworker can run entirely on local models.
- LFM2.5-2.6B from Liquid AI is a small model that can power a local work agent.
- Local models remove the need for a subscription.
