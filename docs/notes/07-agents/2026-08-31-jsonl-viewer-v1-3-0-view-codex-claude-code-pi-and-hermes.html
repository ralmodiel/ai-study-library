JSONL Viewer v1.3.0: View Codex, Claude Code, Pi and Hermes Agent Traces

Summary

The creator released version 1.3.0 of his open-source JSONL viewer. It can now open agent traces from Codex, Claude Code, Pi and Hermes, so it's useful for checking what coding agents did and for looking at fine-tuning datasets. Installers are available.

Key points

  • JSONL Viewer v1.3.0 adds support for viewing agent traces.
  • Supported trace formats: Codex, Claude Code, Pi and Hermes.
  • The tool also views and edits .jsonl files used for fine-tuning and training datasets.
  • Ready-made installers are available.
