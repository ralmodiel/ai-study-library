Summary

The creator shares the launch of Gemini Spark, a dedicated agent in the Gemini app, and jokingly nicknames it 'Gemini Claw'. Spark runs on its own virtual machine, can connect to all of a user's Google data, and comes with a new UI on mobile and web.

Key points

  • Gemini Spark is an agent that runs on a dedicated virtual machine
  • It can connect to all of a user's Google data
  • Ships with a new UI in the Gemini mobile and web apps
  • Example of the trend toward always-on personal agents with their own compute
