Coworker: Open-Source Grok Bot Clone Built on Pi and CopilotKit

This note summarises a video post by Melvin Vivas on X, posted 24 August 2026. The original belongs to Melvin Vivas.

Summary

The creator built Coworker, a free, open-source Grok Bot clone. It uses Pi as the agent runtime, CopilotKit for the chat UI and Firecrawl for web search. It works with OpenAI and OpenRouter models and with local models through Ollama and LM Studio. He built it in one day, moving from Cursor to Codex to Claude Code as his usage limits ran out.

Key points

  • Stack: Pi for the agent runtime, CopilotKit for the chat UI, Firecrawl for web search.
  • Models: OpenAI and OpenRouter, plus local models through Ollama and LM Studio.
  • Each coworker gets its own conversations, so it can start with fresh context when needed.
  • You can view and download files your coworker creates.
  • Still in progress: approvals and a scheduler.
  • Built in a single day: started with /goal in Cursor using GPT-5.6 Sol, moved to Codex, then finished in Claude Code when Codex limits ran out.
