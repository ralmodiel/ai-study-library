# Using a Hermes agent to watch the terminal and drive Codex

Melvin Vivas · X post · 2026-08-09 · [Open on X](https://x.com/melvindvivas/status/2086318163847987475)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

While llama.cpp took a long time to compile, the creator went to bed. He had a second Hermes agent check his terminal every few minutes, send him screenshots, and help him approve and prompt Codex remotely. It shows agents supervising other coding agents.

## Key points

- Compiling llama.cpp from source can take a long time.
- A personal agent (Hermes) can check a terminal on a schedule and send screenshots to your phone.
- The agent can pass along approvals and prompts to a coding agent (Codex) so work keeps going while you are away.
