Summary

The creator shares a milestone (36 GitHub stars) for his project Coworker. Coworker is a desktop app where AI agents do work for you, and it supports both local and cloud models. You can study it as a real example of an agent desktop app.

Key points

  • Coworker is a desktop app where AI agents complete tasks for the user.
  • It supports both local and cloud LLMs.
  • The code is public on GitHub at donvito/coworker and had 36 stars when posted.
  • You can read its code to see how a desktop agent app connects to different model providers.
