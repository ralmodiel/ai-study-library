Summary

The creator released Coworker v0.7.2, his open-source desktop AI assistant. It can search the web, create files, schedule tasks, use memory and run with local or cloud models. This release adds folder write access for the bot and a new File Explorer, plus bug fixes.

Key points

  • Coworker is a simple desktop AI assistant that works with local or cloud models.
  • Features: web search, file creation, scheduled tasks and memory.
  • v0.7.2: you can pick a folder and give the bot write access to it.
  • v0.7.2 adds a new File Explorer and bug fixes.
  • It is a useful open-source example of a desktop agent with tools.
