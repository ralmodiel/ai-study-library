Summary

Melvin Vivas asked Hermes Agent to make a video. The agent used the Hyperframes tool and finished it in about 10 minutes, with Grok 4.5 as the underlying model. It is an example of an agent using a tool to produce media from a single request.

Key points

  • Prompt the agent with a high-level goal ('make me a video').
  • The agent picked and used Hyperframes to create the video.
  • Model used: Grok 4.5 inside Hermes Agent.
  • The finished video took about 10 minutes.
