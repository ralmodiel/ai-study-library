## Summary

Melvin Vivas plans to build a product on the new OpenAI Agents API. He says the API, which runs on Codex, makes 'software factories' (automated software-building pipelines) easy to build.

## Key points

- He says this infrastructure makes it easy to build software factories.
- You need paid OpenAI API credits to use it.
