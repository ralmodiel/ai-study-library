Summary

The creator shares a new companion agent skill in pstack. It helps coding agents draw statecharts and diagrams and check them against specs made with the /create-formal-verification-skill command. The diagrams are drawn with Pele by kepano.

Key points

  • The new pstack companion skill lets agents draw statecharts and diagrams.
  • The diagrams are checked against formal specs made with /create-formal-verification-skill in pstack.
  • It uses Pele (by @kepano) to draw the diagrams.
  • Use case: pairing visual diagrams with formal verification specs inside agent workflows.
