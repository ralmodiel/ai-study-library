Summary

A production AI agent needs more than an LLM plus a prompt. It needs a clear pattern for reasoning, making decisions, using tools and finishing work. The post covers five core agentic design patterns: Tool Use/ReAct, Planning, Reflection/Critic, Routing and Multi-Agent. It advises picking the simplest pattern that can reliably complete the task.

Key points

  • Tool Use / ReAct: the agent reasons, chooses a tool, observes the result, then decides the next step (a loop).
  • Planning: the agent breaks a large goal into smaller, executable steps before doing the task.
  • Reflection / Critic: the agent generates an output, evaluates it, finds weaknesses and improves it.
  • Routing: the system classifies the request and sends it to the right model, tool, workflow or specialist agent.
  • Multi-Agent: specialized agents split the work, collaborate, review each other's outputs and combine the results.
  • You don't need five agents for every problem. Choose the simplest pattern that reliably completes the task.
  • A production agent is more than an LLM connected to a prompt.
