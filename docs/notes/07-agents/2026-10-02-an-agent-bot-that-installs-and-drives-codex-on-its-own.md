# An agent bot that installs and drives Codex on its own

Melvin Vivas · X post · 2026-10-02 · [Open on X](https://x.com/melvindvivas/status/2105963336097837160)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator reports that his Coder Grok Bot installed OpenAI Codex on its computer and then used it. It shows one agent handing coding work to another coding agent so work continues while he is away.

## Key points

- A general agent (Grok Bot) with computer access can install other tools on its own, here the Codex coding agent.
- The bot then used Codex to do coding work, so one agent was directing another.
- The goal was to keep using his Codex usage limits while he was away from the computer.
