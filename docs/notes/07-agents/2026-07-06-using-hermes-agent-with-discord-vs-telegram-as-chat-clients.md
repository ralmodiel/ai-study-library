# Using Hermes Agent with Discord vs Telegram as Chat Clients

Melvin Vivas · X post · 2026-07-06 · [Open on X](https://x.com/melvindvivas/status/2074015035077373956)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator compares chat apps for talking to Hermes Agent. Discord threads give a different experience from Telegram topics, so he recommends setting up a free Discord server. He still uses Telegram for quick chats and says it's fine to use both.

## Key points

- Hermes Agent can use Discord or Telegram as its chat interface.
- Discord threads organize conversations differently from Telegram topics.
- Creating a Discord server is free.
- Use Telegram for quick chats and Discord for organized, threaded work; running both is fine.
