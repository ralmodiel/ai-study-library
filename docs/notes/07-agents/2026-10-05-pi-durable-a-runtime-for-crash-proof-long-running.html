Pi Durable: A Runtime for Crash-Proof, Long-Running, Multiplayer Agents

Summary

This video introduces Pi Durable, an experimental runtime released with Pi 1.0 (the transcript says "Arendil", which is most likely Earendil). Pi on its own is a coding agent that one person drives from a terminal. Pi Durable is a harness for agents that run in Slack, on servers or in the cloud. The video explains how it uses checkpointed tasks, pluggable storage, forked conversations and multi-client streaming so agents can survive crashes and be steered by many people at once.

Key points

  • Pi Durable is a 'harness': storage plus the machinery to run many model conversations in parallel. Conversations call tools, tools run in execution environments, and everything the harness does (model calls, tool runs) is a task.
  • Storage is pluggable. Memory, SQLite and JSONL backends come built in, and the interface is small enough to build on Postgres, a key-value store or a Cloudflare Durable Object. Only the working set stays in memory; everything else stays on disk.
  • Each step of a run is a task that saves a checkpoint before it moves on. If the process crashes, a new process opens the same storage and resumes each task from its last checkpoint.
  • Tools marked ReplaySafe simply rerun after a crash. Tools with side effects, such as a deploy, are never repeated. The model is told it was interrupted, and a request ID makes every submission happen exactly once.
  • Forks branch from any point in a transcript without copying history, like a Slack thread spun off a channel. Sub-agents are just conversations owned by the tool call that started them.
  • Extensions bundle prompt sections, tools, hooks and tasks. App state (to-do lists, plans) lives in typed JSON documents committed atomically with the transcript. Compaction runs in the background, and you can hot-swap extension code while agents keep running.
  • Multiplayer: any number of clients can attach to a conversation. Each gets the current view, then streams only what changes, so people can join late, reconnect or steer the agent mid-run.
  • It is MIT-licensed, about 15,000 lines of TypeScript, and installed from npm. It is experimental, so the API may change.

Try this

  • Install Pi Durable from npm and start building durable agents.
  • Read the Pi Durable source; it is small enough (about 15k lines of TypeScript) for you or your agent to read.
  • Build a Slack-based agent on Pi Durable that survives process crashes and lets several team members steer it at the same time.
  • Write a custom Pi Durable storage backend on Postgres, a key-value store or a Cloudflare Durable Object.
