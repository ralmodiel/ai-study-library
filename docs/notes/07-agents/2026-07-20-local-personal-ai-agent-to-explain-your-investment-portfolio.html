Local Personal AI Agent to Explain Your Investment Portfolio

Summary

Melvin Vivas uses Hermes Agent as a personal AI assistant to help him understand what is happening in his investment portfolio. The model runs locally: Qwen 3.6 35B with MTP (multi-token prediction). It is an example of a private, free personal agent built on a local open-weight model.

Key points

  • Hermes Agent works as a personal AI assistant.
  • Use case: summarizing and explaining changes in an investment portfolio.
  • The model runs fully locally: Qwen 3.6 35B MTP (a mixture-of-experts model with multi-token prediction).
  • Running locally keeps personal financial data private and costs nothing per use.
