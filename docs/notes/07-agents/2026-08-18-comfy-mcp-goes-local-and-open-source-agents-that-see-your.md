Melvin Vivas reshares an announcement that Comfy MCP is now a local, open-source MCP server, following Comfy Cloud MCP, which shipped in June. The local version lets an AI agent see your actual Comfy install, including every node, custom nodes and every model on disk. ## Key points

- Comfy MCP is now available as a local, open-source MCP server.
- Comfy Cloud MCP shipped in June. A local version was the #1 user request after that.
- Because it is local, the agent sees your actual install: every node, including custom nodes, and every model on disk.
- The agent can fetch files, start your Comfy instance and get a workflow to the point where it runs.
- Takeaway: an MCP server that exposes local environment state (installed nodes and models) lets agents work with your real setup instead of guessing.
