# Gemini CLI Adds Subagents with Separate Context Windows

Melvin Vivas · X post · 2026-04-16 · [Open on X](https://x.com/melvindvivas/status/2044753853158248552)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity, Prompt & Context Engineering · **Level:** intermediate

## Summary

The creator shares the news that Gemini CLI now supports subagents. Each subagent gets its own context window, custom system instructions and a chosen set of tools. This lets you build specialized agents, keep the main agent's context clean and run work in parallel.

## Key points

- Gemini CLI now supports subagents.
- Each subagent has its own separate context window.
- Each subagent can have custom system instructions.
- Each subagent gets a curated set of tools.
- Use cases: specialized expert agents, keeping the main agent focused with a clean context, and handing work to parallel agents.
