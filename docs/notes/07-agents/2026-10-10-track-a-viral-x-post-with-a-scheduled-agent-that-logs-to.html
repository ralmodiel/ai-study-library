Track a viral X post with a scheduled agent that logs to Google Sheets

Summary

A step-by-step prompt recipe for having an agent track how an X post performs over time. You send the bot the post link and ask it to check every 30 minutes, measure how many views it gains per interval, judge whether growth is speeding up or slowing down, log everything to a Google Sheet, and write a final report with graphs.

Key points

  • Send the bot the post link and tell it to 'check this every 30 mins'.
  • Ask for the number of views gained in each 30-minute period, and whether growth is speeding up or slowing down.
  • Say 'log everything to a Google Sheet' to keep a record of each check.
  • Say 'when it ends, write me a report with graphs' to get a final summary.
  • The agent sets up the schedule, collects the numbers and sends you updates.
  • Change the tracking length and check interval to suit you.
