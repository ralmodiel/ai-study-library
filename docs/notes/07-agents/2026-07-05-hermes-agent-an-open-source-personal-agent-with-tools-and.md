## Summary

The creator recommends NousResearch's open-source Hermes Agent as a personal AI assistant. It can use tools, remember workflows, run tasks and work across apps, which he sees as the direction personal agents are heading.

## Key points

- Hermes Agent is an open-source agent from Nous Research ('The agent that grows with you').
- Core abilities: tool use, memory of workflows, running tasks and working across apps.
- Personal agents are moving from answering questions to taking actions for the user.
