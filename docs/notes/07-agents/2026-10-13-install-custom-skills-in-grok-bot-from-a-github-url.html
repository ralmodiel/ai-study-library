Install Custom Skills in Grok Bot from a GitHub URL

Summary

To install a custom skill in a Grok Bot, you send the bot the GitHub URL of the skill and it installs it. The creator tried this with his own repo, skillsbento. That repo is a plugins marketplace for Codex and Claude skills.

Key points

  • Grok Bot can install custom skills when you send it a GitHub repo URL in chat.
  • You don't need a manual install step; the bot fetches the skill and installs it.
  • The creator's skillsbento repo collects skills/plugins for Codex and Claude, and they can also be loaded into Grok Bot.
  • This suggests a skill format that can be reused across agents (Claude, Codex, Grok).
