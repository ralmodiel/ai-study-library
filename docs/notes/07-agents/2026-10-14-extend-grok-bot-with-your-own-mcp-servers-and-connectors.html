Topics: AI Agents, Tool Use & MCP · Level: intermediate

Summary

The Grok Bot plugin submission page is live. Developers can extend the assistant by submitting their own MCP servers and connectors.

Key points

  • Grok Bot plugin submissions are now open.
  • Plugins can be MCP (Model Context Protocol) servers or connectors.
  • Submitting one makes your tools available inside Grok Bot.

Resources mentioned

  • Grok Bot · tool · x.ai · paid
    An AI personal assistant the creator describes as having memory, day planning, task scheduling and the ability to do background work without any coding.

Try this

  • Submit your own MCP server or connector on the Grok Bot plugin submission page.
  • Build an MCP server for a tool you use and submit it as a Grok Bot plugin.
