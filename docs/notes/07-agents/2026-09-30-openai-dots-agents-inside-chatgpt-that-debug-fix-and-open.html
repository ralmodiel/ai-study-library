Summary

This 29-second clip from OpenAI's announcement introduces "Dots", agents built into ChatGPT. You give a Dot a task, such as finding what slows down an app and fixing it. It keeps working on its own, traces dependencies, writes code, runs tests and opens pull requests for the team to review. The creator asks whether this puts pressure on xAI's Grok. The clip is a product announcement, not a tutorial, but it shows where agentic coding assistants are heading.

Key points

  • Dots are agents built into ChatGPT ('I'm new in ChatGPT') that take on tasks and keep working on them over time.
  • Example task from the clip: 'Find out what's slowing down our app, build a fix, and show me how much faster it runs.'
  • Dots can trace code dependencies to find everything that needs to change.
  • The workflow shown is: write code, run tests, then open pull requests for humans to review.
  • According to the clip, Dots work with more than 4,000 apps across ChatGPT, which points to broad tool use and integrations.
  • The creator frames it as competition for xAI's Grok ('Is Grok Bot cooked?'). This is opinion and engagement bait, not analysis.
