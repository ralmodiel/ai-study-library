Coworker v0.4.0: Desktop AI Agent App Adds Browser Use

Summary

Melvin Vivas (donvitocodes) announces version 0.4.0 of Coworker, his desktop app where AI agents do work for you. Coworker runs local or cloud models. The main new feature in this release is browser use, so agents can now control a web browser. The 16-second video has no narration, so the post is mostly a pointer to the download page and the GitHub repo.

Key points

  • Coworker is a local-first desktop app where AI agents do tasks for you.
  • It works with both local and cloud LLMs.
  • Version 0.4.0 adds browser use, so agents can control a web browser to finish tasks.
  • The source code is on GitHub at donvito/coworker. You can read it to see how a desktop agent app is built.
  • You can download the app from donvitocodes.com/coworker.
