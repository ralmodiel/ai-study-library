The complete arXiv corpus as a Hugging Face dataset

This note summarises a post by Melvin Vivas on X, posted 20 September 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Melvin Vivas · X post · 2026-09-20 · Open on X

Topics: AI Agents, Tool Use & MCP, Retrieval-Augmented Generation (RAG) · Level: intermediate

Summary

Shares a Hugging Face dataset holding the whole arXiv site: 3,148,796 papers in every version, as LaTeX, PDF, PostScript and HTML, about 16 TB in total. The creator suggests giving it to your agent as a research source.

Key points

  • Dataset: arxiv-complete on Hugging Face (user secemp9).
  • Contains 3,148,796 papers, including every version of each.
  • Formats: LaTeX source, PDF, PostScript and HTML.
  • Total size is about 16 TB, so plan to stream or download only parts of it.
  • Suggested use: give it to an AI agent as a research or knowledge source.

Resources mentioned

  • arxiv-complete (Hugging Face dataset) · dataset · huggingface.co · free
    The full arXiv archive (3.1M papers, every version, in LaTeX, PDF, PS and HTML, 16 TB) hosted on Hugging Face.
