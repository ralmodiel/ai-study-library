Coworker: A Desktop AI Assistant App, Not a Coding Agent

This note summarises a video post by Melvin Vivas on X, posted 7 October 2026. The original belongs to Melvin Vivas.

Summary

This is a short, mostly promotional post. Melvin Vivas jokes about joining the "Grok Bot" team and shows a solo-built desktop app called Coworker. The quoted post explains that Coworker is not an AI coding agent. It is a personal or work assistant desktop app, in the same group as Grok Bot, Dots, OpenClaw and the assistant features of Hermes. It teaches very little beyond the difference between general assistant agents and coding agents.

Key points

  • Coworker is a desktop AI assistant app that Melvin Vivas built by himself.
  • Coworker is not a coding agent and isn't meant to be one. People reposting it as a coding agent have it wrong.
  • It is a personal or work assistant, like Grok Bot, Dots, OpenClaw, or the assistant (not coding) features of Hermes.
  • Personal or work assistant agents are a different product category from AI coding agents.
  • The video has no speech, so all the content is in the post text.
