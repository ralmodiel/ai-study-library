Summary

Coworker v0.7.0 adds a Primary Bot and lets you tag other bots in a conversation. This is a simple pattern for coordinating multiple agents: one main agent plus specialist agents you can mention directly.

Key points

  • Coworker v0.7.0 introduces a Primary Bot that acts as the main agent.
  • You can tag other bots to bring them into the work.
  • A primary agent plus taggable specialist agents is a simple multi-agent coordination pattern.
  • Coworker is open source and supports local and cloud models.
