# GAIA: free Docker installer for multiple Hermes agents

Melvin Vivas · X post · 2026-08-17 · [Open on X](https://x.com/melvindvivas/status/2089240814635581729)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator released GAIA, a free installer that makes it easy to set up one or more Hermes agent instances in Docker on Mac and Windows. The GitHub repo and an about page are linked.

## Key points

- GAIA installs several Hermes agent instances using Docker.
- Works on Mac and Windows. Docker must be installed.
- Free to download from GitHub.
