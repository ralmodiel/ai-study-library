**Topics:** AI Agents, Tool Use & MCP, LLM Fundamentals · **Level:** beginner

## Summary

LFM2.5-2.6B, a small model, is free on OpenRouter with good throughput. Melvin suggests pointing your Hermes agent harness at it to run agents for free.

## Key points

- LFM2.5-2.6B is free on OpenRouter and has good throughput.
- Small free models can power an agentic harness at no cost.
- Configure Hermes (or any harness) to use this model through OpenRouter.
