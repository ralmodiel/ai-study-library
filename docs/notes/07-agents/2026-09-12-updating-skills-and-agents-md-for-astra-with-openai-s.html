Summary

The creator is updating his Skills and AGENTS.md files for the Astra model, following OpenAI's guidance. He says he is sharing two migration prompts he runs in Codex, but the prompts are not in the post text. The main lesson: agent instruction files written for older models should be updated for new ones.

Key points

  • Skills and AGENTS.md written for older models may not suit Astra.
  • OpenAI has published guidance on updating them.
  • The creator uses Codex to run two migration prompts that rewrite these files.
  • The prompts themselves are not included in the post text.
