## Summary

The creator shares Coworker, his open-source desktop app where AI agents do work for you, using local or cloud models. He says he wants to add sandboxes for running agents. The repo is a useful reference for desktop agent apps.

## Key points

- Coworker is a desktop app where AI agents complete tasks for the user.
- It supports both local and cloud models.
- Sandboxed execution is the next planned feature, so agents can run safely.
- The source code is on GitHub at donvito/coworker.
