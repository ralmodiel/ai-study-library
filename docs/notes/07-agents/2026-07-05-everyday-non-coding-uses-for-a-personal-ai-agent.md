# Everyday Non-Coding Uses for a Personal AI Agent

Melvin Vivas · X post · 2026-07-05 · [Open on X](https://x.com/melvindvivas/status/2073633150790680869)

**Topics:** AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

The creator lists the real tasks he has used Hermes for. None of them involve coding, which shows a personal agent working as a general-purpose life assistant.

## Key points

- Send screenshots from a school app and have the agent remind you of deadlines.
- Get sports updates (F1 British Grand Prix, Wimbledon/Alex Eala).
- Shopping research, e.g. finding a replacement monitor.
- Recommendations (K-dramas, cat breeds) and brainstorming business ideas.
- Summarize a video posted on X.
