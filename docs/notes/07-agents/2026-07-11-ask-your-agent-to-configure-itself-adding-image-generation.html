Ask Your Agent to Configure Itself: Adding Image Generation

Summary

Hermes Agent can change its own setup when you ask it in plain language. The creator runs Grok 4.5 through the xAI API and told Hermes to add image generation using Grok Imagine. After that, his personal AI could generate images.

Key points

  • Agents like Hermes can edit their own configuration when you tell them what you want.
  • The creator uses Grok 4.5 through xAI as the main model.
  • He asked the agent to add image generation with Grok Imagine, from the same xAI provider.
  • You can add new abilities (tools) through conversation instead of editing config files by hand.

Try this

  • Ask your agent in plain language to add a new ability (e.g., image generation) through your existing model provider.
  • Add image generation to a personal AI agent by having the agent set up an image model API itself.
