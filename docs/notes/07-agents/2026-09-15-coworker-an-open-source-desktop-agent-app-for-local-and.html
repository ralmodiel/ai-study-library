Coworker: An Open-Source Desktop Agent App for Local and Cloud Models

This note summarises a post by Melvin Vivas on X, posted 15 September 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Summary

Melvin Vivas built Coworker, an Electron desktop app for AI agents, to practise building agentic apps. He took ideas from Grok Bot and Hermes. The post lists its features: support for local models through Ollama, LM Studio and llama.cpp, free models from OpenRouter, Telegram and Discord integration, in-chat approvals, Skills that can be turned on or off per agent, and file access limited to chosen folders.

Key points

  • Coworker is a learning project for agentic app development. It is not meant to compete with Hermes or Grok Bot.
  • You can connect local models from Ollama, LM Studio or llama.cpp in the UI. This was the main reason for building it.
  • It is an Electron desktop app, so it installs easily on Mac, Windows and Linux.
  • It connects to Telegram and Discord, and approvals can happen in chat on the desktop, Telegram or Discord.
  • Each Coworker can switch to a free model from OpenRouter with little effort.
  • Files, scheduled jobs and approvals have their own views, so you don't have to scroll through chats to find them.
  • Each Coworker gets its own Skills and its own local folders, and it can only access those folders.
  • Headless mode for servers is experimental.
