Summary

The creator released Agent Monitor v0.1.0, an open-source dashboard for Codex, Claude Code, Pi and Hermes main agents and their subagents. You can explore agent trees, read traces, and track token usage and estimated costs.

Key points

  • Visualizes main agents and subagents for Codex, Claude Code, Pi and Hermes
  • Explore agent trees to understand how orchestrators spawn subagents
  • Read detailed traces of agent runs
  • Track token usage breakdowns and estimated costs
