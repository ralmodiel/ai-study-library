# Running Gemma4-E2B tool calling locally on an iPhone

Melvin Vivas · X post · 2026-09-19 · [Open on X](https://x.com/melvindvivas/status/2101204879188594857)

**Topics:** AI Agents, Tool Use & MCP, LLMOps, Deployment & Monitoring · **Level:** intermediate

## Summary

The creator reports getting tool calling working with Gemma4-E2B running fully on-device on an iPhone. This shows that small open models can now support agent-style tool use on mobile hardware without a cloud API.

## Key points

- Gemma4-E2B is small enough to run locally on an iPhone.
- It supports tool (function) calling on-device, so local mobile agents are possible.
- Running on-device avoids API costs and keeps data private.
