Summary

The creator installed Hermes Agent on a PC with an RTX 3090 to see how it does with local models. It shows that a consumer GPU can be used to run an agent locally.

Key points

  • Hermes Agent can run on a home PC
  • An RTX 3090 (24GB VRAM) can run local models as the agent's backend
  • Local models avoid sending data to cloud providers
