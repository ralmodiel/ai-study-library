Dots in ChatGPT: always-on AI agents that you hand responsibilities to

Summary

A clip of the launch event for Dots, presented by "Sam" (probably Sam Altman, since Dots ships in ChatGPT). Dots are always-on agents inside ChatGPT, powered by a model called Astra. The demo shows a Dot running work and personal tasks for weeks at a time. It is useful for seeing where agent products are heading: each agent gets its own cloud computer and browser, connects to apps through plugins, can be reached by text or phone, and asks a person to approve important actions.

Key points

  • Dots are always-on agents in ChatGPT. You give one an ongoing responsibility (e.g. 'monitor incoming bug reports, test fixes and draft PRs') instead of one-off tasks like booking a ticket.
  • They run on Astra, which the presenter calls 'our most aligned model', and come with built-in protections and safeguards.
  • Each Dot has its own computer and browser in the cloud. It uses the access you give it and can write and test code.
  • Coding example: move an app off a legacy API before it shuts down. The Dot traces dependencies across the codebase, writes the code, runs tests and opens pull requests for the team to review.
  • Dots work with more than 4,000 apps in ChatGPT and reuse the plugins you have already connected (the demo uses Teams, Google Meet notes and Slack).
  • Approval is built in: the Dot checks in when something important needs your sign-off (e.g. a staged rollout). You can limit which apps it uses and what it does on the computer, and customize instructions for its actions.
  • Availability: you start with one Dot, with teams of Dots planned. Texting and phone calls with your Dot are 'coming soon'.
  • The Dot learns how you like to work over time. For example, it reviews what came in overnight and pings you in the morning with anything urgent.
