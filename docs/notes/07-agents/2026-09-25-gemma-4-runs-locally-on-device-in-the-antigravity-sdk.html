Summary

Gemma 4 now runs locally, on-device, inside the Antigravity SDK, powered by LiteRT. You can build fully local or hybrid multi-agent workflows that pair cloud models with a team of Gemma 4 agents. This lets you audit, patch and test code with full data privacy and no API fees.

Key points

  • The Antigravity SDK now supports Gemma 4 running on your own device.
  • LiteRT powers the on-device inference.
  • You can build fully local or hybrid multi-agent workflows that combine cloud models with local Gemma 4 agents.
  • Possible uses are auditing, patching and testing code with total data privacy and zero API fees.
