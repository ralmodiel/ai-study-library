Coworker: Open-Source Work Agent That Runs on Small Local Models

This note summarises a post by Melvin Vivas on X, posted 28 August 2026. The original belongs to Melvin Vivas.

Topics: AI Agents, Tool Use & MCP, LLM Fundamentals, Portfolio Projects · Level: intermediate

Summary

The creator is building Coworker, an open-source AI agent for work tasks. It can run on small local models, for example LFM2.5-2.6B through LM Studio, to create an invoice from a Telegram message. The post lists the stack: Pi for the agent runtime, CopilotKit for the UI, Firecrawl for web search, LM Studio or Ollama for local models, and OpenAI or OpenRouter for cloud models.

Key points

  • Goal: see how far small local models can go on real work tasks, not just chat.
  • Demo: creating an invoice from Telegram with Liquid AI's LFM2.5-2.6B running locally in LM Studio.
  • Agent runtime: Pi (@pidotdev). UI: CopilotKit. Web search: Firecrawl.
  • Local models through LM Studio or Ollama; cloud models through OpenAI or OpenRouter.
  • Trade-off: local models give privacy and zero cost, cloud models give more power.
  • Free and open source, with installers on GitHub releases.
