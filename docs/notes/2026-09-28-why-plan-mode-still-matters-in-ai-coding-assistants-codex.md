Melvin Vivas · X video post · 2026-09-28 · 0:37 · 1,274 views · [Open on X](https://x.com/melvindvivas/status/2104239715520250187)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

This is a short opinion clip. Melvin Vivas pushes back on the idea of removing "plan mode" from AI coding assistants like Codex, Claude Code and Cursor. He argues that even very capable models can change your code when you only meant to ask a question. A read-only planning mode protects against that, and taking away a feature that paying users rely on is frustrating.

## Key points

- Plan mode lets you ask questions or plan work with an AI coding assistant without it changing your files.
- The creator's main argument: smarter models do not remove the risk of unwanted code changes, because a plain question can still lead the agent to update your code.
- He rejects the claim that "models are so intelligent you don't need plan mode anymore" as a reason to remove it.
- His user-side view: he pays for a subscription, depends on the feature, and removing it is frustrating.
- Practical takeaway: when you are only exploring or asking questions, use a planning or read-only mode so the agent does not make edits you didn't want.
- This is an opinion piece with no tutorial or step-by-step instructions.
