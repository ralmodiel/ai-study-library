# OpenAI DevDay 2026 Replay: Timestamped Guide to the Announcements

## Summary

Melvin Vivas shares the replay of his OpenAI DevDay 2026 livestream, with timestamps for each announcement. Highlights are new models and pricing (GPT 6.1 Sol, Pro 500, Pro 200), developer APIs (Decisions API, Agents API), Codex products (Codex Spaces, Codex Cloud, Codex Security Cloud), Sign-in with ChatGPT, Plugin Extensions and the OpenAI Marketplace. It works as an index for jumping straight to the part you care about.

## Key points

- The keynote with Sam starts at 36:06 in the replay.
- Dots, powered by Astra (compared to Grok Bot), is at 37:11. Codex Spaces, where you work alongside Dots, is at 44:00.
- GPT 6.1 Sol (56:16) costs about 1/5th the price of Astra with close to its intelligence. It runs at about 300 tok/s, roughly 8x faster than Astra.
- Plans: Pro 500 gives 25x the usage of Plus (57:20), and Pro 200 is back (57:42).
- Developer APIs: the Decisions API at 58:06 (the creator guesses it answers Jev) and the Agents API at 1:05:02.
- Codex Cloud (1:04:02) runs tasks remotely, so you can close your laptop. Codex Security Cloud follows at 1:04:34.
- Sign-in with ChatGPT lets you use ChatGPT credits in tools like Devin, Hermes and T3Code (1:20:23). Plugin Extensions (1:21:00), the OpenAI Marketplace (1:23:07) and Banked Reset (1:27:12) come after.
