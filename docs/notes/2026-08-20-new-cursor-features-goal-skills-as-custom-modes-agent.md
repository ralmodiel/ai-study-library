## Summary

Cursor released three new agent features. /goal sets a goal for the agent, skills can now be used as custom modes, and you can steer the agent while it runs.

## Key points

- /goal command: give the agent a goal to work toward.
- Skills can now be used as custom modes.
- You can steer the agent while it is working.
- The creator had been waiting a long time for /goal.
