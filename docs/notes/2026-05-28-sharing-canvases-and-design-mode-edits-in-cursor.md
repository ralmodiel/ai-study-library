# Sharing Canvases and Design Mode Edits in Cursor

Melvin Vivas · X video post · 2026-05-28 · [Open on X](https://x.com/melvindvivas/status/2059886717679874095)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Cursor now lets you share canvases and use design mode to make precise, targeted edits inside them. The quoted author built and shared a canvas using a Slack MCP integration together with the Composer 2.5 model.

## Key points

- You can now share Cursor canvases via a link.
- Design mode lets you make precise, targeted edits inside a canvas.
- Works smoothly with the speed of the Composer 2.5 model.
- The example canvas was built and shared using a Slack MCP server.
