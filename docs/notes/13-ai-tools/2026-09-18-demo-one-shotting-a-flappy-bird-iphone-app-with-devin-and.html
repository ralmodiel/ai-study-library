Summary

A 12-second silent demo in which Melvin Vivas builds a Flappy Bird iPhone app with the AI coding agent Devin from one prompt ("one-shotted"). He used Fable 5.1 and Devin's new macOS environment, which he says works well for iOS development. The post shows a result, not a tutorial, so there are no steps or prompts to copy.

Key points

  • Devin (by Cognition) is an autonomous AI coding agent. Here it built a working Flappy Bird iPhone app from a single prompt.
  • The creator says he used 'Fable 5.1' for this run. The post doesn't say what Fable 5.1 is; it may be a model or version option inside Devin.
  • Devin now has a macOS environment. iOS apps need macOS and Xcode to build, so this lets the agent build and run iPhone apps itself.
  • The creator says the new macOS environment is 'really great for iOS development'.
  • A small, well-known game like Flappy Bird is a quick way to test what an agent can build from one prompt.
  • The video has no speech and shows no prompt, settings or code. It is a showcase, not a step-by-step guide.
