# Slack Code: Multiplayer Coding with AI Agents Inside Slack Channels

## Summary

Melvin Vivas reshares Slack's launch demo of Slack Code, which lets you tag a coding agent such as Claude in a Slack channel. Slack then opens a dedicated code channel where the team and the agent build together. The demo walks through the workflow: the right teammates and context are pulled in, code diffs are reviewed and live HTML previews are shown in Slack, the agent opens a PR, and the channel is archived at the end. Melvin's own comment asks whether agents will replace co-workers. The video is mostly a product announcement, but it shows where team-based agentic coding is heading.

## Key points

- Slack Code adds 'code channels', spaces built for teams and AI agents to work on code together inside Slack.
- You tag a coding agent (the demo uses Claude) in a normal channel, and Slack spins up a dedicated code channel for that task.
- The code channel brings in the right teammates and the context from earlier conversations, so the agent can start working right away.
- It's pitched as multiplayer: the whole team steers one agent on one task, instead of one developer working with one agent on their own.
- Developers review code diffs in Slack, and HTML artifacts give live previews without copy-pasting or refreshing.
- At the end, the agent opens a PR, posts a summary back to the main channel, and archives the code channel.
- Launch partners for agents: Anthropic, GitHub, Cognition and Vercel. It was announced at Dreamforce 2026 (#DF26).
- Melvin's point: agents have 'gone full circle', since they now sit in chat channels like co-workers.
