# Async Dev Workflow: Start Cursor Agents from Your Phone, Finish Locally

Melvin Vivas · X post · 2026-07-08 · [Open on X](https://x.com/melvindvivas/status/2074535657196892527)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

The creator describes an asynchronous coding workflow. Before bed, he used the Cursor mobile app to start a cloud agent on a feature request and have it prepare a PR. In the morning, he pulled the branch to his laptop and finished the work locally. He says the Fable model in Cursor gave a merge-ready PR with no rework.

## Key points

- Use the Cursor mobile app to start a background agent when you are away from your laptop.
- Ask the agent whether a feature is possible and to turn it into a PR.
- Review the agent's answer and branch the next morning.
- Pull the agent's branch to your local setup and finish the work there.
- The creator reports that Claude Fable 5 in Cursor produced a merge-ready PR with no rework.
- Takeaway: hand off exploratory feature work to agents asynchronously, then review and finish it yourself.
