Devin Cloud: Cloud Agent Sandboxes on macOS, Linux, and Windows

Summary

Melvin Vivas shows a feature of Devin Cloud he likes: when you start a cloud agent session, you can pick a macOS, Ubuntu Linux or Windows sandbox. He says this helps when you build desktop or iOS apps that need testing on a specific operating system, and claims OpenAI's Codex cloud agent can't do this. The post closes by asking viewers which cloud agents they use.

Key points

  • Devin Cloud can start sandbox environments running macOS, Linux (Ubuntu) or Windows.
  • You choose the environment in the Devin Cloud interface before the agent starts working.
  • Use case: a desktop app you built has to be tested on at least Windows or Mac, so the agent can do that in the matching OS sandbox.
  • iOS apps need a Mac environment, which the macOS sandbox provides.
  • The creator claims OpenAI Codex's cloud agent can't start Mac or Windows sandboxes. That is his comparison and isn't verified here.
  • When choosing a cloud coding agent, check which operating systems its sandboxes support.
