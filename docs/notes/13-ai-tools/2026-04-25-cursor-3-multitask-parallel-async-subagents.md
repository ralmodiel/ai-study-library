# Cursor 3 /multitask: Parallel Async Subagents

Melvin Vivas · X video post · 2026-04-25 · [Open on X](https://x.com/melvindvivas/status/2047863963694903341)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Cursor 3 adds a /multitask command that runs async subagents to work on your requests in parallel instead of putting them in a queue. Messages that are already queued can also be switched to multitask.

## Key points

- Use /multitask in the new Cursor 3 interface.
- It runs async subagents that work on requests in parallel.
- No need to wait for the current run to finish before the next one starts.
- Messages already in the queue can be moved to multitask.
