## Summary

Melvin Vivas shares a Google AI Studio demo with the comment "who needs this". The demo shows the upgraded Vibe Coding experience building real-time multiplayer apps from a single prompt. Two team members prompt for a shared whiteboard and a multiplayer racing game. The AI Studio coding agent builds the backend and the real-time sync, so the finished apps can be shared by link with no manual setup.

## Key points

- Google AI Studio's upgraded Vibe Coding mode can build real-time multiplayer apps from a natural-language prompt.
- Example prompt 1: a collaborative whiteboard with markers, sticky notes and live cursors so users can see each other move.
- Example prompt 2: a multiplayer racing game with a simple track and a lobby system.
- The built-in Coding Agent builds the backend and real-time sync, so there is no manual server or websocket setup.
- You can build several apps at once: start a second app while the agent is still working on the first.
- To collaborate, you send the app link to another person and they join the session live.
- The point is that AI Studio takes care of real-time sync so you can focus on the idea, which makes it good for fast prototypes.
