Summary

The creator recommends Qwen3-TTS-12Hz-1.7B-Base for voice cloning. It does zero-shot cloning from a 10-second reference clip, needs no fine-tuning, and runs locally.

Key points

  • Model: Qwen/Qwen3-TTS-12Hz-1.7B-Base on Hugging Face (1.7B parameters).
  • Zero-shot voice cloning from about a 10-second reference audio clip.
  • No fine-tuning needed to clone a new voice.
  • Can be run locally, with no cloud API required.
