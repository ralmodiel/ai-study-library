# Shipping Features Fast in Cursor with Multiple AI Models

Melvin Vivas · X post · 2026-05-28 · [Open on X](https://x.com/melvindvivas/status/2059880715962171882)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator built 2 feature requests from a beta tester in one day using AI in Cursor. He used Opus 4.7 for the design feature and a GPT model for the other one. He stresses that people still need to check what the AI built.

## Key points

- AI-assisted coding made it possible to ship 2 feature requests in one day.
- Pick a model per task, for example Opus 4.7 for design work and a GPT model for other work.
- Cursor lets you switch between models from different providers.
- People still need to check and verify AI-generated changes.
