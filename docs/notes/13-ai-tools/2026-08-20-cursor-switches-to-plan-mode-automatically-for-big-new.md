# Cursor Switches to Plan Mode Automatically for Big New Features

Melvin Vivas · X post · 2026-08-20 · [Open on X](https://x.com/melvindvivas/status/2090347784696476150)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator notices that Cursor works out the intent of a request and switches to plan mode by itself when asked for a large new feature. Another apparent trigger is a request that is very different from the original conversation.

## Key points

- Cursor switches to plan mode automatically when a request looks like a big new feature.
- Asking for something unrelated to the current conversation also seems to trigger plan mode.
- Plan mode produces a plan before any code is written.
