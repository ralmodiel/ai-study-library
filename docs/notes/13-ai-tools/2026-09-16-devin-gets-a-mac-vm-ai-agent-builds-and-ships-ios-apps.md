# Devin Gets a Mac VM: AI Agent Builds and Ships iOS Apps

Melvin Vivas · X video post · 2026-09-16 · 0:45 · 963 views · [Open on X](https://x.com/melvindvivas/status/2099894857523454458)

**Topics:** AI Dev Tools & Productivity, Industry Trends & Job Market · **Level:** beginner

## Summary

A short product-news post: Melvin Vivas reshares Cognition's announcement that its autonomous coding agent Devin now has its own Mac VM. Devin can now build and test iOS apps in the iOS Simulator, send a screen recording of the result over Slack, and share a TestFlight link so you can install the build. The video has no speech, only music, so all the information comes from the caption.

## Key points

- Devin, the autonomous AI software engineer, now runs on its own macOS virtual machine.
- On the Mac VM it can build and test iOS apps with the iOS Simulator, a job that needs macOS and Xcode.
- Devin can send a screen recording of the running app through Slack so you can check its work.
- Devin can hand you a TestFlight link so you can install and try the build on your own device.
- The trend: coding agents are moving past writing code to running the whole build, test and delivery loop, including mobile apps.
