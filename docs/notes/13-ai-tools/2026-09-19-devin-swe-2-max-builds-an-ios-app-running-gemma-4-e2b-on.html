Devin SWE-2 Max Builds an iOS App Running Gemma 4 E2B On-Device

Summary

Melvin Vivas quote-posts a demo where Devin, Cognition's AI coding agent, used its SWE-2 Max model to build an iOS app that runs Google's small Gemma 4 E2B model locally on an iPhone. He suggests Codex users try it. The post says SWE-2 Max is free for now. The video has no narration, so the lesson is what the demo shows: a coding agent can build a working on-device LLM mobile app.

Key points

  • Devin (Cognition's autonomous coding agent) was asked to build a full iOS app from a prompt.
  • The app runs the Gemma 4 E2B model locally on the iPhone, with no cloud inference.
  • The build used the SWE-2 Max model in Devin, which the post says was free at the time (Sept 2026).
  • Gemma 'E2B' variants are small, edge-sized models built to run on phones and other low-resource devices.
  • The creator frames Devin SWE-2 as an alternative worth trying for people who use OpenAI Codex.
  • The clip has no speech, so it shows no step-by-step build process.
