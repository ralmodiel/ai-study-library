Summary

This is a short progress update on an experiment: swapping faces/heads in video on a local machine at no cost. Melvin Vivas runs the MiniMax H3 Ref2VA model, quantized to INT8, inside ComfyUI, adds a head-swap LoRA, and fits it on one RTX 3090 with VRAM peaking at 23.8 GB. He says the results aren't perfect yet. The post gives no workflow, settings or code. The video has no useful speech.

Key points

  • Goal: run video face/head swapping fully on your own machine, with no API or cloud costs ($0).
  • Model: MiniMax H3 Ref2VA, a reference-to-video model, quantized to INT8 so it uses less memory.
  • Runtime: ComfyUI, a node-based workflow tool for generative models.
  • A head-swap LoRA is added on top of the base model to focus it on swapping heads.
  • Hardware: one RTX 3090 (24 GB), with VRAM peaking at 23.8 GB, which is nearly all of the card's memory.
  • Quality isn't perfect yet; it's a work in progress.
  • The creator says he's working on it together with Grok (xAI's assistant), using an AI chatbot as a helper for the experiment.
  • The post shares no workflow file, LoRA name or settings.
