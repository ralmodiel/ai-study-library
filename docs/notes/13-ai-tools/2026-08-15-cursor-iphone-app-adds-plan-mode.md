**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator notes that Cursor's iPhone app now has Plan mode. He is using it to add LFM2.5-VL-3B support to AIBackends from his phone.

## Key points

- Cursor's iOS app now supports Plan mode, so you can plan agent tasks from your phone.
- Example use: starting work on adding a new model to a project from mobile.
