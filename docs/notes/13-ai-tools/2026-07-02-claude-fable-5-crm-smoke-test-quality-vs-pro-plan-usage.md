# Claude Fable 5 CRM Smoke Test: Quality vs. Pro Plan Usage Limits

Melvin Vivas · X post · 2026-07-02 · [Open on X](https://x.com/melvindvivas/status/2072619720726221036)

**Topics:** AI Dev Tools & Productivity, LLM Fundamentals · **Level:** beginner

## Summary

The creator ran a CRM smoke test with Claude Fable 5. He says it works more like a senior developer than a junior one. The single test used 96% of the session limit on the Claude Pro plan, so heavy use needs a higher tier.

## Key points

- Use a small CRM build as a smoke test for a new coding model.
- The creator says Fable 5's output felt like a senior developer's work.
- One CRM test used 96% of the Pro plan's session limit.
- Heavy agentic coding with this model probably needs a higher plan than Pro.
