## Summary

The creator runs the local open-weight model Qwen3.8-27B inside Codex. It had been working on a single goal for 31 minutes, which shows a local model can handle long autonomous coding tasks.

## Key points

- Codex can be pointed at a local model such as Qwen3.8-27B.
- The model worked on one goal autonomously for 31 minutes and was still going.
- Local models are a way to avoid cloud usage limits.
