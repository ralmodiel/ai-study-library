## Summary

Release announcement for Melvin Vivas's open-source Markdown Editor v1.4.2. It's a lightweight markdown editor with AI editing that works with local models through Ollama and LM Studio.

## Key points

- Lightweight markdown editor with built-in AI editing.
- Works with local LLM runtimes: Ollama and LM Studio.
- Version 1.4.2 is available on the repo's Releases page.
