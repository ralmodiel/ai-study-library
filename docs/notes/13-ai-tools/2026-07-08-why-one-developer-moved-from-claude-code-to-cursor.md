# Why One Developer Moved from Claude Code to Cursor

Melvin Vivas · X post · 2026-07-08 · [Open on X](https://x.com/melvindvivas/status/2074822822388707449)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator says he hasn't opened Claude Code in a while because Cursor's tooling is now better and it offers Claude models anyway. He likes moving between cloud, local and mobile sessions, so he can keep coding wherever he is.

## Key points

- Cursor gives access to Claude models, so you don't lose model quality by leaving Claude Code.
- The creator thinks Cursor's tooling is now stronger than Claude Code's.
- Cursor lets you move a coding session between cloud, local and mobile.
- You can continue agent coding work from anywhere.
