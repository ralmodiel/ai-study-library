# Cursor: Open an Agent's Workspace Directly in the IDE

Melvin Vivas · X post · 2026-07-18 · [Open on X](https://x.com/melvindvivas/status/2078411050731651509)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator points out a new Cursor feature: you can open the workspace an agent is working in straight into the IDE. Before, you had to open that folder by hand.

## Key points

- Cursor can now open an agent's working workspace directly in the IDE
- This removes the manual step of opening the folder yourself
- Makes it quicker to review and edit agent output
