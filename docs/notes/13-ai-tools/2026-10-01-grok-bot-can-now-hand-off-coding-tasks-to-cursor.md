## Summary

News: Grok Bot can now send coding tasks to Cursor. It can also manage PRs through GitHub and Origin plugins and share video demos of what it builds.

## Key points

- Grok Bot can delegate coding tasks to Cursor.
- GitHub and Origin plugins let it manage PRs.
- Bots can share video demos of what they build.
