This is a short post with a 23-second silent video. It points to the Design Mode feature in Cursor 3, the AI code editor. According to the quoted post, Design Mode lets you annotate and select UI elements directly in the browser so you can point the AI agent at a specific part of the interface. The post gives no steps or details beyond that.

Key points

  • Cursor 3 has a feature called Design Mode.
  • Design Mode lets you annotate UI elements and select them directly in the browser.
  • Selecting an element visually tells the AI exactly which part of the UI to change, so you don't have to describe it in words.
  • The video has no narration, and the post doesn't explain how to turn Design Mode on or use it.
