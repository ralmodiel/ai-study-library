Free Local Image Generation: ComfyUI App Mode + LM Studio + Gemma

Summary

The creator describes a fully local, zero-cost image generation setup. ComfyUI's App Mode gives a distraction-free interface, Gemma 4 E2B running in LM Studio makes the prompts more creative, and Z-Image-Turbo generates the images locally.

Key points

  • ComfyUI App Mode hides the node graph so you can focus on creating.
  • A local LLM (Gemma 4 E2B served by LM Studio) rewrites or expands prompts to make them more creative.
  • Z-Image-Turbo generates the images locally.
  • The whole pipeline runs on your own machine, with no API costs.
