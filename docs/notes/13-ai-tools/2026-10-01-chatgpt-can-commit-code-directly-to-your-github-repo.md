**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

A tip that ChatGPT itself, not just Codex, can commit code to a GitHub repository. The creator encourages people to try it.

## Key points

- ChatGPT can commit code to a connected GitHub repo.
- This works in ChatGPT itself, not only in Codex.
- Useful for quick changes without opening a coding agent.
