Why Model Speed Matters in Coding Agents: Codex vs ChatGPT Plans

This note summarises a post by Melvin Vivas on X, posted 9 October 2026. The original belongs to Melvin Vivas.

Topics: AI Dev Tools & Productivity · Level: beginner

Summary

The creator explains that he cancelled ChatGPT Pro because slow GPT models such as GPT-6.1 Sol make the Codex coding harness feel counterproductive. He kept the Plus plan because he still finds ChatGPT the best tool for brainstorming. The takeaway: when you pick a coding agent, latency matters as much as harness quality.

Key points

  • A good agent harness (Codex) can still feel unproductive if the underlying model is slow.
  • The creator found GPT-6.1 Sol too slow for agentic coding workflows.
  • He downgraded from ChatGPT Pro to Plus instead of cancelling entirely.
  • He still rates ChatGPT as the best tool for brainstorming.
  • Pick tools by task: fast models for coding loops, strong chat models for ideation.
