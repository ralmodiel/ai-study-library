Coding from your phone: Grok Bot hands tasks to Cursor Cloud Agents

Summary

Grok Bot does coding by handing tasks to Cursor Cloud Agents, which run remotely. Because of this, you don't need to run Claude Code or Codex on your own machine. You can close your laptop and manage coding work from your phone.

Key points

  • Grok Bot sends coding tasks to Cursor Cloud Agents, which run in the cloud.
  • You don't need a local session of Claude Code or Codex.
  • Because the work runs in the cloud, you can start and check coding tasks from your phone.
