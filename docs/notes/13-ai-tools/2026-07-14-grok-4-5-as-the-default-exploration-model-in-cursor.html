Summary

A short tip: the creator set Grok 4.5 as his default model for codebase exploration in Cursor. It suggests picking different models for different coding-assistant tasks.

Key points

  • Cursor lets you pick a default model for each kind of task
  • The creator uses Grok 4.5 for exploration (understanding and searching code)
  • Think about giving exploration and implementation work to different models
