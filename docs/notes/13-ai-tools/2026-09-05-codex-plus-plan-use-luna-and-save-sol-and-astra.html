Codex Plus Plan: Use Luna and Save Sol and Astra

This note summarises a post by Melvin Vivas on X, posted 5 September 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Topics: AI Dev Tools & Productivity, LLM Fundamentals · Level: beginner

Summary

The creator argues that on the $20 Codex Plus plan, Sol and Astra burn through usage too fast to be practical. Luna should be the default model there. He likes Sol and Astra for speed, but heavy use of them needs a bigger plan like Codex Pro.

Key points

  • Sol and Astra are very capable but expensive in usage.
  • The $20 Codex Plus plan does not go far with Sol or Astra.
  • Plus users should use Luna as the default model.
  • Sol and Astra get things done fast, so they are still worth it on a higher plan.
  • He plans to upgrade to Codex Pro after rebalancing his AI subscriptions.
