**Topics:** AI Dev Tools & Productivity, Portfolio Projects · **Level:** beginner

## Summary

Melvin built a CRM app from a single prompt using Grok Build CLI with Cursor's Composer 2.5 model. He says the design came out pretty good without using any design skill, which shows how capable one-shot app generation has become.

## Key points

- A full CRM app was generated in one shot with Grok Build CLI plus Composer 2.5.
- The UI design was good without any special design skill or prompt add-on.
- A CRM is a good benchmark project for testing coding agents.
