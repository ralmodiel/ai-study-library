Open-Source Markdown Editor with Local and API AI Editing

Summary

Melvin Vivas shares his open-source markdown editor with built-in AI editing. It works with local models through Ollama and LM Studio, and with API models. He calls it a 'Cursor for markdown editing' and is looking for angel investors.

Key points

  • donvito/markdown-editor is a lightweight markdown editor with AI editing.
  • It supports local models (Ollama, LM Studio) and API-based models.
  • The idea is to bring a Cursor-style AI editing experience to markdown documents.
  • The repo is a good example of adding a local LLM to a desktop or web editor.
