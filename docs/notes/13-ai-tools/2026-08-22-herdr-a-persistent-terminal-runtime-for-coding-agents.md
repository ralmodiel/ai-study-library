# Herdr: a persistent terminal runtime for coding agents

Melvin Vivas · X post · 2026-08-22 · [Open on X](https://x.com/melvindvivas/status/2091071429337067773)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

The creator recommends Herdr to developers who like terminal (TUI) coding agents. Herdr is a runtime where coding agents live, on a laptop, a desktop or a rented server. It keeps real terminals open so agent work keeps going after you close the laptop lid.

## Key points

- Herdr is a runtime for terminal-based coding agents.
- It runs on a laptop, a desktop or a rented remote machine.
- It keeps real terminal sessions open, so long-running agent work survives the laptop lid closing.
- Useful for developers who prefer TUI coding workflows.
