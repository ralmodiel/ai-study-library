Summary

Melvin Vivas shows jsonl-viewer, an open-source tool he built for viewing agent traces. According to the post, it finds trace files from Codex, Claude Code, Pi and Hermes on its own and updates the view live while the agents run. The repo started as a viewer and editor for .jsonl fine-tuning and training datasets. It's useful for inspecting what coding agents actually do step by step.

Key points

  • Coding agents such as Codex, Claude Code, Pi and Hermes save their session traces as JSONL logs that you can inspect.
  • jsonl-viewer finds these traces automatically, so you don't have to look for log files by hand.
  • The view updates live, so you can watch an agent's steps (messages, tool calls) while it runs.
  • The repo's own description says it also views and edits .jsonl files used for fine-tuning and training datasets.
  • Reading agent traces helps you debug agent behavior and understand how coding agents use context and tools.
