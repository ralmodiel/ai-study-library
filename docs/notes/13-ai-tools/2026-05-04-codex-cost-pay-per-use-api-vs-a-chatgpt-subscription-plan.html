Codex Cost: Pay-per-Use API vs a ChatGPT Subscription Plan

This note summarises a post by Melvin Vivas on X, posted 4 May 2026. The original belongs to Melvin Vivas.

Summary

The creator ran OpenAI's Codex coding agent on pay-per-use OpenAI API billing for about 2 hours and found it very expensive. He says a subscription plan is much better value for long agentic coding sessions.

Key points

  • Running Codex on per-token OpenAI API billing got very expensive after about 2 hours of work.
  • For heavy agentic coding, a flat-rate subscription plan is better value than API billing.
  • Agent loops use many tokens, so watch costs before running long sessions on API keys.
  • The creator says not to repeat the experiment; he only did it out of curiosity.
