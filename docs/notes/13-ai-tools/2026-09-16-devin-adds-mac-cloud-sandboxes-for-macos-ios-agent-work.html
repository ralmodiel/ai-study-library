Devin Adds Mac Cloud Sandboxes for macOS/iOS Agent Work

Summary

Melvin Vivas points to Cognition's announcement that Devin can now run in macOS cloud sandboxes. He says that, as far as he knows, it is the only agent harness that does this, which makes it useful for macOS/iOS development and for testing apps on a real Mac.

Key points

  • Devin, the AI coding agent from Cognition, now supports Mac cloud sandboxes.
  • The creator says Devin is the only agent harness with Mac cloud sandboxes.
  • Use case: building macOS and iOS apps with an agent.
  • Use case: having the agent test apps inside a Mac environment.
  • Details are in the 'Bringing macOS to Devin' blog post.
