Summary

Cursor has launched Origin, a code hosting platform that it describes as fast, easy to use and deeply integrated with the Cursor editor. You get started by syncing your repositories from GitHub. The creator plans to move his code over from GitHub.

Key points

  • Origin is Cursor's new code hosting platform and is now live.
  • Cursor describes it as fast, easy to use and deeply integrated with the Cursor editor.
  • Onboarding works by syncing your existing repos from GitHub.
  • It is a possible alternative or backup to GitHub; the creator used it during a GitHub outage.
