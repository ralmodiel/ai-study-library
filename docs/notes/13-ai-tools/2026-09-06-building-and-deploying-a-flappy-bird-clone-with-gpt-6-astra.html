Summary

Melvin Vivas shows a full Flappy Bird game he built with OpenAI's GPT-6 Astra model inside Codex. He says it fit within his 5-hour usage limit, and Codex also deployed the game to ChatGPT sites as a live web page. It's a short demo of an AI coding agent going from prompt to a hosted game, not a step-by-step tutorial.

Key points

  • The model used was GPT-6 Astra, run inside OpenAI's Codex coding agent.
  • A complete Flappy Bird game was built within one 5-hour Codex usage window.
  • Codex also handled deployment: the game was published to ChatGPT sites (a *.chatgpt.site subdomain).
  • The result is playable at flappy-bird-arcade.donvitocodes.chatgpt.site, titled 'Flappy Bird — Pocket Arcade'.
  • A small, well-known game like this is a good way to test what a coding agent can build and deploy in one session.
  • The post doesn't share prompts, code or workflow steps, so it shows what's possible rather than how to do it.
