Summary

The creator recommends herdr, a tool that brings several coding agents (Pi, Codex, Claude Code and others) together in one terminal, so you can manage many agents from one place.

Key points

  • herdr lets you run several coding agents in one terminal.
  • Supported agents include Pi, Codex and Claude Code.
  • It is useful if you switch between several AI coding assistants.
