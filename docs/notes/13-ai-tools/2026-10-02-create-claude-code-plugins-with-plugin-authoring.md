## Summary

A tip from Edwin Arbus: you can use the /plugin-authoring command in Claude Code to create plugins (mods) without learning the plugin format first.

## Key points

- Run /plugin-authoring inside Claude Code to create plugins (mods).
- You don't need to learn the plugin format beforehand; the command guides you.
