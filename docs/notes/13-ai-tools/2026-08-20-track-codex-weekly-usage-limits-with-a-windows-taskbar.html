Summary

Melvin Vivas shares an open-source Windows taskbar widget that shows how much of your OpenAI Codex usage limit is left. It's useful for anyone on Windows who keeps hitting Codex's weekly limits and wants to see usage at a glance.

Key points

  • geocine/codex-window-taskbar is a native Windows taskbar widget that shows Codex usage.
  • It lets you watch your Codex weekly limit without opening the app.
  • It only works on Windows.
  • Jokingly suggests turning it off once you hit 0% remaining.
