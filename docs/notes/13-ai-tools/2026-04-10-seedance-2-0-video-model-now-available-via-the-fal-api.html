Summary

ByteDance's Seedance 2.0 video model is now available through an API on fal, with no access restrictions. The fast image-to-video endpoint is linked, so developers can call it from code.

Key points

  • Seedance 2.0 (ByteDance) can now be called through an API on fal.ai.
  • The quoted post says it is open to everyone with no restrictions.
  • Endpoint: bytedance/seedance-2.0/fast/image-to-video.
