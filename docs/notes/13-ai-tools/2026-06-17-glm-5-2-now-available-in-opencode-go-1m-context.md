# GLM 5.2 Now Available in OpenCode Go (1M Context)

Melvin Vivas · X post · 2026-06-17 · [Open on X](https://x.com/melvindvivas/status/2067225371746173245)

**Topics:** AI Dev Tools & Productivity, LLM Fundamentals · **Level:** beginner

## Summary

A heads-up for OpenCode users: GLM-5.2 is now available in OpenCode Go. It is text-only, has a 1M-token context window and costs the same as GLM 5.1.

## Key points

- GLM-5.2 is available in OpenCode Go.
- Text-only model with a 1M-token context window.
- Same price as GLM 5.1, so it's a free upgrade for existing users.
