## Summary

This is a short demo post with no narration. Melvin Vivas shows the Devin AI coding agent testing his open-source desktop app, Coworker, on Windows. Devin records each test run so he can replay the recordings and check the results himself. Coworker is a desktop app where AI agents do work for you, and it supports both local and cloud models.

## Key points

- Devin (@DevinAI) is an autonomous AI software engineering agent that can run QA tests on a desktop app, here on Windows.
- Devin saves recordings of its test sessions, so a person can replay them and confirm the agent's results instead of trusting it blindly.
- Coworker (github.com/donvito/coworker) is an open-source desktop app where AI agents do tasks for you.
- Coworker supports both local and cloud LLMs.
- Workflow pattern: hand cross-platform testing to an agent, then review the recorded evidence yourself.
