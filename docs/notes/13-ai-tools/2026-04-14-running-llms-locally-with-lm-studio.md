**Topics:** AI Dev Tools & Productivity, LLM Fundamentals · **Level:** beginner

## Summary

The creator says running LLMs locally is underrated because you can experiment for free. LM Studio is his default for text models. He likes its LM Link feature and says developer mode makes API integrations easy.

## Key points

- Local LLMs let you experiment without paying API costs.
- LM Studio is the creator's default app for local text models.
- LM Link is one reason he chooses LM Studio.
- Developer mode serves local models through an API, which makes them easy to plug into your own apps.
