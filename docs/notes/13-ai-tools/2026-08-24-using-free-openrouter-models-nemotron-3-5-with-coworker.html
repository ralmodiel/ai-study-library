Summary

Shows Coworker running a free model from OpenRouter, in this case NVIDIA's Nemotron 3.5. It's a way to try agent workflows without paying for API calls.

Key points

  • OpenRouter offers free models that work with Coworker.

  • Free models let you experiment with agents at no cost.
