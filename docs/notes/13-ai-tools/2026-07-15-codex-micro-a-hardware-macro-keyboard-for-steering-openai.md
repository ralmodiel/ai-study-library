# Codex Micro: A Hardware Macro Keyboard for Steering OpenAI Codex

## Summary

Melvin Vivas jokingly quotes an OpenAI promo for the "Codex Micro" (kbd-1.0-codex-micro), a small macro keyboard made with Work Louder for controlling the Codex coding agent. His comment asks how many "Codex resets" it comes with. The demo builds a browser word game using only the device. Along the way it shows Codex workflow features: voice dictation, plan mode, a reasoning-effort setting, pinned parallel tasks, permission approvals and customizable skill shortcuts.

## Key points

- The Codex Micro is a programmable keyboard built by OpenAI with Work Louder. It has keys, an analog stick and a dial, and you buy it from openai.com.
- You hold a key to dictate prompts to Codex by voice, so you don't need your laptop keyboard.
- By default, swiping the analog stick up turns on Codex plan mode. You can also map the stick to the skills you use most.
- The dial changes reasoning effort, so you can switch between quick tasks and deeper reasoning without breaking your flow.
- Each pinned Codex task maps to its own key. You press a key to switch tasks and can see at a glance what's running or needs attention. If the app is in the background, a double-tap shows what needs attention.
- When Codex asks for permission to run something, you can approve it from the device.
- Every control can be remapped to Codex actions, such as skills, creating a pull request or triggering your 'pet'.
- Demo prompt: build a browser game called 'One Letter Off'. Players turn 'cold' into 'warm' by changing one letter at a time, with a 30-second timer, streaks and tile animations. A follow-up prompt adds a punchier win state and a streak counter.
