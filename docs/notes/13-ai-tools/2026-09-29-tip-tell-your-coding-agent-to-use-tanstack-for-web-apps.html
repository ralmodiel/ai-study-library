Summary

A quick productivity tip: when an AI coding agent builds a web app, tell it to use TanStack. The creator says builds are much faster this way.

Key points

  • Name the framework in your prompt instead of letting the agent choose
  • The creator recommends TanStack for agent-built web apps
  • He reports noticeably faster builds with TanStack
