## Summary

Claude Code tasks can now keep running in the cloud when you close your laptop. This means you no longer need workarounds to keep your machine awake during long agent runs.

## Key points

- Claude Code tasks can keep running after you close your laptop.
- This comes from Claude Code cloud sessions, announced by the Claude devs account.
- Long agent runs no longer need your local machine to stay awake.
