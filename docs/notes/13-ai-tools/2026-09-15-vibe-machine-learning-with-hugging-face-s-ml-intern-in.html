Summary

This is a short post with a silent video. It introduces ML Intern, which the quoted post calls a harness for AI building: it does for building ML/AI solutions what Claude Code and Cursor do for software development. ML Intern is now built into HuggingChat, so you describe an AI use case in plain language and the agent handles the work. Melvin Vivas calls this "Vibe Machine Learning" and says it's a good way to get started and to learn new things along the way.

Key points

  • "Vibe Machine Learning" means describing an ML/AI goal in plain language and letting an agent build the solution, much like vibe coding.
  • ML Intern is described as being to AI building what Claude Code and Cursor are to software development.
  • The ML Intern harness is now fully built into HuggingChat (hf.co/chat).
  • How it works: bring an AI use case and ask for it. The agent does the ML work.
  • The creator recommends it as a beginner-friendly starting point and as a way to learn new ML techniques by watching what the agent does.
