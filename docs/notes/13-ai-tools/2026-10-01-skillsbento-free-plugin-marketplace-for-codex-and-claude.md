# SkillsBento: Free Plugin Marketplace for Codex and Claude Code

Melvin Vivas · X post · 2026-10-01 · [Open on X](https://x.com/melvindvivas/status/2105560043395707354)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

Melvin Vivas announces SkillsBento, a free, open-source plugin marketplace for agent skills. You add it once to Codex or Claude Code, then install new plugins as he publishes them. The first plugin available is 'Devil's Advocate'.

## Key points

- SkillsBento is a plugin and skills marketplace that works with both OpenAI Codex and Claude Code.
- You only add the marketplace once in your coding agent. After that, you can download new plugins as they come out.
- The 'Devil's Advocate' plugin can already be downloaded.
- The source is open on GitHub at donvito/skillsbento, and the website is skillsbento.com.
- Plugin marketplaces are a way to share reusable agent skills across coding assistants.
