# Running Codex Inside a Runpod GPU Instance

Melvin Vivas · X post · 2026-09-03 · [Open on X](https://x.com/melvindvivas/status/2095429834000445886)

**Topics:** AI Dev Tools & Productivity, LLMOps, Deployment & Monitoring · **Level:** intermediate

## Summary

The creator runs the Codex coding agent directly inside a Runpod GPU instance. He says this makes it easier to set up Python and run local models. He also recommends herdr.

## Key points

- Run a coding agent (Codex) on the GPU box itself to handle Python environment setup.
- This makes running local models on cloud GPUs easier.
- herdr is recommended as a useful tool ("herdr rocks!").
