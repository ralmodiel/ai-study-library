Summary

Melvin Vivas shares OpenAI's announcement that Codex is now in preview inside the ChatGPT mobile app for iPhone and Android. From your phone you can start new Codex tasks, review outputs, steer execution and approve next steps. The work itself keeps running on your own machine (laptop, Mac mini or devbox) through the Codex desktop app, which is Mac-only for now.   • Codex is now in preview inside the ChatGPT mobile app on both iPhone and Android.
  • The mobile app connects to the Codex desktop app; Melvin notes this is Mac-only right now.
  • From mobile you can start new work, review outputs, steer execution and approve next steps.
