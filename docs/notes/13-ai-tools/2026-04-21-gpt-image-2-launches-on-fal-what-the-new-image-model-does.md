## Summary

This is a 15-second, silent video post from Melvin Vivas. It shares fal's announcement that OpenAI's GPT Image 2 image-generation model was available on fal from day 0. The quoted post names four strengths: rendering text inside images, following layouts and UI designs, making edits that change only what you ask for, and producing realistic everyday photos. It's a quick product-news update with no tutorial.

## Key points

- GPT Image 2 was available on fal, a generative-media platform, on launch day ("day 0"). Posted 2026-04-21.
- Strength 1: strong text rendering. It can put readable text in images, which helps with posters, ads and mockups.
- Strength 2: it follows layouts and UI designs more closely, so it's useful for generating UI mockups and structured designs.
- Strength 3: cleaner "preserve-and-change" edits. It changes only the part you ask for and keeps the rest of the image the same.
- Strength 4: strong photorealistic results for everyday scenes.
- Lesson: new models often appear on hosted inference platforms like fal at launch, so you can try them through an API without hosting anything yourself.
