# Codex Record & Replay: Turn a Demonstrated Workflow into a Reusable Skill

Melvin Vivas · X video post · 2026-06-18 · 2:04 · 100 views · [Open on X](https://x.com/melvindvivas/status/2067689694159356081)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Melvin Vivas shares a demo of Codex's Record & Replay feature. You do a recurring task once while Codex watches, and Codex turns the recording into a skill you can inspect and edit. The example is publishing a YouTube video: Codex learns where the metadata is kept, how the asset package is organized and which upload settings to use, then repeats the whole process for a new video in a fresh thread. Later runs can use computer use, browser use, connected plugins, or a mix of them.

## Key points

- Record & Replay: show Codex a recurring task once and it turns the demo into a skill you can inspect and edit.
- You decide when recording starts and stops.
- Example workflow: pull metadata (title, description) from a publishing spreadsheet, find the matching assets, add the thumbnail and English captions in YouTube Studio, then save the video as private.
- After recording, Codex reviews the demo and saves what it learned in the skill: where the metadata lives, how the upload package is organized, and how to add captions, save and verify.
- To reuse it, open a fresh thread, attach the next video package and ask Codex to handle it. Codex matches the package to the right spreadsheet row, fills in the fields, uploads and checks that everything saved.
- When it runs a skill, Codex can use computer use, browser use, your connected plugins, or a combination of them.
- Other uses mentioned: formatting and sharing pull requests, or setting up calendar invites the way you like.
- Showing the workflow once means you don't have to write out every step and preference in a prompt.
