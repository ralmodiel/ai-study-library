Summary

The creator says he uses Devin CLI as his own system administrator, running it on the free SWE-2 model. The point is that a terminal coding agent can do server and machine admin work, not only coding.

Key points

  • Devin CLI is a terminal-based coding agent that can run system administration tasks.
  • The creator runs it with the SWE-2 model, which he says is free to use.
  • Coding agents in the CLI can stand in for manual sysadmin work (setup, config, troubleshooting).
