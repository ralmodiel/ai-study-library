Remote-control Codex and Claude Code in WSL from your phone

This note summarises a post by Melvin Vivas on X, posted 3 October 2026. The original belongs to Melvin Vivas.

Topics: AI Dev Tools & Productivity, Fine-tuning & Model Customization · Level: intermediate

Summary

The creator explains how to start remote-control sessions for Codex and Claude Code in a WSL terminal, then connect to them from the phone apps. His WSL setup already has llama.cpp and Unsloth, so he plans to train models from his phone while he's out.

Key points

  • Codex: run codex remote-control start / pair in the terminal (commands as written in the post)
  • Claude Code: run claude --rc to enable remote control (as written in the post)
  • Then connect from the Codex or Claude Code phone app to the running session
  • This works inside WSL on Windows, where his local ML tools (llama.cpp, Unsloth) are installed
  • Use case: start and watch fine-tuning jobs from your phone while away
