Summary

Shows a workflow where you install the Google Colab plugin in Cursor. You edit notebook code locally in Cursor but run it on a Colab GPU instance, so you get both a local AI-assisted editor and free cloud GPUs.

Key points

  • Install the Colab plugin inside the Cursor editor
  • Write and edit notebook code locally in Cursor
  • Run the code on a Google Colab GPU instance
  • Useful for ML work when your own machine has no GPU
