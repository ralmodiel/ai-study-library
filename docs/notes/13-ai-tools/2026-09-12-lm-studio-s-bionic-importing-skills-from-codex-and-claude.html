Summary

Bionic is a new interface from LM Studio. It can import Skills from Codex, Claude Code and other agents, and it lets you chat and code right away. The creator prefers it to LM Studio's classic interface.

Key points

  • Bionic is a new interface from LM Studio.
  • It has a Skills importer for skills from Codex, Claude Code and other agents.
  • You can reuse agent skills you already have without rewriting them.
  • The new interface lets you chat and code right away, unlike the classic one.
