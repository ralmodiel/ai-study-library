Summary

The creator gave Devin's iOS app the same kind of task on three models (Opus 5.5, GPT-6.1 Sol and SWE-2) to compare them. He says onboarding to the app was smooth. Running one task across several models is a simple way to see which works best for you.

Key points

  • Run the same or similar tasks across several models to compare them directly.
  • Models compared: Opus 5.5, GPT-6.1 Sol and SWE-2.
  • Devin's iOS app lets you start agent tasks from your phone.
  • Onboarding to the Devin iOS app was smooth.
