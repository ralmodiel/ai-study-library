# herdr 0.9.0: Control Agents Across Multiple Machines

Melvin Vivas · X video post · 2026-09-08 · [Open on X](https://x.com/melvindvivas/status/2097306208474636329)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

The creator shares the herdr 0.9.0 release. Its main new feature is a single client that connects to every machine running herdr. You can manage coding agents and projects on local and remote machines without switching between terminal tabs.

## Key points

- herdr 0.9.0 connects all your machines running herdr to one client.
- You can control agents and projects on both local and remote machines.
- This removes the need to jump between terminal tabs to manage agents.
