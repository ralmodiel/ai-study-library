Workshop AI: Building Apps with Cloud and Local Agents (GLM 5, Qwen 3.5)

Summary

This is a reshared launch demo for Workshop AI, an agentic tool that builds apps. You can use it in the browser (Workshop Cloud) or on your own computer (Workshop Desktop). The demo starts a social media post generator in the cloud using OpenAI for text and Google's Nano Banana for images. It then finishes the same project offline with a local model. Melvin Vivas adds that Workshop Desktop also works offline with the open models GLM 5 and Qwen 3.5. The video is mostly a product launch, but it shows a useful pattern: build in the cloud, then keep developing with a local model.

Key points

  • Workshop AI has two parts: Workshop Cloud runs in the browser with its own compute environment, and Workshop Desktop lets agents use your own computer.
  • On Desktop you can use frontier models or run local models (the post names GLM 5 and Qwen 3.5) offline, privately and with no usage limit.
  • A built-in hub connects agents to AI models, databases and tools, so you don't have to set up separate provider accounts.
  • Agents pull in relevant 'skills' as needed, such as front-end design, Stripe for payments or Salesforce for CRM.
  • Cloud agents can browse the web, run code, analyze data and visualize results. Workshop also handles research tasks and can import existing projects.
  • Workflow shown: describe the app, build it in the cloud, publish it with access limited to your team, download the project to Desktop, then add features with a local model.
  • Launch offers: $250k in Gemini AI credits (including Nano Banana) given away, free app hosting for the first month, and free unlimited local AI on Desktop.
