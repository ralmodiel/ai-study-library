Summary

This is a 40-second video with no speech, captioned "Claude Claw." It quotes an announcement of Dispatch, a research-preview feature in Claude Cowork. Dispatch gives you one ongoing conversation with Claude that runs on your own computer. You send it tasks from your phone and come back later to finished work. The post teaches very little; it mainly points to the feature and how to set it up.

Key points

  • Dispatch is a new research-preview feature inside Claude Cowork.
  • It is one persistent conversation with Claude that runs on your own computer, not only in the cloud.
  • You message it from your phone and come back later to finished work, so it works like an asynchronous agent.
  • Setup: download Claude Desktop, then pair it with your phone. The quoted caption is cut off at this step.
  • The caption 'Claude Claw' seems to compare Dispatch to always-on personal agents you message remotely. The post doesn't explain this, so it's an interpretation.
  • The video has no narration, so the caption is the only information.
