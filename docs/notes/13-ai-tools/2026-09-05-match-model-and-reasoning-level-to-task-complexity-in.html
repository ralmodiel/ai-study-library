Match Model and Reasoning Level to Task Complexity in Coworker

This note summarises a post by Melvin Vivas on X, posted 5 September 2026. The original belongs to Melvin Vivas.

Summary

While building a headless mode for Coworker, the creator runs GPT-6 Astra on its low reasoning setting so his usage limits last longer. He switches to the cheaper Luna model when a task is simpler. The takeaway is to route each task to a model tier based on how hard it is.

Key points

  • The creator is building a headless (non-interactive) mode for Coworker.
  • He uses GPT-6 Astra on the 'low' reasoning setting to make usage last longer.
  • He deliberately switches to Luna for simpler tasks.
  • Matching the model and reasoning effort to the task saves cost and quota.
