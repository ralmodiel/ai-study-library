Summary

When you use 'Sign in with ChatGPT' in a supported app such as Pi, you can set usage limits for each connected app separately. The creator guesses that these limits share the same usage pool as Codex, but he has not confirmed this.

Key points

  • Supported third-party apps such as Pi offer a 'Sign in with ChatGPT' option.
  • You can control usage limits separately for each connected app.
  • The creator assumes, without confirming, that this usage is shared with Codex limits.
