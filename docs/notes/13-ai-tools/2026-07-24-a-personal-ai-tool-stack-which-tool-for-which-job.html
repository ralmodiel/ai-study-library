A Personal AI Tool Stack: Which Tool for Which Job

This note summarises a post by Melvin Vivas on X, posted 24 July 2026. The original belongs to Melvin Vivas.

Melvin Vivas · X post · 2026-07-24 · Open on X

Topics: AI Dev Tools & Productivity · Level: beginner

Summary

The creator lists the AI tools he uses and what he uses each one for. It is an example of picking a different tool for each kind of task instead of using one assistant for everything.

Key points

  • Cursor: coding.
  • Hermes: personal AI agent.
  • Codex: building apps quickly ('killing apps').
  • ChatGPT: writing tweets.
  • Claude: writing prompts.
