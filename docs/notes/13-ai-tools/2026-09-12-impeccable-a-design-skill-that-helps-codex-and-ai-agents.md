## Summary

The creator asked what design skill to use with Codex, and Impeccable was suggested most often. Impeccable describes itself as 'the missing design vocabulary for agents': a design language that makes your AI coding harness better at UI and design work. It is open source on GitHub.

## Key points

- When the creator asked which design skill to pair with Codex, Impeccable came up most often.
- Impeccable gives AI coding agents a design vocabulary so the UI they generate is better.
- It is open source (GitHub: pbakaus/impeccable) and has a website at impeccable.style.
- The creator plans to test it over the next few days, so it is still being evaluated and not yet a proven recommendation.
