Cursor Adds App Creation, Code Storage with Origin, and Vercel Deploys

Summary

This is a short news post with no narration. It says Cursor can now create new web apps from scratch, store the code with Origin, and deploy straight to Vercel. That puts Cursor in the same space as Vercel's v0 app builder.

Key points

  • Cursor can now start new web apps, not just edit existing codebases.
  • Generated code can be stored with Origin, which the post names as the code-storage step.
  • Apps can be deployed directly to Vercel from this workflow.
  • The creator's take is that 'Cursor just became v0', meaning Cursor now competes with Vercel's v0 prompt-to-app builder.
  • The workflow is: create in Cursor, store with Origin, then deploy to Vercel.
