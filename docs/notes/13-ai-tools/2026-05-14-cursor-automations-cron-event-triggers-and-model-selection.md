# Cursor Automations: Cron, Event Triggers and Model Selection

Melvin Vivas · X post · 2026-05-14 · [Open on X](https://x.com/melvindvivas/status/2054807567965327699)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

Short announcement that Cursor now has Automations. You can schedule them with cron or start them from events, and you can pick which model runs them. This lets you run agent tasks without a person starting each one.

## Key points

- Cursor Automations can run on a cron schedule.
- Automations can be started by event triggers.
- You can choose which model runs an automation.
- The feature is at cursor.com/automations and needs a sign-in.
