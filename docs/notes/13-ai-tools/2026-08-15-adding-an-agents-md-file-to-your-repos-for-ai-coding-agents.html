Summary

The creator praises open-source projects that include an AGENTS.md file in their repos. These projects accept that people now write code with AI, and the file gives coding agents instructions for working in the project.

Key points

  • AGENTS.md is a file in the repo that tells AI coding agents how to work with the project.
  • Shipping one shows a project expects AI-assisted contributions.
  • Good things to include: build/test commands, code conventions and project structure.
