**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

Melvin Vivas says Cursor's cloud environments are free and he uses them a lot to build simple apps like websites. For him, the big change is the cloud agent's computer use plus screenshot and video previews, which let him review work without ever downloading the code to his laptop.

## Key points

- Melvin says Cursor cloud environments are free to use.
- They work well for simple apps such as websites.
- Computer use, screenshots and video previews let you review the agent's work visually.
- You can build and iterate on websites without cloning the code to your local machine.
