Summary

The creator recommends an open-source Windows taskbar widget, codex-window-taskbar, that shows how much of your Codex weekly usage limit is left. It's useful if you use Codex heavily on Windows.

Key points

  • codex-window-taskbar by geocine shows Codex weekly limit usage in the Windows taskbar
  • It's useful for anyone who uses Codex heavily on Windows
  • Tongue-in-cheek tip: turn it off when you reach 0%
