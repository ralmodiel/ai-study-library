Cursor CLI and Grok both use the 'agent' command name

This note summarises a post by Melvin Vivas on X, posted 18 August 2026. The original belongs to Melvin Vivas.

Summary

The creator says Cursor CLI and Grok both run with the same 'agent' alias, so they clash in the terminal. The general lesson is that AI coding CLIs can claim the same command name, and you need to rename or re-alias one to use both. The post does not explain how to fix it.

Key points

  • Cursor CLI and Grok both use the 'agent' alias to run, so the two clash.
  • When you install several AI coding CLIs, check whether they use the same command name.
  • Usual fix (not described in the post): give one tool its own shell alias or wrapper script, or change which one comes first on your PATH.
