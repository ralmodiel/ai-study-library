# Request for Claude Code to support AGENTS.md

Melvin Vivas · X post · 2026-06-16 · [Open on X](https://x.com/melvindvivas/status/2066819068783653280)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

The creator argues that Claude Code should read AGENTS.md, a shared convention for giving coding agents project instructions. At the time Claude Code used its own CLAUDE.md file. This points to the value of agent instruction files that work across tools.

## Key points

- AGENTS.md is a shared format for instructions given to AI coding agents.
- Claude Code uses its own file, CLAUDE.md, for project context.
- Using one shared instruction file avoids keeping a separate copy for each tool.
