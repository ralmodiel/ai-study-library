## Summary

The creator quotes Cursor's announcement that a fast mode for Claude Opus 4.7 is now available in Cursor, and says you don't need Claude Code. Fast mode is 2.5x faster but costs 6x as much, and Cursor recommends standard speed for most tasks.

## Key points

- Claude Opus 4.7 fast mode is available inside Cursor.
- Fast mode is 2.5x the speed at 6x the cost.
- Cursor's own advice is to use standard speed for most tasks.
- The creator's view: you can use Cursor for Opus instead of Claude Code.
