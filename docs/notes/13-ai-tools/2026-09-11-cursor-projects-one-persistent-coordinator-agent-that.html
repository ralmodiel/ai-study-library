Cursor Projects: One Persistent Coordinator Agent That Manages Subagents

Summary

Melvin Vivas shares Cursor's launch video for Projects, a new way of working in the Cursor code editor. Instead of opening a new chat for every task, you work in one long-running thread with a coordinator agent. That agent runs on its own computer, hands work to fleets of subagents, reacts to events like Slack messages and GitHub PRs, and remembers your preferences over months. The video shows a shift from micromanaging single agents to working with something closer to an autonomous coworker.

Key points

  • Projects replaces one-chat-per-task with a single persistent thread run by a coordinator agent.
  • The coordinator agent is always on, runs on its own computer, and manages fleets of subagents for you.
  • It learns your habits over time. For example, after a PR is opened it automatically runs the simplification step and other skills you asked for before.
  • It can react to Slack messages and GitHub PRs and can run cron (scheduled) jobs.
  • There is no onboarding wizard. You set things up through normal chat, and the setup scales.
  • One user in the video says some of his projects run thousands of agents.
  • Cursor's internal figures: Projects users merge about 6x more PRs per week, and merge rates rise about 30% in the first week.
  • The broader shift: from micromanaging individual agents to supervising an autonomous, long-lived agent coworker.
