Summary

First impressions of xAI's Grok Build CLI coding agent. Melvin says it feels more like opencode than Claude Code or Codex. Paired with Cursor's Composer 2.5 model, it gave pretty decent output.

Key points

  • Grok Build CLI is a terminal coding agent.
  • Its interface and feel are closer to opencode than to Claude Code or OpenAI Codex.
  • You can run it with Cursor's Composer 2.5 model, which gave decent results.
