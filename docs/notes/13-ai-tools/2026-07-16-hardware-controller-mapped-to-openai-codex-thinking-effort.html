Summary

This is a 22-second demo with almost no teaching content. Melvin Vivas shows a Sound Voltex rhythm-game controller (FAUCETWO) mapped to OpenAI Codex, with its knobs used to adjust the model's thinking (reasoning) effort. He quotes an OpenAI Devs post about "Codex Micro." The only spoken line is a sample prompt to Codex: "Is there any dependencies in this project?"

Key points

  • OpenAI Codex lets you adjust the model's thinking (reasoning) effort. More effort usually means deeper answers but more time and cost.
  • The creator mapped a Sound Voltex controller (FAUCETWO) to Codex and uses its physical knobs to change thinking effort, which he says works "way better for Codex."
  • The post quotes an OpenAI Devs announcement about "Codex Micro." The caption doesn't explain what Codex Micro is.
  • Example prompt shown: asking Codex whether a project has any dependencies, a quick way to get to know an unfamiliar codebase.
  • There's no tutorial or setup guide for the controller mapping. Treat this as inspiration only.
