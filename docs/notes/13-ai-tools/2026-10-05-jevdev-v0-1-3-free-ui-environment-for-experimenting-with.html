Summary

Melvin Vivas released v0.1.3 of JevDev, his free, open-source development environment for the Jev model by TypeSafe AI. This release fixes the experiments feature so it works again and adds some quality-of-life updates to projects.

Key points

  • JevDev is a free UI tool for experimenting with the Jev model from TypeSafe AI.
  • v0.1.3 fixes the experiments feature, which can now be used.
  • The release also adds quality-of-life improvements to projects.
  • The source is on GitHub at donvito/jev-dev.
