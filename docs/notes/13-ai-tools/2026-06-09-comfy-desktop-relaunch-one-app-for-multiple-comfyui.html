Summary

Melvin Vivas reshares Comfy's announcement of the rebuilt Comfy Desktop app with a short "gotta try" comment. According to the quoted post, the app was rebuilt from scratch, keeps your existing workflows, custom nodes, models and settings, and can run multiple ComfyUI instances. The item offers little teaching. It is mainly a pointer to a new tool for image and video generation.

Key points

  • Comfy Desktop has been rebuilt from scratch as 'one app for every Comfy'.
  • Existing ComfyUI workflows, custom nodes, models and settings carry over unchanged.
  • It keeps the same name but is a completely new app.
  • New feature: you can run multiple ComfyUI instances from the one desktop app (the caption is cut off before the details).
