Summary

Argues that Codex Desktop is more than a coding tool and is becoming a close competitor to Claude Cowork. Besides coding, it now works with your files and has memory, so the creator suggests using it instead of ChatGPT.

Key points

  • Codex is growing beyond coding into a general assistant.
  • It now supports working with your local files.
  • It now supports memory.
  • The creator sees it as a close competitor to Claude Cowork.
