Summary

Melvin Vivas quotes Cognition's announcement that Devin, its autonomous AI software engineer, now runs on a Mac. That lets it build, test and deploy iOS, iPadOS and macOS apps in the cloud from a single prompt. Vivas reacts by renewing his Apple developer account, which suggests he plans to try it. This is a short news item about AI coding agents expanding into native Apple app development.

Key points

  • Cognition says Devin now has access to a Mac, so the agent can handle native Apple-platform development.
  • Devin can build, test and deploy iOS, iPad and macOS apps in the cloud from just a prompt.
  • Cognition shared 11 experiments run over one week, plus open-source code for more than 100 native apps.
  • One example experiment: building and testing a multi-platform, multiplayer app.
  • Shipping to Apple platforms still requires an Apple developer account, which is why the creator is renewing his.
