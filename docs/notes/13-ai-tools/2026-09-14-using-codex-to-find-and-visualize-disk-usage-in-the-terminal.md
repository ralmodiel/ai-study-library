## Summary

The creator used Codex to work out which folders take up the most SSD space and to visualize the result in the terminal, so he didn't need a separate disk-usage app. He shares the exact prompt.

## Key points

- Prompt used: "which folders occupy big space. visualize in the terminal".
- A coding agent can replace small single-purpose utility apps.
- Review any deletions yourself before letting an agent remove files.
