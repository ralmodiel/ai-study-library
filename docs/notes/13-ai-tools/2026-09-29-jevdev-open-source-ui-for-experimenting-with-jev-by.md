## Summary

The creator shares the first push of JevDev, an open-source GitHub repo with a UI for experimenting with Jev by Typesafe.ai. It's a small example of building your own tool around an AI product.

## Key points

- JevDev is a UI tool for experimenting with Jev by Typesafe.ai.
- The code is public on GitHub at donvito/jev-dev.
- This is the first push, so expect it to be early-stage.
- A related post says the tool keeps a history of Jev sessions and was built with Codex and Astra.
