Building a 3D Flight Scene with Sonnet in Cursor, three.js and 3D Models

Summary

Melvin Vivas shares a demo video (no narration) of a 3D plane-over-terrain scene. He built it in March 2025 using Claude Sonnet inside Cursor, with downloaded 3D models of the plane and terrain rendered in three.js. He thinks a newer agent ("Astra") could now rebuild it end to end using Blender and three.js, and that he would only need Codex Pro to do it.

Key points

  • The demo was built in March 2025 by AI-assisted coding with Claude Sonnet inside the Cursor editor.
  • He did not generate the 3D assets. He downloaded ready-made 3D models of the plane and the terrain.
  • three.js was the rendering library for the browser-based 3D scene.
  • His workflow: get the assets, then have the coding assistant write the three.js scene that loads and animates them.
  • He thinks current agents (he names 'Astra') could now handle the asset side too by driving Blender alongside three.js.
  • He says recreating the project today would only need a Codex Pro subscription, so the setup is getting simpler.
  • The video has no speech, so all the detail comes from the caption.
