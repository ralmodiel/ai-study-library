Run Muse Code on Windows Without WSL Using a Skill

Summary

The creator shares a way to install Muse Code natively on Windows without WSL. You add the muse-windows-installer skill from the geocine/skills repo with npx, and run the install from Git Bash so curl and bash are available.

Key points

  • Muse Code can run on Windows without WSL.
  • Add the skill with: npx skills add https://github.com/geocine/skills --skill muse-windows-installer
  • Run the install from Git Bash so curl and bash are available.
