Summary

The creator reports that the open Qwen 3.5 model runs on a consumer RTX 3090 GPU with 24 GB of VRAM. He says it works well as the model behind Claude Code and can use agent skills. This suggests local open models are now a workable option for agentic coding.

Key points

  • Qwen 3.5 can run locally on an RTX 3090 with 24 GB VRAM
  • Qwen 3.5 works well when connected to Claude Code
  • The local model can use Claude Code skills
  • A consumer GPU is enough for local agentic coding
