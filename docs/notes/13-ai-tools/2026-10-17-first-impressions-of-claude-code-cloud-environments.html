Summary

Melvin Vivas tried Claude Code cloud environments. They feel okay, but they charge credits on top of the subscription plan, so you have to top up credits to use them.

Key points

  • Claude Code can run in cloud environments, not just on your local machine.
  • According to the creator, cloud usage costs extra credits beyond the subscription plan.
  • Plan for the extra cost before relying on cloud environments.
