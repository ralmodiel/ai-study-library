# Coworker Desktop App Works with Any OpenAI-Compatible Endpoint

Melvin Vivas · X post · 2026-08-29 · [Open on X](https://x.com/melvindvivas/status/2093630644173877432)

**Topics:** AI Dev Tools & Productivity, LLM Fundamentals, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Melvin Vivas says his local-first desktop app Coworker can connect to any OpenAI-compatible API endpoint. He shows it running on Baseten's inference platform with the GLM 5.3 Flash model, so you aren't tied to a single model provider.

## Key points

- Coworker accepts any OpenAI-compatible endpoint, so you can swap model providers without code changes.
- The creator runs it with Baseten as the inference provider.
- The model used is GLM 5.3 Flash, an alternative to OpenAI models.
- The OpenAI-compatible API format is a de facto standard many inference hosts support, which makes switching providers easy.
