Summary

A tip for stretching Codex usage limits: open separate chats with two models. Send complex or large tasks to Astra and small or minor tasks to Luna.

Key points

  • Open several Codex chats, each using a different model.
  • Send complex or large tasks to the stronger model (Astra).
  • Send small or minor tasks to the lighter model (Luna) to save usage limits.
  • More generally, match model size to task difficulty to control cost and quota.
