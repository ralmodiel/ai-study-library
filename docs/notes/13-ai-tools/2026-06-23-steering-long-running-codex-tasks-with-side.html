Summary

The /side command in the Codex app opens a side thread for checking on a long-running task. In that thread you can ask clarifying questions, give pointers or unblock the agent, for example by asking it to summarize what's done and what's left.

Key points

  • /side opens a side thread next to a running Codex task.
  • Use it to check progress, ask questions, give pointers or unblock the agent.
  • Useful prompt: ask Codex to summarize what's done and what's not done yet.
