# Using Custom and Open Models in OpenAI Codex via config.toml

Melvin Vivas · X post · 2026-06-18 · [Open on X](https://x.com/melvindvivas/status/2067596007261778219)

**Topics:** AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Codex now supports custom models, so you can run open models through other providers. The quoted tip says the easiest setup is to have Codex edit its own configuration file at ~/.codex/config.toml, so you don't have to edit it by hand.

## Key points

- Codex now supports custom model configurations, including open models from third-party providers.
- Custom model settings live in ~/.codex/config.toml.
- Tip: ask Codex to do it for you, e.g. 'Please read ~/.codex/config.toml and help me add the custom model configuration.'
- The change also applies to Codex Desktop.
- The creator's open question is which providers actually work, so test your provider before relying on it.
