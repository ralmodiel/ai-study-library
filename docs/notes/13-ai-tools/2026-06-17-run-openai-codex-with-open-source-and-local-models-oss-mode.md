# Run OpenAI Codex with Open-Source and Local Models (OSS Mode)

Melvin Vivas · X post · 2026-06-17 · [Open on X](https://x.com/melvindvivas/status/2067193292828348811)

**Topics:** AI Dev Tools & Productivity, LLM Fundamentals · **Level:** intermediate

## Summary

The OpenAI Codex App, CLI and SDK aren't limited to OpenAI models. You can set them up to use any open-source model through local providers. The setup is covered in the Codex advanced-configuration docs, in the 'OSS mode / local providers' section.

## Key points

- The Codex App, CLI and SDK all work with open-source models, not just OpenAI models.
- Setup lives in the Codex advanced-configuration docs, in the 'OSS mode - local providers' section.
- This lets you run Codex on locally hosted models, which can help with cost and privacy and lets you experiment with different models.
- The tip comes from Tibo (@thsottiaux) at OpenAI.
