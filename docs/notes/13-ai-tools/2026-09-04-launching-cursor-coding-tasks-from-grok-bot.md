## Summary

A short reaction post about a feature that lets you open a coding task in Cursor straight from Grok Bot, so a chat assistant can hand work off to a coding IDE.

## Key points

- Grok Bot can open a coding task in Cursor.
- This links a chat bot to an AI coding IDE, so tasks move from conversation into the code editor.
