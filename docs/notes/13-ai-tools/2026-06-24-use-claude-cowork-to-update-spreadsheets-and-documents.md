## Summary

The creator describes handing spreadsheet and document updates to Claude Cowork: he gives it the new data and it edits the files, so he no longer works through rows and cells by hand.

## Key points

- Give Claude Cowork the data to update, then let it edit the spreadsheets and docs.
- This removes manual row and cell editing from repetitive office work.
- Agent tools like this are useful beyond coding, for everyday document work.
