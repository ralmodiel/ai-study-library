Improving Codex's UI Design Output with Impeccable (npx impeccable install)

Summary

This is a short demo post. Melvin Vivas installs Impeccable with one command, npx impeccable install, and shows that OpenAI's Codex coding agent then produces better-looking UI designs. He adds Impeccable on top of his existing coding agent. He also jokes that this might replace Claude Design. The 13-second video has no narration, so the main takeaway is the tool and how to install it.

Key points

  • Impeccable (@impeccable_ai) is an add-on that improves the visual and UI design work of an AI coding agent like Codex.
  • You install it with one command: npx impeccable install. This needs Node.js / npm.
  • After installing it, the creator found Codex's design output much better ('Codex is now a better designer!').
  • Other users recommended the tool to him, so it seems to be gaining popularity among people who use AI coding agents.
  • He jokes about cancelling Claude Design, which suggests a free add-on for your coding agent could compete with dedicated AI design products.
  • The video has no speech. It is a quick visual demo, not a walkthrough.
