# Keep Agents Running: Cloud Agents vs a Laptop Dummy Plug

Melvin Vivas · X post · 2026-05-13 · [Open on X](https://x.com/melvindvivas/status/2054467595785679357)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

The creator responds to AgentPlug, a USB-C dummy plug that keeps a Mac awake in clamshell mode so local agents keep running. His point is that you don't need hardware workarounds. Cursor Cloud Agents run remotely, so your laptop does not need to stay on.

## Key points

- Long-running local agents stop when the laptop sleeps.
- AgentPlug works around this by pretending to be an external display, which keeps a Mac in clamshell mode.
- Cloud agents (Cursor Cloud Agents) avoid the problem by running remotely.
