# Claude Cowork and Claude Code have separate usage limits

Melvin Vivas · X post · 2026-09-18 · [Open on X](https://x.com/melvindvivas/status/2100884704195146126)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

A quick tip: Claude's Cowork and Claude Code products have separate usage limits. That's useful when planning which tool to use once you hit a cap.

## Key points

- Cowork and Claude Code have separate usage limits.
- Hitting the limit in one doesn't necessarily block the other.
