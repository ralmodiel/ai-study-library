# v0 vs Claude Code for cloning an app's design

Melvin Vivas · X post · 2026-03-05 · [Open on X](https://x.com/melvindvivas/status/2029251954808111142)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

While building a new project from a clone of an existing app, the creator found that v0 handled the UI design well and Claude Code struggled. The lesson is to use a design-focused generator for UI work and a coding agent for everything else.

## Key points

- v0 produced a strong UI design when cloning an app
- Claude Code struggled with the same design task
- Use design-focused AI tools for UI and coding agents for logic
