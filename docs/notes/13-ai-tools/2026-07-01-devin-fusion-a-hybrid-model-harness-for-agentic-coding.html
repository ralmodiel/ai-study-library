Summary

Devin Fusion is a new hybrid-model harness for agentic coding, now available for Cloud agents. Its makers claim conventional model routing passes benchmarks but writes code you wouldn't merge. They say Fusion delivers Fable-level intelligence for about 35% less cost. Melvin sees it as the closest thing to Fable available right now.

Key points

  • Conventional model routing can pass benchmarks but still produce code you wouldn't merge.
  • Devin Fusion combines several models in one harness for agentic coding.
  • Claimed result: about 35% lower cost for Fable-level intelligence while still feeling good to use.
  • Available for Devin Cloud agents.
