# Coworker v0.3.3: Skills Toggle, Schedules and Inline Approvals

Melvin Vivas · X post · 2026-08-29 · [Open on X](https://x.com/melvindvivas/status/2093591788259049896)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Release notes for Coworker v0.3.3, Melvin Vivas's local-first desktop AI coworker app. This minor release improves quality of life: easier folder selection, turning Skills on or off, better visibility and editing of scheduled jobs, and approving agent actions inline in the chat.

## Key points

- You can select folders right next to the chat box to give the agent working context.
- Skills can be enabled or disabled one by one.
- Scheduled jobs now show up in the main Coworker view.
- Editing a scheduled job is now friendlier and replaces the earlier raw cron configs.
- Approving agent actions inline in chat is a human-in-the-loop control.
