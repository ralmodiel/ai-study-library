# Seedance 2.0 on fal: Strict Content Filters Block Video Generation

Melvin Vivas · X post · 2026-04-20 · [Open on X](https://x.com/melvindvivas/status/2046160846360084525)

**Topics:** AI Dev Tools & Productivity, AI Safety, Security & Guardrails · **Level:** beginner

## Summary

The creator reports that Seedance 2.0 video generation on fal often fails because of strict content restrictions. Prohibited keywords and some image references trigger the failures. The post asks whether anyone has found a way around it, so it offers no fix.

## Key points

- Seedance 2.0 is a video generation model that can be used through the fal platform.
- Generations can fail when the prompt contains prohibited keywords.
- Image references (image-to-video inputs) can also trigger the content restrictions.
- No workaround is given. Expect failed jobs and plan prompts and reference images with this in mind.
