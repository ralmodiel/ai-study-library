## Summary

The creator runs Qwen 3.5 35B locally in LM Studio and praises its vision ability. He uses it to write prompts for free instead of paying for API calls.

## Key points

- Qwen 3.5 35B can run locally through LM Studio.
- Its vision (image understanding) is strong.
- Use case: write prompts (e.g., image prompts) locally at no cost.
- Local models cut API costs for routine tasks.
