**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

A practical note on Grok subscriptions: X Premium+ does not let you use the Grok Bot, so you need a SuperGrok account. Using Grok models in Cursor requires a separate subscription.

## Key points

- X Premium+ does not include access to the Grok Bot.
- You need a SuperGrok account to use the Grok Bot.
- Using Grok in Cursor needs a separate subscription.
- Check which subscription covers which product before you pay.
