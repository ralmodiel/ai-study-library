# CamelFlow: open-source visual viewer for Apache Camel routes

Melvin Vivas · X post · 2026-09-29 · [Open on X](https://x.com/melvindvivas/status/2104855828822204518)

**Topics:** AI Dev Tools & Productivity, Portfolio Projects · **Level:** intermediate

## Summary

The creator released CamelFlow, an open-source (Apache 2.0) tool that shows Apache Camel route configurations visually. You can run it with a single Java command or through JBang, which makes it an example of a polished developer tool for enterprise integration.

## Key points

- CamelFlow shows Apache Camel route configurations as visual diagrams
- Run it with: java -jar camelflow.jar ./my-routes
- Or with JBang: jbang camelflow@donvito/camel-flow ./my-routes
- It is open source under the Apache 2.0 license
- The creator's point: enterprise tools don't have to look bad
