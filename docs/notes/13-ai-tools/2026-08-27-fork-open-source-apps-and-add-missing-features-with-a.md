# Fork Open-Source Apps and Add Missing Features with a Coding Agent

Melvin Vivas · X post · 2026-08-27 · [Open on X](https://x.com/melvindvivas/status/2092878949122744661)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

If an open-source app you use is missing a feature, fork it and have any coding agent add the feature. Then keep it as your own version.

## Key points

- Look for open-source apps you can fork.
- Any coding agent can add the feature; which one doesn't really matter.
- Customize your fork for your own needs.

## Try this

- [ ] Fork an open-source tool you use and add a missing feature with a coding agent.
- [ ] Add a feature you want to a fork of an open-source app, using a coding agent.
