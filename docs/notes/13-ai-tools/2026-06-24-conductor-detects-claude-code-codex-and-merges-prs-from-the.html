Summary

Further notes on Conductor: it detects the Claude Code and Codex installs on your machine, lets you pick one per project, and lets you merge the PR from inside the tool when a change is ready.

Key points

  • It automatically detects installed Claude Code and Codex.
  • You choose which agent to use for each project.
  • Finished changes can be merged as PRs directly from Conductor.
