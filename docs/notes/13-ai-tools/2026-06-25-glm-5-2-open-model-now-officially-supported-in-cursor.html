GLM 5.2 open model now officially supported in Cursor

Summary

Cursor now officially supports the open model GLM 5.2, through a partnership with Fireworks. The quoted announcement says Cursor shared results from its own evals. It shows open models becoming usable choices inside coding assistants.

Key points

  • GLM 5.2 is an open model, now officially available in Cursor.
  • Cursor serves it through a partnership with Fireworks.
  • Cursor published its own eval results for the model.
  • Open models are becoming real options next to closed models in coding tools.
