# Splitting AI Tools: Cursor 3 + GPT-5.4 for Code, Claude for Learning

Melvin Vivas · X post · 2026-04-09 · [Open on X](https://x.com/melvindvivas/status/2042129299919315072)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator downgraded from Claude Max to Claude Pro. He now codes mostly in Cursor 3 (Glass) with GPT-5.4 and keeps Claude for brainstorming and learning. The post shows one way to split work across AI subscriptions to save money.

## Key points

- He moved from Claude Max to the cheaper Claude Pro plan.
- Most coding now happens in Cursor 3 (Glass) with GPT-5.4.
- He still uses Claude for brainstorming and learning new topics.
- Lesson: match each tool to the task instead of paying for one top-tier plan.
