Summary

Melvin suggests Resemble AI's open-source Chatterbox model for cloning a voice from a short audio recording. Instead of setting it up by hand, you can ask a coding agent like Claude or Codex to install and run it for you.

Key points

  • Chatterbox (resemble-ai/chatterbox) is an open-source text-to-speech model described as state of the art.
  • It can clone a voice from a short reference audio recording.
  • Shortcut: ask a coding agent (Claude or Codex) to set up and run Chatterbox for you.
