jsonl-viewer Grows into a Coding-Agent Trace Viewer

This note summarises a post by Melvin Vivas on X, posted 7 September 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Melvin Vivas · X post · 2026-09-07 · Open on X

Topics: AI Dev Tools & Productivity, AI Agents, Tool Use & MCP, LLMOps, Deployment & Monitoring · Level: intermediate

Summary

The creator's open-source jsonl-viewer started as a tool for viewing and editing .jsonl datasets. It now also displays coding-agent traces from Codex, Claude Code, Pi and Hermes, which helps when debugging what an agent actually did.

Key points

  • jsonl-viewer views and edits .jsonl files, the format often used for fine-tuning and training datasets.
  • It is turning into a trace viewer for coding agents: Codex, Claude Code, Pi and Hermes.
  • Coding agents save session traces as JSONL, so a JSONL viewer can be used to inspect them.
  • Follow the repo for updates.
