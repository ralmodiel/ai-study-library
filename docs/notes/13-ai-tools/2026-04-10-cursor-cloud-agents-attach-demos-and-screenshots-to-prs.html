Summary

Melvin Vivas reshares an announcement: Cursor's cloud agents can now attach demos and screenshots of their work to the pull requests they open. Reviewers can check what the agent built directly in GitHub, without checking out the branch.

Key points

  • Cursor cloud agents can open PRs on their own.
  • Those PRs can now include demo recordings and screenshots of the agent's work.
  • Teams review these artifacts directly in GitHub.
  • Visual artifacts make it faster to verify UI changes made by agents.
