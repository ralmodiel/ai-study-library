Summary

The creator does unlimited, free AI coding with Unsloth's build of Qwen 3.5 running on one RTX 3090. It shows that local coding models are practical on consumer GPUs.

Key points

  • Unsloth publishes quantized builds of Qwen 3.5 that run on consumer GPUs.
  • One RTX 3090 (24 GB) is enough for local AI coding.
  • Running locally means no usage limits or API bills.
