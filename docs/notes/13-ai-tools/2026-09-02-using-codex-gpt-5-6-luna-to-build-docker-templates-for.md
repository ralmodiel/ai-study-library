## Summary

A short update: Codex, running GPT 5.6 Luna, is building Docker templates that the creator plans to test on Runpod. The only takeaway is that a coding agent can write infrastructure and container setup, not just application code.

## Key points

- Coding agents can write Docker and infrastructure setup.
- He used the GPT 5.6 Luna model in Codex and says it's 'so far so good'.
- He'll test the templates on Runpod GPU hosting.
