Melvin Vivas · X post · 2026-09-16 · [Open on X](https://x.com/melvindvivas/status/2100110722852409435)

**Topics:** AI Dev Tools & Productivity, Programming & ML Foundations · **Level:** beginner

## Summary

The creator says the operating system doesn't really matter for AI work. He uses both Mac and Windows, and WSL on Windows gives him a Linux environment too, so in effect he works across three operating systems.

## Key points

- Any OS (macOS, Windows, Linux) is fine for AI engineering work
- On Windows, WSL (Windows Subsystem for Linux) gives you a full Linux environment
- With WSL, one Windows machine covers both Windows and Linux workflows
