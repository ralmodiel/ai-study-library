Summary

Melvin Vivas posts a 15-second demo of a motion graphics video he made by giving a prompt to OpenAI's Codex, with the "Astra High" setting. The clip has no narration, and the post doesn't share the prompt. What it shows is that a coding agent can produce animated visuals, not just regular code.

Key points

  • Codex, OpenAI's coding agent, was used to make a motion graphics video from a single prompt.
  • The creator says he used "Astra High", which looks like a model or reasoning-effort setting in Codex. The post doesn't explain what it is.
  • The exact prompt isn't in the post, so you can't reproduce the result from this item alone.
  • The 15-second clip has no speech. It's a showcase of the output, not a tutorial.
  • Takeaway: coding agents can create visual and animation content, likely by writing code that renders the animation.
