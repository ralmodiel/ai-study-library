# Cursor Workflow: Start an Agent on Mobile, Continue in the Cloud

Melvin Vivas · X post · 2026-08-15 · [Open on X](https://x.com/melvindvivas/status/2088466506292306112)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator describes his Cursor workflow: he starts an agent from Cursor's mobile app, lets it continue in the cloud, then downloads the result to test locally. He sees it as a smooth way to code from anywhere.

## Key points

- Start agent tasks from the Cursor mobile app.
- The agent keeps running in the cloud after you start it on your phone.
- When you need to test locally, download the work and run it on your machine.
