## Summary

The creator quotes Google's announcement of Gemini-SQL2, a text-to-SQL feature powered by Gemini 3.1 Pro. The announcement says it reached state-of-the-art results on the BIRD benchmark by turning natural language into ready-to-run SQL. It shows that natural-language-to-SQL is becoming practical.

## Key points

- Gemini-SQL2 turns natural-language questions into SQL queries that can be run directly.
- It is powered by Gemini 3.1 Pro.
- It is reported to reach state-of-the-art results on the BIRD text-to-SQL benchmark.
- BIRD is a competitive benchmark for checking how well models turn questions into SQL.
- The creator's take: you may no longer need to write SQL by hand.
