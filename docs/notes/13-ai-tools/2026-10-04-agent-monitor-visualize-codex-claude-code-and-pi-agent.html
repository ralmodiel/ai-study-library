Summary

This short post from Melvin Vivas points to Agent Monitor, an open-source GitHub tool that turns coding-agent traces from Codex, Claude Code or Pi into visuals. According to the repo, it shows subagents, a detailed traces view, a breakdown of token use and cost. The creator says it is most fun when you use subagents, because you can watch them spawn and work.

Key points

  • Agent Monitor is a free, open-source visualizer for coding-agent traces (repo: donvito/agent-monitor).
  • It works with traces from OpenAI Codex, Claude Code and the Pi coding agent.
  • The repo lists an advanced traces view, a token breakdown and cost tracking.
  • It is most useful (and most fun) when your agent spawns subagents, because you can see each subagent's activity.
  • Seeing traces visually helps you understand how coding agents split up work and where tokens and money go. These are basic observability habits for agents.
