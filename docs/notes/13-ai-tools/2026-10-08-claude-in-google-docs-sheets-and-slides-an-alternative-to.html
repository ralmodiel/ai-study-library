Summary

This is a short product-news post. Melvin Vivas says Claude models are a good alternative to Gemini when you work in Google Workspace. The post he quotes says Claude now works inside Google Docs, Sheets and Slides: it sits in a sidebar, reads the open file and edits it in place, and you approve each edit. The video's transcript is only "Hey!", so all the content comes from the caption.

Key points

  • Claude now works inside Google Docs, Google Sheets and Google Slides.
  • Those Google Workspace files can also be opened inside Claude.
  • In Workspace, Claude sits in a sidebar next to your file and reads what you have open.
  • Claude edits the document in place rather than in a separate chat output.
  • You can approve each edit before it is applied, so you stay in control of changes.
  • The creator thinks Claude is a strong alternative to Gemini, Google's built-in assistant, for Workspace tasks.
