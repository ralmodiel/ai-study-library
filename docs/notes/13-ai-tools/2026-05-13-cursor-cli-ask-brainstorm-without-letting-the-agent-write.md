**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

A tip about the Cursor CLI's /ask command. It lets you brainstorm or ask questions without the agent changing your code. The creator calls it an underrated feature.

## Key points

- The Cursor CLI has an /ask command.
- /ask is for brainstorming and questions; the agent does not edit code.
- Use it to plan before you let the agent make changes.
