Running coding agents from an iPhone

This note summarises a post by Melvin Vivas on X, posted 3 October 2026. The original belongs to Melvin Vivas.

Topics: AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · Level: beginner

Summary

The creator lists the coding agents he set up on his iPhone so he can work while mobile. Some of them control his computer remotely (Codex, Claude Code, Cursor, Grok Bot). Others run as cloud agents (Cursor, Devin).

Key points

  • Agents that control your own computer: Codex, Claude Code, Cursor, Grok Bot
  • Cloud agents that run without your machine: Cursor, Devin
  • Mixing local-access agents with cloud agents lets you keep coding from a phone
