# Reusable GPU devbox: PyTorch/CUDA plus six coding agents

Melvin Vivas · X post · 2026-09-02 · [Open on X](https://x.com/melvindvivas/status/2095138320481390772)

**Topics:** AI Dev Tools & Productivity, LLMOps, Deployment & Monitoring, Fine-tuning & Model Customization · **Level:** intermediate

## Summary

The creator built a reusable Docker devbox (v1.1.0) for local NVIDIA GPUs or cloud GPU providers like Runpod and QuickPod. It bundles PyTorch/CUDA with the coding agents Codex, Claude Code, Pi, Grok Build and Cursor CLI, plus Herdr for persistent sessions.

## Key points

- One image works on local NVIDIA GPUs, Runpod or QuickPod
- Base: PyTorch + CUDA
- Coding agents included: Codex, Claude Code, Pi, Grok Build, Cursor CLI
- Herdr keeps sessions running
- Current version is 1.1.0 on Docker Hub (melvindave/runpod-pytorch)
