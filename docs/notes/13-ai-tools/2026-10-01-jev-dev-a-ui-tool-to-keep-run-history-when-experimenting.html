jev-dev: A UI Tool to Keep Run History When Experimenting with Jev

Summary

Melvin Vivas built jev-dev, an open-source UI tool for experimenting with Jev by Typesafe.ai. He built it because the Jev Playground doesn't keep a history of past runs. An experiments feature is still being built.

Key points

  • The Jev Playground doesn't save a history of past runs.
  • jev-dev (github.com/donvito/jev-dev) is a UI tool for experimenting with Jev by Typesafe.ai and keeps track of past runs.
  • An 'experiments' feature is still in progress.
  • Pattern: when a vendor playground lacks run history, a small local UI that logs prompts and outputs makes iteration easier.
