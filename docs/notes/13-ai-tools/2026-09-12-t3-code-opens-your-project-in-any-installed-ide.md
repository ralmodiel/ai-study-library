# T3 Code Opens Your Project in Any Installed IDE

Melvin Vivas · X post · 2026-09-12 · [Open on X](https://x.com/melvindvivas/status/2098616772807278900)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

T3 Code finds every IDE installed on your machine and gives you a shortcut to open the project in the one you prefer. The creator gives this as an example of good UX in an agent app.

## Key points

- T3 Code detects all the IDEs you have installed.
- It has a shortcut to open the current project in your preferred IDE.
