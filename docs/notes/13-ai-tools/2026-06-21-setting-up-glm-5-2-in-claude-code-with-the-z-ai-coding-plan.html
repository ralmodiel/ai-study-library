Summary

The creator shares his settings for running GLM 5.2 inside Claude Code through the Z.ai coding plan. The settings themselves were in an image, so only the setup is described here. It shows that Claude Code can point to a third-party, Anthropic-compatible model provider.

Key points

  • Claude Code can run GLM 5.2 through Z.ai's coding plan.
  • This works through Claude Code settings that point to Z.ai's Anthropic-compatible endpoint (https://api.z.ai/api/anthropic, per a related post).
