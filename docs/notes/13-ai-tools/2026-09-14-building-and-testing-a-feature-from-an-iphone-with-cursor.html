The creator says he built and tested a whole feature using only Cursor Projects on his iPhone, without using his Mac. It shows that you can now do real coding work with a cloud or mobile AI coding agent.

Key points

  • Cursor Projects on iPhone was enough to build and test a feature from start to finish

  • Mobile coding agents let you do development work away from your desk
