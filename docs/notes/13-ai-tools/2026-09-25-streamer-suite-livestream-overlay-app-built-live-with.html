Streamer Suite: livestream overlay app built live with Claude Code

Summary

Melvin Vivas published the source code of Streamer Suite, which he built during a livestream using Opus 5.5 in Claude Code. The app adds CPU/RAM and GPU monitors to a stream as OBS browser sources. The goal is one local app that manages all your stream widgets and overlays.

Key points

  • The app was built live on stream with Opus 5.5 in Claude Code.
  • Streamer Suite shows CPU/RAM and GPU monitors as widgets.
  • The widgets are added to OBS as browser input sources.
  • The goal is a single local app that manages all your livestream widgets and overlays.
  • It is still a work in progress.
