The creator announces his first long-form YouTube video. In it he argues that removing Plan Mode from Claude Code, Codex and Cursor is a mistake. The post itself has no details, so watch the video for the reasoning.

Key points

  • The creator argues that Plan Mode in AI coding agents (Claude Code, Codex, Cursor) is still valuable.
  • Plan Mode lets the agent propose a plan before it edits code, so you can review the approach first.
  • In a related post, he says Plan Mode isn't needed for casual vibe coding, which suggests it matters most for structured work.
