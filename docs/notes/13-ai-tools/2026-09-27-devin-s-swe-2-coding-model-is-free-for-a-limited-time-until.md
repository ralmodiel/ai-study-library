## Summary

This is a 14-second news clip. It says Devin (from Cognition) released a new AI coding model called SWE-2, which the creator calls the current top model on the Terminal-Bench benchmark. SWE-2 is free on Devin Cloud until October 8 and in the Devin desktop app until October 15. It doesn't teach any techniques. Its only use is pointing learners to a free trial of a strong coding agent model.

## Key points

- Devin released a new coding model called SWE-2 (the transcript spells it 'SW2').
- The creator calls SWE-2 the best model right now on Terminal-Bench, a benchmark for agents doing tasks in a terminal.
- SWE-2 is free on Devin Cloud until October 8.
- SWE-2 is free in the Devin desktop app until October 15.
- The headline 'AI coding is FREE' is overstated: the free access is a limited-time promotion, not a permanent free tier.
