## Summary

The quoted Anthropic announcement lists updates to Claude Design: it keeps your design system consistent across projects, lets you edit directly on the canvas, syncs with Claude Code, and adds more tool integrations. The creator's own reply just asks for Fable back.

## Key points

- Claude Design now applies your design system consistently across projects.
- You can edit directly on the canvas.
- Claude Design syncs with Claude Code, linking design and code workflows.
- It connects to more of the tools you already use.
