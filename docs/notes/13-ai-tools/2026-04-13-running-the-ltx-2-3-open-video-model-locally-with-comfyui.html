Summary

This is a short demo post. Melvin Vivas shows LTX 2.3, the open video-generation model from LTX Studio (Lightricks), running locally and for free in ComfyUI. One generation took about 5 minutes on a consumer RTX 3090 GPU. He says he hasn't yet worked out how to control the audio in the output. The post shows that open video models can run on a home GPU, but it doesn't give the workflow steps.

Key points

  • LTX 2.3 is an open video-generation model from LTX Studio (Lightricks) that you can run locally at no cost.
  • ComfyUI, a node-based interface for generative models, was used to run the model.
  • One generation took about 5 minutes on an NVIDIA RTX 3090 (24 GB VRAM), a consumer GPU.
  • The model produces audio along with the video, but the creator hadn't yet worked out how to control it.
  • Running open models locally avoids per-generation API costs. You pay with generation time and need a strong GPU.
