# Save Codex limits: plan in ChatGPT with the GitHub plugin

Melvin Vivas · X post · 2026-09-16 · [Open on X](https://x.com/melvindvivas/status/2100106657254764564)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

A workflow tip for saving Codex usage limits. Instead of using Codex's plan mode, plan the feature in a ChatGPT chat using the GitHub plugin by pasting your repo URL. Then switch to Codex only to implement the plan.

## Key points

- Don't use plan mode in Codex, because it uses up your Codex limits
- Plan in a ChatGPT chat with the GitHub plugin/connector instead
- Paste your GitHub repo URL and ask ChatGPT to plan the new feature
- Planning in ChatGPT doesn't count against Codex limits
- Once you have the plan, switch to Codex for implementation
