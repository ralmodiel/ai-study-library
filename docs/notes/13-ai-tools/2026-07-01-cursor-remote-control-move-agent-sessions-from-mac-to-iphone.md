# Cursor Remote Control: move agent sessions from Mac to iPhone

Melvin Vivas · X post · 2026-07-01 · [Open on X](https://x.com/melvindvivas/status/2072305721379873015)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Cursor's Remote Control feature lets you start a coding agent on your Mac and keep working with it from your iPhone. This means you can watch and steer long-running agent tasks when you're away from your desk.

## Key points

- Start a Cursor agent on your desktop (Mac).
- Continue the same agent session from your iPhone with Remote Control.
- Useful for checking on and steering long-running agent tasks from anywhere.
