**Topics:** AI Dev Tools & Productivity, LLM Fundamentals · **Level:** beginner

## Summary

Z.ai's GLM-5.1 model is now available to all GLM Coding Plan subscribers. The plan offers GLM models for coding agents and IDEs.

## Key points

- GLM-5.1 is available to all GLM Coding Plan users.
- The GLM Coding Plan is a subscription to GLM models for coding agents and IDEs.
