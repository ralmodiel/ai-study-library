Summary

Cursor's latest release lets you search text inside the agent window, a feature the creator had suggested to the Cursor team. It helps you find earlier output in long agent sessions.

Key points

  • New Cursor release: you can search text in the agent window.
  • Useful for finding earlier messages or output in long agent conversations.
  • The feature came from a user suggestion; tool teams do respond to feedback.
