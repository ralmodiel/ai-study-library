Summary

Melvin Vivas shares a short demo video, with no speech, of release v0.3.1 of his open-source project Coworker. The release adds streaming sync between Telegram and Coworker. He says he used up his OpenAI Codex 5-hour usage limit in about 10 minutes while running the "GPT 5.6 Sol" model on high/fast settings, and felt it was worth it. The post mostly shows a release and a usage anecdote. It has no step-by-step lesson.

Key points

  • Coworker v0.3.1 adds streaming sync between Telegram and Coworker, so you can chat with or follow the tool from Telegram.
  • The creator used up his OpenAI Codex 5-hour usage limit in about 10 minutes.
  • He ran the model he calls "GPT 5.6 Sol" on high reasoning effort with fast mode, which burns through the quota much faster.
  • His verdict: the speed and quality were "definitely worth it" despite the quota cost.
  • The release is on GitHub under the donvito account. The link in the caption is cut off; the full path in the post text is github.com/donvito/coworker/releases/tag/v0.3.1.
