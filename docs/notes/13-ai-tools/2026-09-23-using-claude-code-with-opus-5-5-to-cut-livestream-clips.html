Using Claude Code with Opus 5.5 to Cut Livestream Clips

Summary

The creator used Claude Code running Opus 5.5 to automatically make short clips from a livestream recording. He says it saved a lot of time and finished before Codex did. It is an example of using agentic coding tools for media automation, not only for writing code.

Key points

  • Claude Code with Opus 5.5 was asked to make clips from a livestream recording.
  • The creator says it saved a lot of time on manual editing.
  • He ran Codex on the same task, and it had not finished when Claude Code did.
  • Agentic coding assistants can automate non-coding chores such as video clipping by scripting tools for you.
