# Running MiniMax M3 Locally in ComfyUI on an RTX 3090

Melvin Vivas · X post · 2026-08-07 · [Open on X](https://x.com/melvindvivas/status/2085423372423614896)

**Topics:** AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator got MiniMax's M3 model running locally in ComfyUI on a consumer RTX 3090 GPU. He expects generation to be slow ("a long night"). This shows that the model can run on local hardware, but slowly on a 24GB consumer card.

## Key points

- MiniMax M3 can run locally through ComfyUI.
- On a single RTX 3090 (24GB), the creator expects generation to be slow.
- Plan for long run times when running large generative models on consumer GPUs.
