# Local Qwen 3.5 Adds an Express API and SQLite to Make an App Full-Stack

Melvin Vivas · X post · 2026-03-08 · [Open on X](https://x.com/melvindvivas/status/2030343979829801360)

**Topics:** AI Dev Tools & Productivity, Portfolio Projects · **Level:** intermediate

## Summary

The creator asked a locally running Qwen 3.5 to add an Express API server that saves data to SQLite. The model did it and turned the app into a full-stack app.

## Key points

- Local Qwen 3.5 handled a multi-step backend task: adding an Express API server and SQLite storage.
- The frontend-only app became full-stack.
- This is a useful benchmark task for testing local coding models.
