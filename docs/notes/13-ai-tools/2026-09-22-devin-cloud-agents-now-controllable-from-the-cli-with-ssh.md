# Devin Cloud Agents Now Controllable from the CLI with SSH Access

Melvin Vivas · X video post · 2026-09-22 · 0:11 · 3,598 views · [Open on X](https://x.com/melvindvivas/status/2102224439492674028)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

A short reshare of a Cognition announcement. Devin's cloud coding agents can now be steered from the command line, not only the web app, and you can SSH straight into the agent's VM. Cognition also says agent PRs are tested in a real VM with a real browser or devices, and the testing is recorded on video. The SWE-2 model was free to use until October 8.

## Key points

- Devin cloud agents can now be steered from a CLI as well as the web interface.
- You can SSH directly into the VM Devin is working in to inspect or step in on its work.
- Cognition says Devin tests its PRs in a real VM, with a real browser or devices, and records the testing on video so you can check it.
- SWE-2 was offered free until October 8 (according to the quoted Cognition post).
- Why it matters: coding agents are moving toward work environments you can see and reach, so you can check what an agent did instead of trusting its output blindly.
