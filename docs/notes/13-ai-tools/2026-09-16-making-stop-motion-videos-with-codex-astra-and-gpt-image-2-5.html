Summary

A short demo with no narration. Melvin Vivas shows a stop-motion video made with OpenAI Codex. In the quoted post, he says he asked Astra to generate individual scenes with GPT Image 2.5 and then stitch them into a stop-motion video. He says he made no manual edits. The post shows that coding agents can run multi-step creative media pipelines, not just write code.

Key points

  • Codex can handle more than code: it can coordinate image generation and video assembly from a single request.
  • Workflow: use Astra inside Codex, ask it to generate scenes with GPT Image 2.5, then have it stitch the frames into a stop-motion video.
  • The creator says he made no manual edits; the agent did the whole pipeline.
  • Stop-motion fits this well because it is a sequence of still images, so an image model can make the frames and the agent can assemble them.
  • The video is 31 seconds long, has no speech, and is a showcase rather than a step-by-step tutorial.
