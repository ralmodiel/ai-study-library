Summary

Melvin shares the Pi v0.84.2 release. It adds full-screen search across your whole session transcript and lets you choose which built-in tools load at startup, globally or per project. You update with 'pi update'.

Key points

  • Pi v0.84.2 is out.
  • Press Ctrl+Shift+F to search the full session transcript.
  • You can choose the built-in tools that load at startup, either globally or per project.
  • Run 'pi update' to get the latest version.
