# One-Shotting a Slack Clone with Fable 5

Melvin Vivas · X video post · 2026-06-11 · [Open on X](https://x.com/melvindvivas/status/2064807455435956586)

**Topics:** AI Dev Tools & Productivity, Prompt & Context Engineering, Portfolio Projects · **Level:** beginner

## Summary

A user gave Fable 5 one prompt asking for a 1:1 Slack clone in TypeScript, Electron, Tailwind and SQLite. It produced both the UI and the server in under 10 minutes. The example shows how much a single detailed prompt that names the tech stack can produce.

## Key points

- Prompt: 'Create a 1:1 clone of Slack using Typescript, Electron, Tailwind, SQLite. Make it beautiful and functional.'
- Naming the exact tech stack in the prompt steers the output
- Fable 5 one-shotted the UI and the server in under 10 minutes
- Treat it as a strong first draft, not finished software
