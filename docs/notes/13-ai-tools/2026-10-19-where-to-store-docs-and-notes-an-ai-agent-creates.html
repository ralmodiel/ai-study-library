Where to store docs and notes an AI agent creates

This note summarises a post by Melvin Vivas on X, posted 19 October 2026. The original belongs to Melvin Vivas.

Summary

The creator shares how he sends AI agent output to different places so he can reach it anywhere and share it: Markdown notes go to Notion, office-style files to Google Docs/Sheets/Slides, everything else to Google Drive, and local files to his computer.

Key points

  • Markdown notes → Notion
  • Documents, spreadsheets and presentations → Google Docs, Sheets, Slides
  • Any other file → Google Drive
  • Need to work on files locally? Have the agent save them straight to your Mac or Windows computer
  • The goal: output you can reach from anywhere and that's ready to share
