Summary

A quick tip for OpenAI Codex cloud: a new cloud environment does not publish automatically. You have to save and publish it before you can use it. To do that, open the environment, go to the chat that created it, and publish it from there.

Key points

  • Codex cloud environments do not auto-publish after you create them.
  • An environment must be saved and published before Codex can use it.
  • How to publish: click the environment, open the chat that created it, then click Publish.
  • If a new environment seems unusable, check first that it has been published.
