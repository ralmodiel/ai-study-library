# Claude Code mods: customize behavior and UI with plugins

Melvin Vivas · X video post · 2026-10-02 · [Open on X](https://x.com/melvindvivas/status/2105872553818611759)

**Topics:** AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Claude Code now supports mods. They can change how it behaves, customize the UI, or swap in your own features. Mods are written in a few lines of TypeScript, or Claude can build them for you, and they ship inside plugins installed with /plugin. The creator says Pi already offered this kind of customization.

## Key points

- Claude Code mods can change agent behavior, customize the UI and swap in your own features.
- You write a mod in a few lines of TypeScript, or ask Claude to generate it.
- Mods ship inside plugins.
- Install plugins with the /plugin command in the Claude Code CLI or desktop app.
- The creator says Pi already offered similar customization.
