## Summary

If Codex uses up your usage limits unusually fast, you can report it with the /feedback command. This only works if you agree to share your session so OpenAI can look into it.

## Key points

- Run /feedback inside Codex if you hit your limits unusually fast.
- Sending feedback means sharing your session data with OpenAI, so only do it if you're comfortable with that.
- The aim is to help OpenAI find and fix the limit-consumption problem.
