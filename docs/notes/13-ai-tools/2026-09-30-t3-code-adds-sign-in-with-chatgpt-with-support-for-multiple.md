## Summary

Melvin Vivas shares a short video quoting the T3 Code launch post. T3 Code is a launch partner of "Sign in with ChatGPT," so you can now set it up by installing it and signing in with your ChatGPT accounts. It supports more than one account and doesn't need any other dependencies. There is no spoken explanation, so this works more as a tool tip than a lesson.

## Key points

- T3 Code is a launch partner of the new 'Sign in with ChatGPT' feature.
- Setup takes 3 steps: install T3 Code, sign in with your ChatGPT account(s), then send your first prompt.
- T3 Code lets you sign in with more than one ChatGPT account at the same time.
- The post says no external dependencies are needed to get started.
