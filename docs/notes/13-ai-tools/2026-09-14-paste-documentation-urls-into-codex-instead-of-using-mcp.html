Paste Documentation URLs into Codex Instead of Using MCP

This note summarises a post by Melvin Vivas on X, posted 14 September 2026. The original belongs to Melvin Vivas.

Topics: AI Dev Tools & Productivity, AI Agents, Tool Use & MCP, Prompt & Context Engineering · Level: beginner

Summary

The creator says that when Codex needs documentation, he just pastes the docs URL into the chat. He asks whether an MCP server is still needed for simply giving a coding agent access to documentation.

Key points

  • To give Codex documentation context, paste the documentation URL straight into the prompt.
  • For simple doc lookups, a coding agent that can fetch web pages may not need a dedicated MCP server.
  • MCP may still be worth it for repeated, structured or authenticated access. Choose based on the use case.
