Summary

A short post sharing HeyGen Skills, which let a coding agent like Claude Code make AI avatar videos. According to the quoted HeyGen announcement, you describe an avatar or paste a photo, and the agent builds the avatar, saves it for future videos and writes the video prompt for you. The clip is only a demo of an avatar introducing itself ("I'm Jake..."). It doesn't walk through any setup steps.

Key points

  • HeyGen Skills are add-on skills that give an AI agent such as Claude Code the ability to make avatar videos.
  • To create an avatar, you describe it in text or paste a photo, and the agent builds it.
  • The avatar is saved and reused in every future video, so you don't have to recreate it.
  • The agent also writes the video prompt so the message comes across well.
  • The pitch: agents could already write text, and now they can also make video content.
  • The post says to 'check the link below' to get started, but no link was included in the material.
