## Summary

Melvin Vivas announces version 0.3.1 of Coworker, his open-source project on GitHub (donvito/coworker). The main new feature is streaming sync between Telegram and Coworker. The 39-second video is a silent demo with no narration, so the release notes on GitHub are the only real source of detail.

## Key points

- Coworker v0.3.1 is a new release of the donvito/coworker GitHub repository.
- Headline feature: two-way streaming sync between Telegram and Coworker ('Telegram <> Coworker streaming sync').
- This suggests you can use and follow Coworker from a Telegram chat, with output streamed as it is produced.
- The video has no speech. Check the GitHub release page for the changelog and setup steps.
