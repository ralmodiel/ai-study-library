Use Cursor's Ask Mode to ask questions without code edits

This note summarises a post by Melvin Vivas on X, posted 21 July 2026. The original belongs to Melvin Vivas.

Summary

Many developers end prompts to Claude or Codex with 'don't write any code, I'm just asking a question.' The creator points out that Cursor has a built-in Ask Mode for exactly this, and says Codex and Claude lack an equivalent mode.

Key points

  • A common workaround is adding 'don't write any code, I'm just asking a question' to prompts for coding agents.
  • Cursor's Ask Mode lets you ask questions about your codebase without the agent changing any code.
  • According to the creator, Codex and Claude don't have a dedicated Ask Mode, so you have to state the constraint in your prompt there.
  • Switch modes based on intent: Ask for exploring and understanding, Agent for making changes.
