Editing a GitHub Repo From ChatGPT Work on iOS

Summary

ChatGPT Work on iOS can make changes directly to a GitHub repo after you connect your GitHub account and mention the repo in the chat. This is separate from remotely controlling the Codex desktop app.

Key points

  • ChatGPT Work on iOS can make changes to your repo from your phone.
  • Setup: connect your GitHub account, then mention the repo in the conversation.
  • This is different from remote-controlling the Codex desktop app.

Resources mentioned

  • ChatGPT Work (iOS) · tool · openai.com · paid
    ChatGPT mode on iOS that can make changes to connected GitHub repos.
  • Codex desktop app (Mac) · tool · openai.com · paid
    Desktop app that runs Codex locally; the mobile app connects to it to control tasks remotely.

  • Connect your GitHub account in ChatGPT and mention a repo to make changes from mobile.
