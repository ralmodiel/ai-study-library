Summary

After the Cursor and X accounts are unified, the Cursor dashboard root redirects to Grok. To use cloud agents in the browser, click 'New Run' or go straight to cursor.com/agents. Automations are hard to find because the Grok view has no left-menu shortcut yet.

Key points

  • After the Cursor–X account unification, the Cursor dashboard root redirects to Grok.
  • Click 'New Run' to reach cloud agents in the browser at cursor.com/agents.
  • Automations have no left-menu shortcut in the Grok view right now, so they take some searching to find.
