# Antigravity 2.0 Adds a /plan Mode for Agent Planning

Melvin Vivas · X video post · 2026-09-27 · [Open on X](https://x.com/melvindvivas/status/2104198176739885565)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Antigravity 2.0 now has a dedicated planning mode, like the one in the Antigravity CLI. When you type /plan, the agent researches the task and drafts an implementation plan, and asks for your approval before writing any code. The creator says plan mode is valuable but optional.

## Key points

- Type /plan in Antigravity 2.0 to switch into planning mode.
- In this mode the agent steps back, thinks through the task and does extensive research before acting.
- It then produces an implementation plan for you to review and asks for your approval.
- The same feature already exists in the Antigravity CLI.
- Plan mode is optional, so you can skip it if you don't like it.
