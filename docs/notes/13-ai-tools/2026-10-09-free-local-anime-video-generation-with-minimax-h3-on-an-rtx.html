Summary

The creator uses Grok Bot to make anime videos with the Minimax H3 model running locally on an RTX 3090 GPU. Because generation runs on his own PC, it costs nothing beyond the hardware.

Key points

  • Minimax H3 video generation can run locally on a consumer RTX 3090 GPU
  • Local generation avoids per-use API costs
  • Grok Bot was used to drive the video creation workflow
