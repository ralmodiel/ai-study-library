## Summary

Points out a usability feature of Grok Build CLI: it shows running background tasks, and you can stop them with a mouse click inside the terminal.

## Key points

- Grok Build CLI shows the tasks that are currently running.
- You can stop background tasks easily with the mouse.
- Being able to see and control background processes is a useful thing to compare across CLI coding agents.
