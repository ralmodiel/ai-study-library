# When one coding model gets stuck, switch to another

Melvin Vivas · X post · 2026-03-03 · [Open on X](https://x.com/melvindvivas/status/2028558916993581411)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator says that when Claude Opus 4.6 gets stuck on a coding task, it stays stuck. He gets the work moving again by switching to OpenAI's Codex 5.3. The practical lesson is to keep a second coding model ready to break out of dead ends.

## Key points

- Claude Opus 4.6 can get stuck in a loop on some coding problems and not recover.
- Switching to a different model (Codex 5.3) can get the task moving again.
- Keeping more than one AI coding assistant available makes you less dependent on one vendor's quirks and outages.
