Summary

The creator installed Meta's Muse Code CLI with a one-line curl script to try the Muse Spark 1.3 model. Using it requires a plan.

Key points

  • Install command: curl -fsSL https://dev.meta.ai/install.sh | bash
  • Muse Code is Meta's coding CLI and gives access to Muse Spark 1.3.
  • Using it requires a plan, so it isn't free to try.
