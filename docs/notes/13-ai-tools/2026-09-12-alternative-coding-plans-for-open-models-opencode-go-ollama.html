Summary

The creator lists subscription plans for coding with open-weight models instead of proprietary ones: OpenCode Go, Ollama Cloud and Nous Cloud (Hermes). He has settled on OpenCode Go after positive feedback and is still researching Ollama and Nous.

Key points

  • OpenCode Go is a coding plan for open models; the creator chose it after good feedback
  • Ollama Cloud is another option for running open models in the cloud
  • Nous Cloud offers the Hermes models
  • These are alternatives to proprietary plans such as Codex Pro

Resources mentioned

  • OpenCode Go · tool · opencode.ai · paid
    A subscription plan from OpenCode for coding with open models.
  • Ollama Cloud · tool · ollama.com · free
    Ollama's cloud service for running open models.
  • Nous Portal · tool · portal.nousresearch.com · paid
    Nous Research's model-access portal, where you can sign up and use hosted models such as Hy3.
