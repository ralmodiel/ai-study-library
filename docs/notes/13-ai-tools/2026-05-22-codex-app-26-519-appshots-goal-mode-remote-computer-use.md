## Summary

Quotes the Codex app 26.519 release notes. New features: Appshots (send any app window to Codex), Goal mode out of beta, and remote computer use while the Mac is locked. The creator uses it to argue for getting a Mac.

## Key points

- Appshots: press both Command keys to send any app window to Codex.
- Goal mode is out of beta in the app, IDE and CLI.
- Remote computer use works while the Mac is locked.
- Several features are Mac-only, which is why the creator recommends a Mac for Codex users.
