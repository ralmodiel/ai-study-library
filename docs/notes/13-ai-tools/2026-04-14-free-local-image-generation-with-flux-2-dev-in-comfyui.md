# Free Local Image Generation with FLUX.2 Dev in ComfyUI

Melvin Vivas · X post · 2026-04-14 · [Open on X](https://x.com/melvindvivas/status/2043764035917885768)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator generates images locally with Black Forest Labs' FLUX.2 Dev model, using ComfyUI. Because the model runs on your own hardware, generations cost nothing.

## Key points

- FLUX.2 Dev is an image generation model from Black Forest Labs that can run locally.
- ComfyUI is a node-based interface for running open image models on your own GPU.
- Running locally means generations are free; you only pay for your own hardware and power.
