Summary

A short news post: Cursor can now import chat sessions from Claude Code. The creator thinks this helps if you start a task in Claude Code and want to carry on in Cursor without losing the conversation.

Key points

  • Cursor now supports importing Claude Code chats.
  • Useful if you start work in Claude Code and then move to Cursor's editor.
  • You keep the earlier conversation context instead of re-explaining the task.
  • The creator is asking for feedback, so he hasn't fully tested it yet.
