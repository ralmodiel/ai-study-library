# Cutting AI Coding Costs by Routing Most Work to Commodity Models

Melvin Vivas · X post · 2026-08-27 · [Open on X](https://x.com/melvindvivas/status/2092966735829995956)

**Topics:** AI Dev Tools & Productivity, LLMOps, Deployment & Monitoring · **Level:** intermediate

## Summary

A quoted case study: a lead engineer used the Pi coding-agent harness to send most of his client work to DeepSeek. He used a stronger model (Fable) only when he needed it. Using cheaper 'commodity models' by default kept his total usage within two $20 plans.

## Key points

- Send everyday coding tasks to cheap commodity models (here DeepSeek).
- Use the more expensive model (Fable) only for tasks that need it.
- With this setup, two $20/month plans covered all of his usage.
- The harness (Pi) was called 'the most important piece' of the setup because it makes switching models easy.
