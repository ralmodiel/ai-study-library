Summary

The creator found that Devin's Ubuntu sandbox has Docker pre-installed. He updated and tested a Docker image entirely in the cloud, which means the agent can run almost anything packaged as a Docker image.

Key points

  • Devin's Ubuntu sandbox comes with Docker pre-installed.
  • You can build, update and test Docker images entirely in the cloud.
  • Because of this, practically any workload packaged as a Docker image can run in Devin's environment.
