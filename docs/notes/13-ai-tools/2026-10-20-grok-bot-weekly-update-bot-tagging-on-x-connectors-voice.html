Summary

This is a product changelog video for Grok Bot, an AI assistant/agent product, quoted in Melvin Vivas's post. Matt from the team walks through the week's releases: redesigned chat cards, a 3x faster bot computer, highlighted draft edits, plus-address email aliases, reading and replying to X DMs, tagging @bot in X threads, new connectors, voice-call memory, fewer notifications, and team features. It shows how a consumer agent product adds tool integrations and memory, but it doesn't teach engineering skills.

Key points

  • Chat cards were redesigned: markdown tables and A/B/C multi-select question cards got a new look.
  • Bot's computer (its sandboxed execution environment) now runs 3x faster, so responses that use it come back quicker.
  • When Grok Bot drafts and then revises Slack or Gmail messages, the edits are now highlighted.
  • Plus-address email aliases give a bot what amounts to unlimited email addresses. Ask the bot in chat to create one.
  • Grok Bot can read and reply to X DMs, with rate limits to stop spam. To tag @bot in an X thread, you first install and configure the X plugin so your X username is linked to your account.
  • New connectors include Robinhood, Coinbase, Trello and others.
  • Voice calls now keep memory of the previous call's full transcript, but only for 30 minutes.
  • Other changes: notifications go only to the device you're active on, teammate invites (team/enterprise), Android Assistant support, team bot access lists, an unread-messages pill on mobile, better scheduling of routine times, and a better Slack sign-in link.
