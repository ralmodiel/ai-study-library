# xAI open-sources the Grok Build coding agent CLI

Melvin Vivas · X post · 2026-07-16 · [Open on X](https://x.com/melvindvivas/status/2077595891280805972)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

xAI has open-sourced Grok Build, its coding-agent harness, including the Git repo for the Grok Build CLI. It also reset usage limits for all users. Anyone can now read and help improve the code of a production coding-agent harness.

## Key points

- Grok Build, xAI's coding agent, is now open source.
- The Git repo for the Grok Build CLI is published.
- xAI says open sourcing lets the community help build a reliable, robust harness.
- Usage limits were reset for all users when it was released.
- The code is listed at x.ai/open-source.
