# Hugging Face hf CLI Skill in Claude Code for Pushing Datasets

Melvin Vivas · X post · 2026-04-22 · [Open on X](https://x.com/melvindvivas/status/2046952007576240494)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator calls the Hugging Face hf CLI a must-have skill in Claude Code if you work with Hugging Face. With it, Claude Code can push datasets to Hugging Face easily.

## Key points

- Install command: hf skills add --claude --global
- The skill lets Claude Code use the hf CLI for Hugging Face tasks.
- The creator highlights how easy it makes pushing datasets.
