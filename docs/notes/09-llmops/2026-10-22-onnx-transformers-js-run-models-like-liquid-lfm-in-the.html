Summary

This is a short interview clip about ONNX (Open Neural Network Exchange), an open standard that lets you train a model in one framework and run it in another. It explains that ONNX defines the operators a model needs, while hardware vendors such as AMD, Intel and Qualcomm build their own runtimes to make it fast. It also shows how Transformers.js can load an ONNX-exported model, like a Liquid Foundation Model (LFM), inside a single-page web app so it runs in the browser with no compiler or separate runtime.

Key points

  • ONNX stands for Open Neural Network Exchange. It is an open standard for moving models between frameworks: you train in one and run inference in another.
  • ONNX defines the set of operators a neural network needs to run inference. That makes a model portable.
  • Speed depends on the hardware vendor. AMD, Intel and Qualcomm each provide their own runtime providers tuned for their chips.
  • Transformers.js can load an ONNX-exported model directly in the browser.
  • You can build a single-page app that loads the ONNX model and runs it right away, with no compiler or separate runtime to install.
  • The example given is running a Liquid Foundation Model (LFM) in the browser through ONNX and Transformers.js.
