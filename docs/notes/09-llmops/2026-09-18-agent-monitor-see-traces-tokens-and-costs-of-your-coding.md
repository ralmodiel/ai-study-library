# Agent Monitor: see traces, tokens and costs of your coding agents

Melvin Vivas · X post · 2026-09-18 · [Open on X](https://x.com/melvindvivas/status/2100681194585432373)

**Topics:** LLMOps, Deployment & Monitoring, AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator shares Agent Monitor, his open-source tool for seeing what coding agents do behind the scenes. It shows subagents, detailed traces, token breakdowns and cost usage. It supports Codex, Claude Code, Pi and Hermes.

## Key points

- Agent Monitor shows what your coding agents are doing behind the scenes.
- It supports traces from Codex, Claude Code, Pi and Hermes.
- It visualizes Codex and Claude Code subagents.
- It includes an advanced traces view, a token breakdown and cost tracking.
- It's useful for debugging agent behavior and controlling spend.
