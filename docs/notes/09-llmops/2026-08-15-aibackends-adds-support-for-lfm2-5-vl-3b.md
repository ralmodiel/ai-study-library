# AIBackends Adds Support for LFM2.5-VL-3B

Melvin Vivas · X post · 2026-08-15 · [Open on X](https://x.com/melvindvivas/status/2088564446138638560)

**Topics:** LLMOps, Deployment & Monitoring · **Level:** beginner

## Summary

The creator says he has finished adding support for Liquid AI's LFM2.5-VL-3B vision model to AIBackends. It is a short progress update that points to the project site.

## Key points

- LFM2.5-VL-3B (a small vision-language model) is now supported in AIBackends.
- Part of the work leading up to the AIBackends 0.4.0 release.
