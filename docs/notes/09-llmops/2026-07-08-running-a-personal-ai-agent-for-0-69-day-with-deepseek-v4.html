Running a Personal AI Agent for $0.69/Day with DeepSeek V4 Flash

Summary

A real cost figure: one day of running DeepSeek V4 Flash through OpenRouter as the main agent model in Hermes cost $0.692. It was used for personal-assistant tasks, not coding. Cheap, fast models can make an always-on personal agent very affordable.

Key points

  • One day of use cost $0.692.
  • Model: DeepSeek V4 Flash, accessed through OpenRouter.
  • Used as the main agent model in Hermes for personal-AI tasks, not coding.
  • Routing a cheap 'flash' model through a gateway like OpenRouter keeps daily agent costs low.
