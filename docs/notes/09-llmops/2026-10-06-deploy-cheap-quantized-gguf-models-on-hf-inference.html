Deploy Cheap Quantized GGUF Models on HF Inference Endpoints with llama.cpp

This note summarises a post by Melvin Vivas on X, posted 6 October 2026. The original belongs to Melvin Vivas.

Topics: LLMOps, Deployment & Monitoring · Level: intermediate

Summary

Explains how to deploy GGUF-quantized models on Hugging Face Inference Endpoints: pick llama.cpp from the Catalog, then choose the model. Quantized models need less GPU VRAM, so they run on cheaper instances. A Qwen3.8-27B Q4_K_M runs on an L4 for about $0.80/hour.

Key points

  • In Hugging Face Inference Endpoints, choose 'llamacpp' from the Catalog menu, then select the GGUF model to deploy.
  • Quantized GGUF models need less GPU VRAM, which makes hosting cheaper.
  • Qwen3.8-27B-UD-Q4_K_M fits on a single L4 instance at about $0.80/hour.
  • Running it 24x7 costs roughly $600/month.
