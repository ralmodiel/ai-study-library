Daytona Offers GPU Sandboxes (H100, RTX 4090/5090)

Summary

Daytona now has GPU sandboxes. If you don't choose a GPU, it starts an H100 by default. The config also supports RTX 4090 and 5090, so check it to avoid paying for more GPU than you need.

Key points

  • Daytona sandboxes can have GPUs attached.
  • The default GPU is an H100 if you don't specify one.
  • The config also supports RTX 4090 and RTX 5090, which are cheaper options.
  • Set the GPU type explicitly to control cost.
