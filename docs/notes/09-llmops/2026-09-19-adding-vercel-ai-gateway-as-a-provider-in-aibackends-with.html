Adding Vercel AI Gateway as a provider in AIBackends with Devin

This note summarises a post by Melvin Vivas on X, posted 19 September 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Melvin Vivas · X post · 2026-09-19 · Open on X

Topics: LLMOps, Deployment & Monitoring, AI Dev Tools & Productivity · Level: intermediate

Summary

The creator used the Devin coding agent to add Vercel AI Gateway (aigw) as a new provider for the Jev model in his open-source AIBackends API. AIBackends is an API server for common AI use cases. It supports several models and providers: local ones through Ollama or LM Studio, and cloud ones through OpenRouter, OpenAI, Anthropic and others.

Key points

  • Jev was free on Vercel AI Gateway for a limited time, so the creator added the gateway as a provider.
  • He assigned the integration work to Devin, an AI coding agent.
  • AIBackends (donvito/ai-backends) is an API server runtime for common AI use cases, with support for multiple models and providers.
  • You can run it locally with Ollama or LM Studio, or in the cloud through OpenRouter, OpenAI, Anthropic and others.
  • Design idea: put a provider abstraction in your backend so you can switch to free or cheaper model endpoints quickly.
