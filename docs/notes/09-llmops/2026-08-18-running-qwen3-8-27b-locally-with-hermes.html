Topics: LLMOps, Deployment & Monitoring, AI Agents, Tool Use & MCP · Level: intermediate

Summary

The creator runs Qwen3.8 27B locally with Hermes and calls the model really good. Its downside is slow thinking (reasoning), but it costs nothing to use.

Key points

  • Qwen3.8 27B runs on local hardware and gives strong results.
  • The trade-off is speed: the reasoning phase is slow on a local setup.
  • Running locally means zero API cost.
