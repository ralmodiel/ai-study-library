llama.cpp's built-in web UI for testing local models

Summary

The default web UI that comes with llama.cpp is now good enough for testing local inference. It lets you pick a model and change reasoning levels, so you don't need a separate chat tool.

Key points

  • llama-server includes a web chat UI out of the box.
  • It supports model selection and changing reasoning levels.
  • It removes the need for a separate tool just to test inference.
