## Summary

Melvin Vivas added per-model usage stats to Agent Monitor, his open-source dashboard for Codex and Claude Code subagents. The tool shows traces, a breakdown of tokens and cost usage, so you can see which models are using your budget.

## Key points

- Agent Monitor now shows usage stats for each model.
- It visualizes Codex and Claude Code subagents.
- Other features: an advanced traces view, a token breakdown and cost usage.
- Tracking usage per model helps you find expensive subagents and plan model routing.
