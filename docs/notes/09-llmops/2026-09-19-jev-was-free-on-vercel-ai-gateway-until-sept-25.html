Summary

The creator shares Vercel's announcement that TypeSafe AI's Jev model was free on Vercel AI Gateway until September 25. That offer has now ended. The model page is still useful to look up.

Key points

  • Vercel described Jev as the fastest-adopted model on the Gateway.
  • It was free to use through Vercel AI Gateway until Sept 25. That date has passed.
  • The model page is at vercel.com/ai-gateway/models/jev.
