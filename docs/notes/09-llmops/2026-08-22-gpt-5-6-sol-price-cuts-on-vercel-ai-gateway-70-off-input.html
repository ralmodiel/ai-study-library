GPT-5.6 Sol Price Cuts on Vercel AI Gateway (70% Off Input)

Summary

Vercel AI Gateway cut prices again for GPT-5.6 Sol. On top of an existing 50% discount, input is now 20% cheaper and output 33% cheaper, for a total of about 70% off input and 83% off output. Model gateways can be a cheap way to reach frontier models.

Key points

  • On top of the 50% discount, input costs 20% less and output 33% less.
  • Total savings: about 70% off input and 83% off output.
  • The discount covers all tiers, including fast mode.
  • Model IDs: openai/gpt-5.6-sol and openai/gpt-5.6-sol-fast.
  • Compare model prices across gateways before choosing a provider.
