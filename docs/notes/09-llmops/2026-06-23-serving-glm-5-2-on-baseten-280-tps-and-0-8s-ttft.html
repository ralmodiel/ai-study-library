Summary

Baseten hosts the open model GLM-5.2 and claims more than 280 tokens per second with under 0.8s time to first token. The creator points it out as a hosting option for GLM 5.2.

Key points

  • GLM-5.2 is available on Baseten's model library
  • Claimed throughput: more than 280 tokens per second
  • Claimed latency: under 0.8s time to first token (TTFT)
  • TPS and TTFT are the key metrics when choosing an inference provider
