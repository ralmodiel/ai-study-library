Hosting a Personal AI Agent: Local Mac Mini vs Cloud VM Privacy Trade-off

Summary

Melvin Vivas asks for cheaper alternatives to a Mac Mini for running a personal AI agent (Hermes). He mentions Hostinger VMs that host Hermes, but questions whether it's safe to put personal data in the cloud. The post shows the trade-off between local hardware and cloud hosting.

Key points

  • Many people buy Mac Minis as always-on local machines for personal AI agents like Hermes.
  • Cloud VMs, such as Hostinger's offering for Hermes, are a cheaper alternative to buying hardware.
  • Putting personal data on a cloud VM raises privacy concerns, so consider what data the agent can reach.
  • Weigh cost against data control before choosing local or cloud hosting for a personal agent.
