The creator runs the new DeepSeek V4 Pro 0813 model through Baseten's inference platform and uses it with Pi as the agent harness. It is a short example of pairing an open model host with a coding agent.

Key points

  • DeepSeek V4 Pro 0813 is available on Baseten.

  • Hosted inference providers let you try new open models without running them yourself.
