Monthly Claude Platform API credits for Max and Team plans

This note summarises a post by Melvin Vivas on X, posted 9 October 2026. The original belongs to Melvin Vivas.

Summary

The creator asks how the new monthly Claude Platform API credits work, and quotes Anthropic's announcement. Max and Team subscribers get a monthly API credit they can spend on any model, in their own code or in third-party harnesses. The full terms are in a Claude Help Center article.

Key points

  • Max 5x plan: $100 in monthly API credits
  • Max 20x plan: $200 in monthly API credits
  • Team plan: up to $500, pooled across the team
  • Credits work on any model, including Haiku 5.5
  • You can use them in your own code or in third-party harnesses
  • The post leaves open whether the credits come on top of your current plan; check the official terms
