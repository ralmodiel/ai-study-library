# CocoIndex v1: Incremental Data Pipelines for AI and Agents

**Topics:** Retrieval-Augmented Generation (RAG), Embeddings & Vector Databases · **Level:** intermediate

## Summary

CocoIndex has reached v1, a redesign of its framework for building incremental data pipelines. The creator recommends it for data transformations that feed AI and agent pipelines, such as indexing data for retrieval.

## Key points

- CocoIndex v1 shipped after 50 v1-alpha releases and about 70 contributors since v0.
- v1 is a fundamental redesign of how you write incremental data pipelines.
- Recommended for data transformation in AI and agent pipelines.
- Incremental pipelines reprocess only the data that changed, which keeps indexes fresh at lower cost.
