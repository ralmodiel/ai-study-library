# Drive Blender from a Coding Agent via Headless Python Scripts

Melvin Vivas · X post · 2026-09-11 · [Open on X](https://x.com/melvindvivas/status/2098229727396049178)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

A tip: once Blender is installed, you can ask Astra in Codex to use it. The agent writes Blender Python scripts and runs them headlessly, so you can make 3D content without opening the Blender GUI.

## Key points

- Install Blender on the same machine where the coding agent runs.
- Tell Astra in Codex, in plain language, to use Blender.
- The agent writes Blender Python scripts and runs them headlessly (no GUI).
- This shows a general pattern: a coding agent can control any scriptable desktop tool through its CLI.
