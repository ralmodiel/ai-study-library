# Cloudflare's 'cf': an agentic CLI for the whole Cloudflare API

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Melvin highlights Cloudflare's new 'cf' CLI, which covers nearly the entire Cloudflare API and is built to be easy for AI agents to use. It can do things like buy a domain, and it has a natural-language command search (cf cli search "...") that returns relevant commands.

## Key points

- 'cf' is an agentic CLI covering nearly the entire Cloudflare API.
- You can do nearly anything from it, including buying a domain.
- Run `cf cli search "<what you want>"` to find the commands you need, e.g. for messages stuck in a queue.
- CLIs with searchable commands are a good fit for coding agents that run shell commands.
