# Coworker with Liquid AI LFM2.5-2.6B via LM Studio on a Mac

Melvin Vivas · X post · 2026-08-26 · [Open on X](https://x.com/melvindvivas/status/2092602149440196867)

**Topics:** AI Agents, Tool Use & MCP, LLMOps, Deployment & Monitoring · **Level:** beginner

## Summary

Shows the creator's Coworker agent app running fully locally on a Mac. It uses Liquid AI's small LFM2.5-2.6B model, served through LM Studio, which suggests small local models can power a desktop agent.

## Key points

- Coworker can use local models served by LM Studio.
- Liquid AI's LFM2.5-2.6B is small enough to run on a Mac.
- Pairing a local model server (LM Studio) with an agent app gives you a fully local AI agent.
