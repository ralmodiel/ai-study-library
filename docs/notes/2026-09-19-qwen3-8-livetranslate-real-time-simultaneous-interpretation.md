# Qwen3.8-LiveTranslate: real-time simultaneous interpretation model

Melvin Vivas · X post · 2026-09-19 · [Open on X](https://x.com/melvindvivas/status/2101264405531070851)

**Topics:** Industry Trends & Job Market, LLM Fundamentals · **Level:** intermediate

## Summary

The creator shares Qwen's announcement of Qwen3.8-LiveTranslate, a model for real-time simultaneous interpretation. It uses an Interleave architecture to improve faithfulness, fluency and conciseness, and it cuts average lag across 60 languages.

## Key points

- Qwen3.8-LiveTranslate is Qwen's next-generation real-time simultaneous interpretation (speech translation) model.
- It is built on an 'Interleave' architecture.
- Qwen says it improves faithfulness, fluency and conciseness of translations.
- Average lagging (LAAL) dropped from 2.8s to 2.3s.
- It covers 60 languages.
- LAAL (Length-Adaptive Average Lagging) is a standard latency metric for simultaneous translation, useful to know when you compare streaming models.
