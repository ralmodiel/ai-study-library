# Claude Desktop Now Available on Linux (Beta)

Melvin Vivas · X post · 2026-07-01 · [Open on X](https://x.com/melvindvivas/status/2071998237150695735)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

Claude Desktop is now in beta on Linux (Ubuntu and Debian). On all paid plans it gives Linux users a desktop app with Claude Code, Claude Cowork and chat, in addition to the browser and terminal options.

## Key points

- Claude Desktop is in beta for Ubuntu and Debian Linux.
- It includes Claude Code, Claude Cowork and chat in one desktop app.
- It is available on all paid Claude plans.
- It adds to the existing browser and terminal (CLI) ways of using Claude.
