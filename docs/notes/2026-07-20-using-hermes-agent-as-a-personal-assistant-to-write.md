**Topics:** AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

The creator used Hermes, his personal AI assistant, to write a bank authorization letter for his sister, which then only needed a signature. It's a practical example of personal-agent use, and the post links to his coaching and livestream site.

## Key points

- A personal AI agent can draft everyday documents such as authorization letters
- The human still reviews, signs and sends the document
- Example of a practical, non-coding use for a personal agent
