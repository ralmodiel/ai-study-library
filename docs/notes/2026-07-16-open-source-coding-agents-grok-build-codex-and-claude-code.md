# Open-source coding agents: Grok Build, Codex, and Claude Code

Melvin Vivas · X post · 2026-07-16 · [Open on X](https://x.com/melvindvivas/status/2077606003928150514)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

The creator points out that two major coding-agent harnesses, xAI's Grok Build and OpenAI's Codex, are now open source, while Anthropic's Claude Code is not. You can read the code of open-source agent harnesses to see how coding agents are built.

## Key points

- Grok Build (xAI's coding agent) is open source.
- OpenAI Codex (the CLI coding agent) is open source.
- Claude Code is not open source yet.
- You can study open-source harnesses to learn how coding agents handle tool use, planning and editing.
