# ZCode: official coding environment for GLM models

Melvin Vivas · X post · 2026-07-02 · [Open on X](https://x.com/melvindvivas/status/2072356371908166018)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

Z.ai released ZCode, an official development environment (harness) for its GLM coding models. GLM Coding Plan subscribers get 1.5x usage quota in ZCode. You can also bring your own key (BYOK) to use existing subscriptions and APIs. It runs on macOS, Windows and Linux.

## Key points

- ZCode is Z.ai's official coding harness for GLM-5.2; the linked page now says GLM-5.3.
- GLM Coding Plan subscribers get 1.5x usage quota inside ZCode.
- BYOK is supported, so it works with your existing subscriptions and API keys.
- Available on macOS, Windows and Linux.
