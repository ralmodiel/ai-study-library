# Muse Spark 1.3 Is Free to Try in OpenCode

Melvin Vivas · X post · 2026-09-03 · [Open on X](https://x.com/melvindvivas/status/2095418975366873434)

**Topics:** AI Dev Tools & Productivity, LLM Fundamentals · **Level:** beginner

## Summary

Meta's Muse Spark 1.3 model is available for free in the OpenCode coding agent, and the creator is testing it. This is a free way to try a new model for coding.

## Key points

- Muse Spark 1.3 is free to use in OpenCode (as of 2026-09-03).
- OpenCode is a coding agent that lets you switch between models.
- In later posts that day the creator gave a negative early impression ("Meta is cooked").
