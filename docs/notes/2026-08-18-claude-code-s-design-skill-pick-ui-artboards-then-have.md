# Claude Code's /design Skill: Pick UI Artboards, Then Have Claude Build One

Melvin Vivas · X post · 2026-08-18 · [Open on X](https://x.com/melvindvivas/status/2089542030812909989)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

Claude Code has a new /design skill, in research preview. It brings Claude Design's artboard workflow into the CLI and Desktop app and is built on artifacts. You get editable UI artboards, pick one, adjust it, and then ask Claude to implement it in code.

## Key points

- /design is a new skill in Claude Code, currently in research preview.
- It brings Claude Design's artboard workflow into the Claude Code CLI and Desktop app.
- It is built on artifacts.
- The steps are: run /design, get several editable UI artboards, pick one, tweak it, then have Claude implement it.
- You settle the visual design before any code is written, so less implementation work gets thrown away.
