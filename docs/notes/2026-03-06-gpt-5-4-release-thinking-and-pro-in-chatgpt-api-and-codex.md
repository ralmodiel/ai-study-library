Melvin Vivas · X post · 2026-03-06 · [Open on X](https://x.com/melvindvivas/status/2029639892037423128)

**Topics:** Industry Trends & Job Market, LLM Fundamentals · **Level:** beginner

## Summary

Announcement that OpenAI's GPT-5.4 Thinking and GPT-5.4 Pro are rolling out in ChatGPT, and GPT-5.4 is also in the API and Codex. OpenAI says it combines its advances in reasoning, coding and agentic workflows in one frontier model.

## Key points

- GPT-5.4 comes in Thinking and Pro variants in ChatGPT.
- It is available in the OpenAI API and in Codex.
- It is positioned as one model for reasoning, coding and agentic workflows.
