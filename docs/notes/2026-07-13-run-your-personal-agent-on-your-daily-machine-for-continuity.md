# Run your personal agent on your daily machine for continuity

Melvin Vivas · X post · 2026-07-13 · [Open on X](https://x.com/melvindvivas/status/2076551731534803302)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator runs the Hermes agent on the Mac he uses every day instead of a separate machine. That way the agent has continuity with his daily work and context. Running it on a dedicated box would defeat the purpose for his use case.

## Key points

- Hermes runs on the creator's everyday Mac, not a separate machine.
- Reason: continuity, since the agent lives where daily work and context are.
- A separate dedicated machine defeats the purpose for this personal-assistant use case.
- Trade-off to keep in mind: running locally on your main machine gives the agent access to your real environment, so check permissions and privacy.
