## Summary

Practical tip for Codex Plus users: the Astra model uses up plan limits faster. Save Astra for exceptional queries and use Luna and Sol for everyday work.

## Key points

- On the Codex Plus plan, Astra burns through usage limits faster.
- Save Astra for exceptional, hard queries only.
- Use Luna and Sol for everyday tasks.
- General principle: send each task to the cheapest model that can handle it.
