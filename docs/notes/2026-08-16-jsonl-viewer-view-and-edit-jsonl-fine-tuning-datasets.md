# jsonl-viewer: view and edit JSONL fine-tuning datasets

Melvin Vivas · X post · 2026-08-16 · [Open on X](https://x.com/melvindvivas/status/2088700005460894139)

**Topics:** Fine-tuning & Model Customization, AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator added a file explorer to jsonl-viewer, his open-source tool for viewing and editing .jsonl files. These files are often used for fine-tuning and training datasets, so the tool helps when you inspect or clean training data.

## Key points

- JSONL (one JSON object per line) is the usual format for fine-tuning and training datasets
- jsonl-viewer lets you view and edit .jsonl files
- The new file explorer lets you browse and open several dataset files
