## Summary

A quick tip: Pi agent users who sign in through ChatGPT/OpenAI Codex need to re-authenticate with the new ChatGPT sign-in option. The old option is now labeled 'OpenAI Codex (legacy)'.

## Key points

- The Pi agent now has a new ChatGPT sign-in option.
- The old auth option is labeled 'OpenAI Codex (legacy)'.
- Re-authenticate with the new sign-in to keep the agent working.
