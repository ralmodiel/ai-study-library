## Summary

The creator runs the LTX 2.3 video generation model locally in ComfyUI on one consumer RTX 3090 GPU. It shows that open video models can run on consumer hardware.

## Key points

- LTX 2.3 (a video generation model) runs locally through ComfyUI.
- The hardware used is one RTX 3090 (24 GB VRAM), a consumer GPU.
