# Handing off an unfinished Codex session to Grok Build

Melvin Vivas · X post · 2026-08-16 · [Open on X](https://x.com/melvindvivas/status/2088975804789375279)

**Topics:** AI Dev Tools & Productivity, Prompt & Context Engineering · **Level:** intermediate

## Summary

The creator explains his workaround after hitting Codex limits. He asked Grok Build to load the unfinished Codex session and complete the task, moving work from one coding agent to another.

## Key points

- When one coding agent hits its usage limit partway through a task, another agent can pick up the work.
- Grok Build was asked to load the existing Codex session and finish the job.
- Keeping session and context files means a task isn't stuck with a single tool.
