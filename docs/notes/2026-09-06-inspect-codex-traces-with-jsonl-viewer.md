## Summary

Codex saves its session traces as JSONL files. The creator's open-source jsonl-viewer lets you open and inspect them to see what the agent did.

## Key points

- Codex session traces are stored as JSONL.
- jsonl-viewer can open these traces for inspection.
- The same tool also views and edits fine-tuning datasets in JSONL format.
