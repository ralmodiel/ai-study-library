# Docker image with coding agents pre-installed on a CUDA + PyTorch base

Melvin Vivas · X post · 2026-09-15 · [Open on X](https://x.com/melvindvivas/status/2099758058876649922)

**Topics:** AI Dev Tools & Productivity, LLMOps, Deployment & Monitoring, Programming & ML Foundations · **Level:** intermediate

## Summary

The creator shares his Docker image, ai-devbox. It comes with coding agents already installed on top of a CUDA and PyTorch base. It is meant for using coding agents to help with ML work on GPU clouds, and he says it works on Runpod.

## Key points

- ai-devbox is a Docker image with coding agents pre-installed.
- Its base image already includes CUDA and PyTorch, so it's ready for GPU ML work.
- Use case: let coding agents help with machine-learning experiments on a GPU machine.
- The creator has tested it on Runpod GPU pods.
