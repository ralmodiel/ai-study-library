# Using Claude Code (Opus 5.5) to cut clips from livestreams

Melvin Vivas · X post · 2026-09-27 · [Open on X](https://x.com/melvindvivas/status/2104206093740306675)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator uses Claude Code with Opus 5.5 as a video editor to make clips from his livestream recordings, which saves him a lot of time. This shows a coding agent doing non-coding automation work. He notes that heavy use might need a Claude Max plan.

## Key points

- Coding agents like Claude Code can automate tasks beyond coding, such as cutting video clips from livestreams.
- The creator reports big time savings when making clips this way.
- Heavy agent use can go past usage limits, so a higher tier like Claude Max may be needed.
