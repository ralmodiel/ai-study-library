# Fine-Tune a Model on Your Own Coding Agent Traces

Melvin Vivas · X post · 2026-08-30 · [Open on X](https://x.com/melvindvivas/status/2093954206478774398)

**Topics:** Fine-tuning & Model Customization, AI Agents, Tool Use & MCP · **Level:** advanced

## Summary

The creator recommends a Hugging Face live tutorial by Ben Burtenshaw on fine-tuning a coding agent with its own agent traces, so it keeps learning over time. The idea is to turn the logs your coding agent already produces into training data.

## Key points

- Coding agent traces (logs of agent sessions) can be used as training data.
- Fine-tuning on those traces is a path to continual learning for a coding agent.
- The tutorial is a free live session on Hugging Face's YouTube channel.
- There is an accompanying article (not linked in the post).
