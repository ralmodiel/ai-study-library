**Topics:** AI Agents, Tool Use & MCP, LLM Fundamentals, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator recommends the GPT-5.6 Luna model for agent 'coworker bots' because it is very cheap through OpenRouter. He links his open-source Coworker desktop app, where AI agents do work for you using local or cloud models.

## Key points

- GPT-5.6 Luna is a low-cost model that works well for agent bots.
- Using it through OpenRouter keeps costs very low.
- Coworker (donvito/coworker) is a desktop app where AI agents do tasks for you.
- Coworker supports both local and cloud models.
