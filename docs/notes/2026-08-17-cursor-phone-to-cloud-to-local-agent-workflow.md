# Cursor Phone-to-Cloud-to-Local Agent Workflow

Melvin Vivas · X post · 2026-08-17 · [Open on X](https://x.com/melvindvivas/status/2089331950028992985)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

The creator explains why he uses Cursor at work: it has an iOS app and cloud agent environments. He starts a task on his phone, lets a cloud agent run it, then hands it off to his local machine. He can also pick different models.

## Key points

- Cursor has an iOS app, so you can start coding tasks from your phone.
- Cursor cloud agents run tasks in remote environments, so work keeps going while you're away from your desk.
- Workflow: start on the phone, let the cloud agent work, then hand off to local development to review and finish.
- Cursor lets you choose between different models for each task.
