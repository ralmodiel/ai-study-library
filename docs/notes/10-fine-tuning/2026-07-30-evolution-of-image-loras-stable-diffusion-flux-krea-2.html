Evolution of Image LoRAs: Stable Diffusion → Flux → Krea 2

Summary

A short note on which base models image LoRAs have been trained on over time: first Stable Diffusion, then Flux, and now Krea 2. It helps you pick a current base model for image LoRA fine-tuning.

Key points

  • Image LoRA base models went SD → Flux → Krea 2
  • Krea 2 is presented as the newest base model for image LoRAs

Resources mentioned

  • Stable Diffusion · tool · stability.ai · free
    Open image-generation model family that was the first popular base for image LoRAs.
  • FLUX · tool · github.com · check price
    Black Forest Labs' family of text-to-image generation models. Some versions have open weights and some are only available through a paid API.
    Also in: Martin Scorsese Joins Black Forest Labs: Storyboarding with FLUX (Melvin Vivas on X · notes), Martin Scorsese Storyboards a Scene with Black Forest Labs' FLUX (Melvin Vivas on X · notes)
  • Krea 2 · tool · krea.ai · check price
    Krea's image-generation model, named as the newest base for image LoRAs.
