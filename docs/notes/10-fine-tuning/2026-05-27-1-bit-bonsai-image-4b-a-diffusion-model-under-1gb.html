1-bit Bonsai Image 4B: A Diffusion Model Under 1GB

Summary

A quoted announcement says the 1-bit Bonsai Image 4B diffusion transformer is only 0.93GB, 8.3x smaller than the full-precision version. It shows how extreme quantization shrinks image models enough to run on small devices.

Key points

  • Bonsai Image 4B is a 4B-parameter diffusion transformer.
  • The 1-bit quantized variant is 0.93GB, which is 8.3x smaller than full precision.
  • This is the maximum-compression variant, built to shrink the footprint as much as possible.
  • An image model under 1GB is small enough for edge and in-browser use.
