# Krea 2 Open Weights: Raw (Undistilled) vs Turbo (Distilled) Image Models

## Summary

This is a short post sharing Krea's announcement that it has released the open weights of its Krea 2 image generation model. There are two versions. Krea 2 Raw is an undistilled checkpoint from mid-training, meant to be fine-tuned. Krea 2 Turbo is a faster distilled version with a wide range of aesthetic styles. The post shows the usual split between a base model you customize and a distilled model you run for fast inference.

## Key points

- Krea has released the open weights of Krea 2, a text-to-image generation model.
- Krea 2 Raw is an undistilled checkpoint taken from mid-training. It is meant as a base for fine-tuning.
- Krea 2 Turbo is a distilled version built for fast generation, with a wide range of aesthetic styles.
- Undistilled base models are usually better for fine-tuning, for example with LoRA. Distilled models trade some flexibility for fewer inference steps and lower latency.
- Open weights let you run, customize and self-host the model instead of depending on a closed API.
