# ML Intern: Post-Train a Model by Chatting (Hugging Face)

Melvin Vivas · X post · 2026-04-23 · [Open on X](https://x.com/melvindvivas/status/2047198947001958632)

**Topics:** Fine-tuning & Model Customization, AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Highlights Hugging Face's ML Intern, an agent that lets you train or post-train models through a chat conversation. It makes fine-tuning possible in plain language, without writing training code yourself.

## Key points

- ML Intern from Hugging Face lets you train models just by chatting.
- People are using it to post-train models.
- Model customization becomes possible through natural-language instructions.
