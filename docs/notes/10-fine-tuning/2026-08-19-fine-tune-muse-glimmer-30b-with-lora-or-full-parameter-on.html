Summary

Muse Glimmer 30B is now on Fireworks' Dedicated Training API for both LoRA and full-parameter fine-tuning. It is a U.S.-developed open-weight model said to be strong at agentic work, tool use and long-horizon reasoning.

Key points

  • Fireworks' Dedicated Training API supports LoRA and full-parameter fine-tuning.
  • Muse Glimmer 30B is an open-weight, U.S.-developed model.
  • It is described as one of the strongest models of its size for agentic work and reliable tool use.
  • LoRA is the cheaper option; full-parameter tuning updates all the weights.

Resources mentioned
