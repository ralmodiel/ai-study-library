Summary

The creator built an open-source viewer and editor for .jsonl files using GLM 5.2 in Cursor. Fine-tuning and training datasets for local LLMs usually come in JSONL format, and he couldn't find a good viewer, so he made one.

Key points

  • Fine-tuning and training datasets are usually stored as .jsonl (one JSON object per line).
  • donvito/jsonl-viewer lets you view and edit .jsonl files.
  • It was built with GLM 5.2 inside Cursor, an example of using AI to build your own small tools.
  • Checking your dataset by eye before fine-tuning a local LLM helps catch formatting errors.
