Fine-tuning Gemma 3 270M with Unsloth for Work Tasks

Summary

The creator says he is fine-tuning Google's tiny Gemma 3 270M model for a work use case with Unsloth, and is thinking about fine-tuning Gemma 4 next. Very small models like this are cheap to customize for narrow tasks.

Key points

  • Gemma 3 270M is a very small open model that suits fine-tuning for narrow tasks.
  • Unsloth is a library that makes fine-tuning faster and lighter on memory.
  • Fine-tuning a tiny model for one work task is fast and cheap.
  • Gemma 4 can also be fine-tuned.
