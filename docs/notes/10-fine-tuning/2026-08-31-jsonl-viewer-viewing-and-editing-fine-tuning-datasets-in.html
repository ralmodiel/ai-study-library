Summary

The creator built jsonl-viewer, an open-source tool for viewing and editing .jsonl (JSON Lines) files. Fine-tuning and training datasets are usually stored in this format. He asks users to try it and request features.

Key points

  • Fine-tuning and training datasets are usually stored as JSON Lines (.jsonl), with one JSON object per line
  • jsonl-viewer lets you view and edit .jsonl files so dataset curation is easier
  • It is open source on GitHub (donvito/jsonl-viewer), and the creator welcomes feature requests
