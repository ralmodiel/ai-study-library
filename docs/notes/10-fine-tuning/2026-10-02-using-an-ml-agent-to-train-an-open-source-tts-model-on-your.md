# Using an ML agent to train an open-source TTS model on your voice

Melvin Vivas · X post · 2026-10-02 · [Open on X](https://x.com/melvindvivas/status/2105946723692707961)

**Topics:** Fine-tuning & Model Customization, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

The creator's ML Grok Bot explained how to fine-tune an open-source text-to-speech model on his own voice. He plans to add a Hugging Face skill so the agent can start a cloud GPU and run the training itself.

## Key points

- An agent with an ML role can walk you through fine-tuning an open-source TTS model on your own voice recordings.
- There are two ways to get compute: plug in your own local GPU, or give the agent a Hugging Face skill so it can start a GPU itself.
- Skills or tools that let an agent provision compute turn it from an advisor into something that actually runs the training.
