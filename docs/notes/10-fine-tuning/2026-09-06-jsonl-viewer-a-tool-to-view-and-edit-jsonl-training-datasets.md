# jsonl-viewer: a tool to view and edit JSONL training datasets

Melvin Vivas · X post · 2026-09-06 · [Open on X](https://x.com/melvindvivas/status/2096278471324598772)

**Topics:** Fine-tuning & Model Customization, AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator shares his open-source jsonl-viewer, a tool for viewing and editing .jsonl files. These files are commonly used for fine-tuning and training datasets. It's useful for checking dataset records before training.

## Key points

- JSONL (one JSON object per line) is the usual format for fine-tuning and training datasets.
- donvito/jsonl-viewer lets you view and edit .jsonl files.
- The creator later says it supports traces, which helps when monitoring agent runs.
