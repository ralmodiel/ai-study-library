# Loop engineering fits fine-tuning better than coding

Melvin Vivas · X post · 2026-08-09 · [Open on X](https://x.com/melvindvivas/status/2086310825439150105)

**Topics:** Fine-tuning & Model Customization, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

The creator argues that loop engineering (automated iterate-and-check loops) works better for fine-tuning models than for coding. Coding outputs vary too much to keep results consistent and accurate.

## Key points

- Automated loops pay off most where results are measurable and repeatable, as in fine-tuning runs.
- Coding tasks vary more, so automated loops have a harder time producing consistent, accurate results.
