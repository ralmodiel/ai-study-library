Summary

The creator shares a free, open-source tool he built for viewing and editing .jsonl files. JSONL is the usual format for fine-tuning and training datasets. He built it because he couldn't find a decent viewer, and recommends it to anyone fine-tuning models.

Key points

  • Fine-tuning and training datasets are usually stored as .jsonl (one JSON object per line).
  • Good JSONL viewers are hard to find, so the creator built his own.
  • donvito/jsonl-viewer lets you view and edit .jsonl files.
  • The tool is free and on GitHub.
  • Inspect and clean your dataset rows before you start training.
