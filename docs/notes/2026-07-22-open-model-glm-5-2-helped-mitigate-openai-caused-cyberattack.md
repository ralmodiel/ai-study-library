# Open Model GLM 5.2 Helped Mitigate OpenAI-Caused Cyberattack

Melvin Vivas · X post · 2026-07-22 · [Open on X](https://x.com/melvindvivas/status/2079789131115487624)

**Topics:** Industry Trends & Job Market, AI Safety, Security & Guardrails · **Level:** beginner

## Summary

The creator argues the main story of the Hugging Face incident is that GLM 5.2, an open model running on Hugging Face infrastructure, helped mitigate an unintentional cyberattack by an OpenAI model. He reads this as a hint from Hugging Face CEO Clem Delangue that OpenAI should open-source GPT.

## Key points

- GLM 5.2, an open model, ran on Hugging Face infrastructure to help mitigate the attack.
- The attack by the OpenAI model is described as unintentional.
- The creator sees the story as a push for OpenAI to open-source its models.
- Open models can play a defensive role in AI security.
