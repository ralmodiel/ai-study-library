# Codex Workflow: Try GPT-5.6 Luna First, Escalate to Sol

Melvin Vivas · X post · 2026-08-31 · [Open on X](https://x.com/melvindvivas/status/2094284747719758001)

**Topics:** AI Dev Tools & Productivity, LLM Fundamentals · **Level:** beginner

## Summary

A model-escalation tip for OpenAI Codex. Start each task with the Luna model, and only move to Sol if Luna can't fix the issue. The creator says this makes better use of usage limits on a Plus plan.

## Key points

- Use Luna as the default model for Codex tasks.
- Switch to Sol only when Luna fails to fix an issue.
- Escalating step by step like this saves usage limits, especially on the Plus plan.
- General pattern: start with the cheaper or lighter model and escalate to the stronger one only when needed.
