# Apply to OpenAI's Codex for Open Source program

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator submitted his open-source project Coworker to OpenAI's Codex for Open Source program and encourages other maintainers to apply. The program gives maintainers Codex access to review code, understand large codebases and improve security coverage.

## Key points

- OpenAI launched Codex for Open Source to support open-source maintainers
- Maintainers can use Codex to review code, understand large codebases and strengthen security coverage
- Approved projects may get free Codex Pro
- Even small projects can apply; the creator's Coworker had only 29 stars
