# Agent Skills: Modular On-Demand Context, and skillsbento

Melvin Vivas · X video post · 2026-03-02 · [Open on X](https://x.com/melvindvivas/status/2028177375884906862)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity, Prompt & Context Engineering · **Level:** beginner

## Summary

Melvin argues that agent skills are the future: modular, on-demand packages that give a coding agent deep context for complex development, beyond simple code completion. He started skillsbento.com, a free, open-source collection of agent skills. He also quotes a post announcing an "Intro to Agent Skills" video.

## Key points

- Agent skills are modular packages of context and instructions that an agent loads on demand.
- They help agents go beyond simple code completion to complex, modern development.
- skillsbento.com is the creator's free, open-source collection of agent skills.
- An "Intro to Agent Skills" video teaches how to create skills.
