## Summary

The creator recommends LM Studio Bionic, a new LM Studio app built around agents for work and coding rather than plain chat. He is testing it with the local model Gemma 4 E4B.

## Key points

- LM Studio Bionic makes running local AI easier.
- Its interface is built around agents, not just chat.
- He tested it with Gemma 4 E4B, a small model that runs locally.
