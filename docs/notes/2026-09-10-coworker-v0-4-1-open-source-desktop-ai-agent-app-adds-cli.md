# Coworker v0.4.1: Open-Source Desktop AI Agent App Adds CLI & Headless Mode

Melvin Vivas · X post · 2026-09-10 · [Open on X](https://x.com/melvindvivas/status/2097923822804767061)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Melvin Vivas released v0.4.1 of Coworker, his open-source desktop app where AI agents do work for you. It runs with both local and cloud models. This release adds a CLI and a headless mode, so the agents can be scripted or run without the GUI.

## Key points

- Coworker is a desktop app where AI agents carry out tasks for the user.
- It supports both local and cloud LLMs.
- v0.4.1 adds a command-line interface (CLI).
- v0.4.1 adds a headless mode for running agents without the desktop UI, which is useful for automation and servers.
- The source code is on GitHub at donvito/coworker.
