## Summary

The creator jokes that everyone is using Opus 4.8 while quoting Anthropic's announcement. The announcement says Claude Sonnet 5's introductory pricing is now permanent. Useful as a reference point for model cost when choosing between models.

## Key points

- Claude Sonnet 5 launched in June at $2 per million input tokens and $10 per million output tokens.
- The introductory price was meant to end August 31 but will now stay the same.
- The creator notes many people still use the pricier Claude Opus 4.8.
- Compare price per token against capability when picking a model for production.
