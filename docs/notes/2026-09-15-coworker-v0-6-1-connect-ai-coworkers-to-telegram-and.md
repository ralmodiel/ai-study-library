## Summary

Melvin Vivas announces version 0.6.1 of Coworker, his own open-source project. This release lets you connect your AI 'coworkers' (agents) to Telegram and Discord bots, so you can talk to them from chat apps.

## Key points

- Coworker is the creator's open-source project on GitHub (donvito/coworker).
- v0.6.1 adds Telegram bot integration.
- v0.6.1 adds Discord bot integration.
- You can download it from the GitHub release page.
