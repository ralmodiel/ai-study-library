# Local Video Generation with LTX 2.3 on an RTX 3090

Melvin Vivas · X post · 2026-04-14 · [Open on X](https://x.com/melvindvivas/status/2043757122148794646)

**Topics:** AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator runs the LTX 2.3 video model in ComfyUI on a consumer RTX 3090 GPU. Each video takes about 4-5 minutes to generate, and because the model is local you can run unlimited generations for free.

## Key points

- Hardware: one RTX 3090 (24 GB VRAM) is enough to run LTX 2.3 video generation.
- Speed: about 4-5 minutes per video.
- Tool: ComfyUI runs the workflow.
- Benefit: unlimited generations with no per-generation cost, unlike cloud video APIs.
