# Tactics to Stretch Your Weekly Codex Usage Limit

Melvin Vivas · X post · 2026-08-20 · [Open on X](https://x.com/melvindvivas/status/2090291371710308762)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

After his Codex limit reset, the creator lists rules for making the weekly quota last. They cover choosing cheaper models by default, limiting /goal runs, supervising Codex while it works, and doing planning in plain ChatGPT.

## Key points

- Use the lighter Luna model by default and save Sol for very complex tasks.
- Avoid /goal; if you do use it, keep the scope small and run it with Luna.
- Stay at your computer while Codex runs so you can stop it if it burns too much quota.
- Do planning in ChatGPT when the task doesn't need your codebase as context yet.
