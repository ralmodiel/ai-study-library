# Coworker v0.5.0: Local Desktop Agent with Markdown Memory

Melvin Vivas · X post · 2026-09-11 · [Open on X](https://x.com/melvindvivas/status/2098290172110811283)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

Release notes for Coworker v0.5.0, the creator's local desktop agent, built using Codex for coding, testing, docs and release. Each coworker now has memory stored as a plain markdown file. You can edit it by chatting, from settings, or by changing the file directly.

## Key points

- Coworker v0.5.0 adds memory for each coworker, plus bug fixes.
- Memory is a simple markdown file, kept simple on purpose because the app runs locally.
- Edit memory by chatting, in settings, or by editing the markdown file.
- The creator used Codex to code, test, document and release the app.
