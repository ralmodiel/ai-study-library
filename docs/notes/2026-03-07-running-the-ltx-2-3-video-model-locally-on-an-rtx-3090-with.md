## Summary

This is a short 5-second demo clip with no speech. Melvin Vivas shows the LTX 2.3 video generation model running locally on one consumer NVIDIA RTX 3090 GPU through ComfyUI. The post has no tutorial steps or settings. Its only lesson is that this recent open video model can run on consumer hardware you own, with no cloud API.

## Key points

- LTX 2.3, a video generation model from the LTX team (@ltx_model), can run locally on one RTX 3090.
- The RTX 3090 is a consumer GPU with 24 GB of VRAM, so you don't need a data-center card to try it.
- ComfyUI, a node-based interface for running diffusion and generative models, was used to run the model.
- The clip is only a demo. It gives no workflow file, settings, resolution or generation times.
- To reproduce it, follow the official ComfyUI and LTX accounts for workflows and model releases.
