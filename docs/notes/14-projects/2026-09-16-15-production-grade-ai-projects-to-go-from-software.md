## Summary

A short reel listing 15 portfolio projects for software engineers moving into AI engineering. The creator says none of them are "I called an API and deployed a chatbot"; each one solves a real problem AI teams face in production. The projects cover evals and regression detection, cost control and gateways, RAG and caching, guardrails, fine-tuning with LoRA, and agent orchestration. The video has no speech; all content is in the caption.

## Key points

- Skip simple 'call an API and deploy a chatbot' projects. Build things that solve real production problems for AI teams.
- Reliability and evals projects: a model regression detection system, a failure forensics tool for AI pipelines, an LLM output arbitration system and an automated eval dataset generator.
- Cost and infrastructure projects: an LLM cost autopilot, a semantic caching layer, an LLM gateway with rate limiting and fallback routing, and an AI feature flag system.
- Retrieval and data projects: a RAG pipeline with hybrid search, Text-to-SQL with guardrails and a multi-modal document processor.
- Prompt and model lifecycle projects: a prompt versioning and A/B testing platform, and a fine-tuning pipeline using LoRA.
- Automation and agent projects: a self-healing documentation bot and an agent orchestration system.
- Commenting 'hired' gets you the creator's step-by-step build guide for all 15 projects and a link to a community with working engineers and recruiters.
