Summary

Bashiri Smith shares a prompt to paste into Claude before you start any coding project. It asks Claude to act as a principal engineer and design three AI-native portfolio projects. Each project comes with an 8-step Claude Code pairing plan: scaffolding, API contracts, data, workers, tests, AI (RAG or agents plus evals), CI/CD and instrumentation. The prompt adds rules that rule out toy apps: each project must handle real-world issues, set measurable eval, latency and cost targets, and use a different domain from the others.

Key points

  • Prompt framing: 'You are a principal engineer tasked with designing three AI-native portfolio projects', with a Claude Code pairing plan of 8 concrete, paste-ready prompts per project.
  • Steps 1-2: Scaffolding (a monorepo file structure for your chosen stack) and Contracts (OpenAPI spec and GraphQL schemas, plus generated typed clients).
  • Steps 3-4: Data (Postgres schemas, migrations, seed scripts, fake data) and Workers (a queue with one job that has retries and dead-letter handling).
  • Steps 5-6: Tests (Jest/PyTest setup with example unit and integration tests) and AI (RAG or agent loops, an evaluation harness and a small golden dataset).
  • Steps 7-8: CI/CD (GitHub Actions for test, build and Docker push) and Instrumentation (OpenTelemetry).
  • Constraint: no toy apps. Each project must deal with backpressure, retries, pagination, partial failures and schema migrations.
  • Use the TypeScript or Python stacks most teams use today. Avoid vague AI claims and set precise evals plus latency and cost targets.
  • Each of the 3 projects should use a different domain and problem type to show range.
