Summary

Bashiri Smith shares a ChatGPT prompt for new coders who aren't landing interviews. The prompt has ChatGPT look at junior and mid-level software engineer job listings on sites like LinkedIn and Wellfound, pick out the skills employers want most, and suggest three unusual, technically hard projects that look like a startup MVP. Each idea comes with a tech stack, advanced features and a suggested way to describe it on a resume.

Key points

  • Basic CRUD apps and portfolio websites are no longer enough to get interviews.
  • Ask ChatGPT to analyze real junior and mid-level software engineer job listings (LinkedIn, Wellfound, other job boards) to find the most in-demand skills and the problems companies are hiring to solve.
  • Ask for 3 unique project ideas that solve real-world problems and give users actual value.
  • Each project should use industry-relevant tech and include at least one hard feature, such as real-time collaboration, data visualization, AI-powered automation or multi-step workflows.
  • The finished project should look like a real startup MVP.
  • For each project, ask for: a one-sentence description, a real-world use case, the full tech stack, advanced features that show technical depth, and a short resume pitch aimed at recruiters.
  • Tell ChatGPT not to suggest generic projects (to-do lists, blogs, weather apps, clones) unless they solve a real user problem in a unique way.

Try this

  • Paste the prompt into ChatGPT before starting any new coding project.
  • Have it analyze junior and mid-level job listings on LinkedIn and Wellfound to find the most in-demand skills.
  • Pick one of the three suggested MVP-style projects and build it, including at least one technically hard feature.
  • Use the generated resume pitch to describe the project on your resume.
  • Skip generic projects like to-do lists, blogs, weather apps and clones.
  • A startup-MVP-style app with real-time collaboration
  • A data-visualization product that solves a real user problem
  • An AI-powered automation tool with multi-step workflows
