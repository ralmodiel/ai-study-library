Local Image Generation Pipeline Built with Claude Code

This note summarises a post by Melvin Vivas on X, posted 18 March 2026. The original belongs to Melvin Vivas.

Melvin Vivas · X post · 2026-03-18 · Open on X

Topics: Portfolio Projects, AI Dev Tools & Productivity · Level: intermediate

Summary

The creator used Claude Code to build a local image-generation pipeline that needs no external APIs. It runs Z-Image-Turbo and FLUX.2 dev on ComfyUI with an RTX 3090. They are considering running it 24/7 to produce stock photos at scale.

Key points

  • The pipeline is fully local and calls no paid APIs.
  • Models used: Z-Image-Turbo and FLUX.2 dev, both running on ComfyUI.
  • Hardware: one RTX 3090.
  • Claude Code was used to build and automate the pipeline.
  • Use case: producing stock photos at scale, possibly running 24/7.
