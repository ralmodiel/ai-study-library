Summary

Bashiri Smith says you should stop learning AI concepts without building anything with them. Instead, build one real project for each core AI engineering skill: RAG, agents, evals, ops, security and machine learning. He links a free Google Drive guide with 27 projects like these, plus his AI engineering community of working AI engineers and recruiters.

Key points

  • Don't just study AI concepts. Turn each skill into a project you actually build.
  • RAG: build a retrieval-augmented generation pipeline that uses hybrid search.
  • Agents: build an agent orchestration system that coordinates multiple agents.
  • Evals: build a generator that creates eval sets from production logs.
  • LLMOps: build a semantic caching layer.
  • Security and guardrails: build a SQL guardrail layer that blocks destructive queries.
  • ML foundations: build a fine-tuning pipeline that uses LoRA.
  • The creator's guide has 27 projects like these, and the caption links to it.
