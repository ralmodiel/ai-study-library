Summary

Bashiri Smith matches five production-oriented AI engineering skills with one portfolio project each. The skills are LLM observability, cost optimization, multimodal AI, prompt engineering and AI regression testing. The caption describes each project, and it links to a Google Drive folder with 27 AI project ideas.

Key points

  • LLM observability: build a failure forensics tool that traces a broken pipeline back to the exact step that failed.
  • Cost optimization: build an LLM cost autopilot that sends each request to the cheapest model that can handle it (model routing).
  • Multimodal AI: build a document processor that turns messy PDFs and scans into clean structured data.
  • Prompt engineering: build a prompt versioning and A/B testing platform that shows which prompt actually performs better.
  • AI regression testing: build a system that runs evals on every commit and blocks changes that lower quality (CI-gated evals).
  • These projects focus on production concerns (tracing, cost, evals, CI) rather than basic chatbot demos.
