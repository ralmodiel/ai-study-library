Summary

This short video links six AI engineering skills to six portfolio projects. The creator presents each one as a real task from the job, not a tutorial. The projects cover RAG reranking, human-in-the-loop agents, LLM request batching, LLM-as-a-judge evals, QLoRA fine-tuning and data exfiltration guardrails. The video ends by promoting the creator's guide of 27 projects (a Google Drive folder) and his Skool community.

Key points

  • Document reranking in RAG -> build a RAG pipeline with a reranking step that re-scores retrieved results before generation.
  • Human approval in agents -> build a human approval agent with human-in-the-loop control over its actions.
  • LLM request batching -> build an LLM request batching layer (inference optimization for throughput and cost).
  • LLM-as-a-judge evals -> build an LLM-as-a-judge eval harness to score model outputs automatically.
  • QLoRA fine-tuning -> build a QLoRA fine-tuning pipeline (efficient fine-tuning of a quantized model with low-rank adapters).
  • Data exfiltration guardrails -> build guardrails that stop sensitive data from leaking (data loss prevention).
  • The creator presents these as actual on-the-job tasks, not tutorial exercises. His full guide covers 27 projects.
