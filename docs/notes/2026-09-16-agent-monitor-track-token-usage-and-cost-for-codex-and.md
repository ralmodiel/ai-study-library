# Agent Monitor: Track Token Usage and Cost for Codex and Claude Code Agents

Melvin Vivas · X video post · 2026-09-16 · 0:01 · 2,236 views · [Open on X](https://x.com/melvindvivas/status/2100152172549959815)

## Summary

Melvin Vivas shows Agent Monitor, his open-source dashboard for watching coding-agent sessions. It shows token usage with a per-agent breakdown and an estimated cost for the main agent and its subagents. It works with OpenAI Codex, Claude Code and Pi. The project is still in development, but you can already use it.

## Key points

- Agent Monitor is an open-source GitHub project (donvito/agent-monitor) for visualizing coding-agent sessions.
- It shows a dashboard of the main Codex agent and its subagents.
- It shows token usage broken down per agent, plus an estimated cost.
- It supports Codex, Claude Code and Pi.
- According to the repo description, it also has an advanced traces view.
- It is still in development but already usable. It's a practical way to see where tokens and money go in multi-agent coding workflows.
