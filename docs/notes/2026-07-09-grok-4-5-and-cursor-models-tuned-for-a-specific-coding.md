# Grok 4.5 and Cursor: Models Tuned for a Specific Coding Harness

Melvin Vivas · X post · 2026-07-09 · [Open on X](https://x.com/melvindvivas/status/2074930765956358176)

**Topics:** AI Dev Tools & Productivity, Industry Trends & Job Market · **Level:** intermediate

## Summary

The creator notes that Grok 4.5 was built with Cursor and guesses it was optimized for Cursor's agent harness. The lesson: a model can work better inside the harness (tools and prompts) it was tuned for, so test it in the environment where you will actually use it.

## Key points

- Grok 4.5 was a collaboration between SpaceX(AI) and Cursor
- The creator guesses (it is not confirmed) that the model was optimized for the Cursor harness
- A model's coding quality can depend on the harness: its tools, prompts and agent loop
- Test a model in the tool you will actually use, not only on general benchmarks
