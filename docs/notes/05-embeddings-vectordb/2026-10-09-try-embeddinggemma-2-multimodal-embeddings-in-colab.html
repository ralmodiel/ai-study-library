Summary

EmbeddingGemma 2 is Google's multimodal embedding model. It maps text, code, images, video and audio into one shared embedding space. The creator shares a Google Colab notebook in his GitHub notebooks repo so you can try it. The quoted post points to Google's developer guide, which uses the sentence-transformers library.

Key points

  • EmbeddingGemma 2 puts text, code, images, video and audio into a single embedding space
  • A shared space enables search across media types, for example a text query that finds images or video
  • The model can be loaded with sentence-transformers or other frameworks
  • Workflow from the guide: load the model through your preferred framework, then embed multimodal content
  • A ready-to-run Colab notebook is in the creator's donvito/notebooks repo
