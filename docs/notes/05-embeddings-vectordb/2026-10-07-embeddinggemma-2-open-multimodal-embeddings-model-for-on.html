EmbeddingGemma 2: open multimodal embeddings model for on-device use

This note summarises a post by Melvin Vivas on X, posted 7 October 2026. The original belongs to Melvin Vivas.

Summary

The creator shares Google's announcement of EmbeddingGemma 2, an open embeddings model built to run on-device, and says Gemma releases excite him more than Gemini ones. The model embeds code, images, video, audio and text, comes in sizes from 270M to 740M parameters, supports Matryoshka embeddings to save storage, and uses the Apache 2 license.

Key points

  • EmbeddingGemma 2 is an open embeddings model built for on-device use.
  • It embeds five kinds of input: code, images, video, audio and text.
  • The model is modular, with sizes from 270M to 740M parameters.
  • It supports Matryoshka embeddings, so you can shorten the vectors to save storage at some cost in quality.
  • It's released under the Apache 2 license, so you can use it commercially.
  • The creator finds Google's open Gemma models more exciting than Gemini.
