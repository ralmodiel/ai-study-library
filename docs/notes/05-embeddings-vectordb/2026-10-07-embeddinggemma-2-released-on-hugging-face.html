Summary

The creator announces that Google's EmbeddingGemma 2 embeddings model is now on Hugging Face. The post links straight to the model page, so you can download it and try it.

Key points

  • EmbeddingGemma 2 is Google's new open embeddings model.
  • It's published on Hugging Face as google/embeddinggemma-2.
  • The Hugging Face model page is where to start if you want to download and test the model.
