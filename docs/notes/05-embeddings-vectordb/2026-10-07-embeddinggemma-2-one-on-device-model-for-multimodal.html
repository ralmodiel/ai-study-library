EmbeddingGemma 2: One On-Device Model for Multimodal Embeddings

Summary

Melvin Vivas shares Google's announcement of EmbeddingGemma 2. It is a compact (740M-parameter) open embedding model built for on-device and edge apps. It maps text, images, video and audio into one shared embedding space, so a single model can handle cross-modal search, retrieval, classification and clustering. Before this, each data type needed its own model.

Key points

  • EmbeddingGemma 2 is a lightweight open model with 740M parameters, built for on-device and edge apps.
  • The first-generation EmbeddingGemma embedded text only. Version 2 natively supports multiple types of data (multimodal).
  • Cross-modal retrieval used to need separate models for text, vision and audio. EmbeddingGemma 2 puts text, images, video, audio, or any mix of them, into one shared embedding space.
  • Example: a picture of a cat, the word 'cat' and the sound of a cat all land close together in the shared embedding space.
  • One model can power search, retrieval, classification and clustering across different data types.
  • The model weights are on Hugging Face, and starter notebooks are in the Gemma Cookbook.
