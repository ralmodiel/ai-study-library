Summary

Gemini Embedding 2 is now generally available. It is a single embedding model that maps text, images, video, audio and PDFs into one shared vector space, which allows search across modalities.

Key points

  • Gemini Embedding 2 is generally available (GA).
  • It embeds 5 modalities (text, images, video, audio, PDFs) into one unified space.
  • It supports up to 8,192 input tokens and 100+ languages.
  • It embeds audio natively, with no transcription step.
  • The output size is flexible.
