# Coworker v0.3.0: Telegram Messaging, File Return and PowerPoint Export

Melvin Vivas · X post · 2026-08-28 · [Open on X](https://x.com/melvindvivas/status/2093306737780724006)

**Topics:** AI Agents, Tool Use & MCP, Portfolio Projects · **Level:** beginner

## Summary

Release notes for Coworker v0.3.0, the creator's open-source AI work agent. You can now message the agent from Telegram, ask it to do research and create files, and get those files sent back to your phone. The release also adds PowerPoint export, avatars, message copy and quality-of-life updates.

## Key points

- Message the Coworker agent from Telegram.
- It can do research, create files and send them back to your phone.
- New in this release: PowerPoint export, avatars, message copy and QoL fixes.
- Available for Mac, Windows and Linux.
