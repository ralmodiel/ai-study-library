## Summary

The creator shares a quoted announcement that Astra brings a new way for Codex to keep and retrieve context when the context window fills up. Instead of repeatedly squashing the history into one summary, Astra keeps notes across context windows so details that build up over a session aren't lost. This is a useful pattern for anyone managing context in long-running coding agents.

## Key points

- When a context window fills, the usual approach is to compress the history into a single summary, and details are lost each time.
- With Astra, Codex keeps notes across context windows, so accumulated details survive without being repeatedly re-summarized.
- Takeaway for context engineering: long agent sessions benefit from external, persistent notes (a form of memory) rather than only rolling summaries.
- The post only quotes the announcement and points to a follow-up post. No setup steps are given.
