# Use computer use to auto-screenshot your app, update the README, and record a demo

Melvin Vivas · X post · 2026-08-27 · [Open on X](https://x.com/melvindvivas/status/2092691303817732209)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Turn on computer use in Codex or Claude so the agent can run your app, take screenshots, and add them to your README. Then go further and ask it to make a video walkthrough of your app.

## Key points

- Turn on computer use in Codex or Claude so the agent can control your desktop and app
- Ask the agent to take screenshots of your running app
- Have it update the README with the screenshot images
- Ask it to make a demo video walkthrough of the app
- This automates documentation and demo work for portfolio projects
