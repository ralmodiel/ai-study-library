## Summary

Melvin Vivas cut OpenAI's DevDay 2026 keynote down to a 5-minute clip of the announcements. The main themes are always-on agents (Dots, ChatGPT Space, specialist Dots), faster model tiers and a new Pro 500 plan, new developer APIs (the Decisions API and the Agents API, plus Amazon Bedrock managed agents), Codex moving fully to the cloud along with a new Codex security cloud, and a way to sell apps through plugin extensions and the OpenAI marketplace. Product names come from a machine-generated transcript, so check them against OpenAI's official DevDay pages.

## Key points

- Dots: what OpenAI calls 'remarkably capable, always on' agents that proactively flag things for you. Enterprise users get a preview of 'specialist Dots', set up like virtual teammates.
- ChatGPT Space: a shared workspace where you, your teammates and your agents work together.
- New model 'GPT 6.1 Sol' (name as transcribed). The 'Fast' tier gives 2x the speed at 2x the price of standard; the new 'Ultra fast' tier gives 8x the speed at 6x the price.
- Pro 500 plan: the highest usage limits, with Ultra fast in ChatGPT and Codex and 25x the usage of Plus.
- New APIs: the Decisions API (preview), an 'AI research intern' that takes on well-defined research tasks, and the Agents API with core building blocks for agents. On AWS, Amazon Bedrock managed agents are powered by OpenAI.
- The agent harness behind Codex and Dots is now open source, tuned for accuracy, speed and low token use. Codex now runs fully in the cloud, so you can start a task on your phone and pick it up in the browser. The new Codex security cloud helps defenders harden their infrastructure.
- OpenAI private intelligence (preview) gives stronger data controls, with ZDR (zero data retention) and private safety processing. The Responses API grew 100x in a year while staying above 99% reliability.
- Distribution: plugin extensions let developers build full apps that feel native to ChatGPT. Plugins can be suggested during a conversation, users can sign into apps with tokens from their ChatGPT plan, and the OpenAI marketplace launched with 30+ partners (CodeRabbit, Notion, Vercel). Enterprises can spend part of their existing OpenAI commitment on marketplace products.
