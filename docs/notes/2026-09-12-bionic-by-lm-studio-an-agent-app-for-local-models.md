# Bionic by LM Studio: An Agent App for Local Models

Melvin Vivas · X post · 2026-09-12 · [Open on X](https://x.com/melvindvivas/status/2098615595113791728)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity, LLMOps, Deployment & Monitoring · **Level:** intermediate

## Summary

LM Studio has released Bionic, a new agent app that works with models running locally. The creator plans to try it with Qwen3.8 27B on an RTX 3090. This setup lets you run agents without cloud APIs.

## Key points

- Bionic is LM Studio's new agent app.
- It works with models running locally.
- The creator's planned setup is Qwen3.8 27B on one RTX 3090 GPU (24 GB).
