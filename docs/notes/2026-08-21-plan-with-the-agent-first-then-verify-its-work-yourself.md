# Plan With the Agent First, Then Verify Its Work Yourself

Melvin Vivas · X post · 2026-08-21 · [Open on X](https://x.com/melvindvivas/status/2090704432120152353)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

The creator ran Cursor's agent for a few hours from the iPhone app. Before it started building, he worked through the plan with the agent to make sure every spec from the product owner was covered. The last step, verifying the result, still had to be done by hand.

## Key points

- Work through the implementation plan with the agent before it starts writing code.
- Check that the plan covers every spec from the product owner or stakeholder before you let the agent run.
- Long agent runs can be started and left running from Cursor's iPhone app.
- Final verification is still a human job. Set aside time to test the result by hand.
