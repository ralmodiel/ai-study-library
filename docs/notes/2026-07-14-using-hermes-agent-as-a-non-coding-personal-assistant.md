# Using Hermes Agent as a Non-Coding Personal Assistant

Melvin Vivas · X post · 2026-07-14 · [Open on X](https://x.com/melvindvivas/status/2076933970810548513)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator lists what he actually uses the Hermes agent for. None of it is coding: school deadline reminders from screenshots, sports updates, shopping research, entertainment picks, business ideas, summarizing videos and generating videos. It shows that a general agent can work as an everyday personal assistant.

## Key points

- Send screenshots from apps (e.g., a kids' school app) and ask the agent to track and remind you of deadlines
- Use it for live info lookups like sports results (F1 British Grand Prix, Wimbledon)
- Use it for product research, e.g., finding a replacement monitor
- Ask it for recommendations (K-dramas, cat breeds) and brainstorming (non-software business ideas)
- Have it summarize a video posted on X, or generate a video
- The takeaway: agents like Hermes are useful well beyond coding
