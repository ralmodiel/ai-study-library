## Summary

The creator no longer makes invoices by hand. Claude Cowork generates them every month. This is an example of using an AI agent for recurring admin tasks.

## Key points

- Claude Cowork can automate recurring business tasks such as invoicing.
- The creator runs invoice creation through Cowork every month.
- Recurring, template-based paperwork is a good fit for agent automation.
