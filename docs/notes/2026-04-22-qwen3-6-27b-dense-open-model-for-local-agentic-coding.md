## Summary

The creator calls Qwen3.6-27B a must-try for coding locally. It is a dense open-source model that the Qwen team says surpasses Qwen3.5-397B-A17B on all major coding benchmarks.

## Key points

- Qwen3.6-27B is a dense (not mixture-of-experts) open-source model.
- Its focus is strong agentic coding performance.
- It reportedly beats the much larger Qwen3.5-397B-A17B on coding benchmarks.
- The creator recommends it for local coding.
