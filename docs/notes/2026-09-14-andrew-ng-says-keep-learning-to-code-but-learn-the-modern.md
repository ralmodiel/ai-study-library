# Andrew Ng Says Keep Learning to Code, but Learn the Modern Way

## Summary

The video starts with Andrew Ng's comment that telling people to stop learning to code because AI will automate it may be some of the worst career advice ever given. His reason is that better tools make software engineering easier, so more people should code, not fewer. The creator agrees that coding and structured problem-solving are still very valuable. He also argues that older ways of learning (outdated bootcamps, generic online courses, some college CS programs, and spending months on HTML, CSS and React) will slow you down, and he points to his free AI engineer roadmap instead.

## Key points

- Andrew Ng: advising people not to learn to code because of AI may be 'some of the worst career advice ever given'.
- Ng's reasoning: as better tools make software engineering easier, more people should do it, not fewer.
- Coding and structured problem-solving are still among the most valuable skills.
- Learning to code the way people did in 2023 is a waste of time. Many bootcamps, online courses, certifications and university CS programs are behind.
- Spending 6 months on HTML, CSS and React just to build basic websites is a trap: you learn the wrong things and fall about 6 months behind.
- The creator offers a free step-by-step path meant to get you job-ready for the 2027 market.
