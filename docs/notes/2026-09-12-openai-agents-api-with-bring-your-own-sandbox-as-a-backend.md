# OpenAI Agents API with Bring Your Own Sandbox as a backend for a 'software factory'

Melvin Vivas · X post · 2026-09-12 · [Open on X](https://x.com/melvindvivas/status/2098729077163401577)

**Topics:** AI Agents, Tool Use & MCP, AI System Design & Architecture, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator plans to use OpenAI's newly launched Agents API as the backend for a 'Software Factory' app whose UI was generated by Codex with GPT-6 Astra (Ultra). The Agents API supports BYOS (Bring Your Own Sandbox), so agents can run code in sandbox providers such as Blaxel, Cloudflare, Daytona, E2B, Modal and Vercel.

## Key points

- OpenAI launched an Agents API meant to be the backend for apps that build software with agents.
- It supports BYOS (Bring Your Own Sandbox): plug in Blaxel, Cloudflare, Daytona, E2B, Modal or Vercel to run code.
- The creator first had Codex with Astra (Ultra) build only the UI of a Software Factory app, then picked a backend.
- A useful workflow: prototype the UI with a coding agent first, then connect an agent API backend.
