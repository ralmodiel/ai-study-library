# Brainstorm in ChatGPT chat, save Codex quota for coding

Melvin Vivas · X post · 2026-08-23 · [Open on X](https://x.com/melvindvivas/status/2091208506921931148)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator brainstorms product ideas in regular ChatGPT chat. He doesn't switch to Work mode even when ChatGPT suggests it, so his Codex usage stays available for coding. Plain ChatGPT can still create files and mockup images.

## Key points

- Use regular ChatGPT chat to brainstorm product ideas
- Skip ChatGPT's suggestion to switch to Work so your Codex usage limits are kept for coding
- Regular ChatGPT can still create files and mockup images for early product ideas
