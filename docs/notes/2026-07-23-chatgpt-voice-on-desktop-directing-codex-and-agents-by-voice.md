# ChatGPT Voice on Desktop: Directing Codex and Agents by Voice

Melvin Vivas · X video post · 2026-07-23 · 1:08 · 92 views · [Open on X](https://x.com/melvindvivas/status/2080385485999063342)

**Topics:** AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · **Level:** beginner

## Summary

Melvin Vivas reshares OpenAI's announcement that ChatGPT Voice now runs in the ChatGPT desktop app. A one-minute demo shows someone using only their voice to control the computer, draft launch blog posts, brainstorm a feature and ask for pushback, and send Codex to check feature flags and find a bug's root cause in a new thread with a pull request. The announcement says the feature runs on GPT-Live, which can speak, listen and coordinate work in the app at the same time. The post is a product showcase, not a tutorial.

## Key points

- ChatGPT Voice is now in the ChatGPT desktop app and is rolling out globally (according to the quoted announcement).
- With voice alone you can control your computer and direct several agents running in ChatGPT Work or Codex.
- It runs on GPT-Live, a model that can speak, listen and coordinate work in the app at the same time.
- Demo workflow: draft launch blog posts by voice, then 'ramble' about a feature idea and ask the assistant to ask questions and push back.
- Codex gets voice-delegated tasks: check that feature flags are configured correctly, and spin up a new thread to open a pull request and find a bug's root cause (here, a misconfigured feature flag).
- Goal-based delegation: set a goal, tag the team for review later and check in from your phone; the assistant creates follow-up goals.
