## Summary

Melvin Vivas shows a short demo (no narration) of an iOS app built by the AI coding agent Devin. The app runs the small Gemma4-E2B model locally on an iPhone. He says he built it with Devin's SWE-2 Max model, which he says is free right now. The post shows what agentic coding tools can do, but it doesn't explain how the app was built.

## Key points

- Devin, the AI software-engineering agent from Cognition, was asked to build a complete iOS app from a prompt.
- The app runs the Gemma4-E2B model locally on the iPhone, with on-device inference and no cloud API.
- The model used inside Devin was SWE-2 Max, which the creator says was free to use when he posted (Sept 2026).
- Gemma 'E2B' variants are small, edge-sized models built for phones and other devices, which is why they can run on an iPhone.
- The video has no narration, so implementation details are not shown. Treat it as a demo, not a tutorial.
