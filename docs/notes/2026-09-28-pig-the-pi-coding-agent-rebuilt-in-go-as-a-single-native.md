# PiG: The Pi Coding Agent Rebuilt in Go as a Single Native Binary

## Summary

Melvin Vivas shares an announcement for PiG, a rebuild of the Pi coding agent (@pidotdev) in Go. PiG ships as a single native binary. It supports live extensions in several languages and derivative harnesses called "Piglets," and it aims to keep all of Pi's features. The video has no speech, so the caption and the linked project site are the only content.

## Key points

- PiG is described as a faithful Go implementation of the Pi coding agent.
- It ships as one native binary, so there is no separate runtime to install.
- It supports live extensions written in multiple languages.
- You can build derivative harnesses, called "Piglets," on top of it.
- The goal is to keep everything Pi does, just written in Go.
- More details are at pi-in-go.dev.
