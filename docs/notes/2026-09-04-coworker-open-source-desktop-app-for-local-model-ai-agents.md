# Coworker: Open-Source Desktop App for Local-Model AI Agents

Melvin Vivas · X post · 2026-09-04 · [Open on X](https://x.com/melvindvivas/status/2095864372132458864)

**Topics:** AI Agents, Tool Use & MCP, AI Dev Tools & Productivity, Portfolio Projects · **Level:** beginner

## Summary

The creator introduces Coworker, a desktop app where AI agents do work for you using local or cloud models. It includes Telegram integration and browser use, and installs on Mac, Windows and Linux. The source code is on GitHub and downloads are on his website.

## Key points

- Coworker lets you run your 'bots' (agents) on local models as well as cloud models.
- It has Telegram integration, so you can talk to agents from chat.
- It supports browser use for web automation.
- It installs easily on macOS, Windows and Linux.
- Source: github.com/donvito/coworker; download: donvitocodes.com/coworker.
