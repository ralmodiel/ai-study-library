## Summary

This is a short post with a video and no narration. It shares a quoted post claiming that Z.ai's GLM-5.1 model did better than Claude Code (Opus 4.6) on an informal test: building a Three.js racing game. The quoted author was impressed that GLM-5.1 got car physics with working drift mechanics right on the first try. They also liked how well it kept improving its own output. It is an anecdotal comparison of coding models, not a formal benchmark.

## Key points

- GLM-5.1 is a model from Z.ai (@Zai_org), shown here as a challenger to Claude Code running Opus 4.6 for coding work.
- The test was informal: ask the model to build a Three.js racing game and judge the result.
- GLM-5.1 reportedly got car physics with real drift mechanics right in one shot. The author calls this hard to do.
- The author's favorite strength was how well it iterates on its own work (the caption is cut off at this point).
- Building a small, demanding project like a physics game is a quick hands-on way to compare coding models. Results from one person's test are anecdotal.
