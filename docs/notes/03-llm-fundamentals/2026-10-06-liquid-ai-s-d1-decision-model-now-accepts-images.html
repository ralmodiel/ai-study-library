Liquid AI's d1 Decision Model Now Accepts Images

This note summarises a post by Melvin Vivas on X, posted 6 October 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Topics: LLM Fundamentals, Industry Trends & Job Market · Level: intermediate

Summary

Liquid AI added vision to d1, its first 'decision model', so it now takes images, text or both as input. Liquid AI tested it against GPT-6.1 Sol and Claude Opus 5.5 on six real applications, from filtering support tickets to inspecting circuit boards. According to Liquid AI, d1 matches or beats GPT-6.1 Sol.

Key points

  • d1 is a decision model, built for classification and decision tasks.
  • It now accepts image, text or image + text input.
  • It was tested on six real applications, including support-ticket filtering and circuit-board inspection.
  • Liquid AI says d1 matches or beats GPT-6.1 Sol in these tests.
