Claude Opus 4.8 on OpenRouter: Pricing and Fast Mode

This note summarises a post by Melvin Vivas on X, posted 29 May 2026. The original belongs to Melvin Vivas.

Summary

Claude Opus 4.8 is now on OpenRouter at the same price as Opus 4.7. The quoted post says it improves agentic coding, reasoning and computer use, and that Fast Mode trades higher cost for speed.

Key points

  • Opus 4.8 costs the same as Opus 4.7.
  • It improves agentic coding, reasoning and computer use.
  • It is about 4x less likely than 4.7 to let code flaws pass without comment.
  • Opus 4.8 Fast Mode costs 2x as much and runs about 2.5x faster.
  • OpenRouter lets you call the model through one unified API gateway.
