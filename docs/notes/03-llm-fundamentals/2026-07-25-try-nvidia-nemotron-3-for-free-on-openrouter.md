## Summary

A short tip that NVIDIA's Nemotron 3 model can be used for free on OpenRouter. The creator is testing it with his Hermes personal AI agent. This is a quick way to try a new model without paying.

## Key points

- Nemotron 3 is available as a free model on OpenRouter.
- OpenRouter gives you one API for many models, so you can swap models without changing code.
- The creator is testing Nemotron 3 as the model behind his Hermes agent.
