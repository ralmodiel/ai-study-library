# Free GLM-5.2 via Hugging Face Inference Providers in coding agents

Melvin Vivas · X post · 2026-06-19 · [Open on X](https://x.com/melvindvivas/status/2067678312537915410)

**Topics:** LLM Fundamentals, AI Dev Tools & Productivity, LLMOps, Deployment & Monitoring · **Level:** intermediate

## Summary

For a limited time, Hugging Face made GLM-5.2 free through its Inference Providers API across several providers. The model can be plugged into coding agents such as Pi, opencode, Codex or Claude Code.

## Key points

- GLM-5.2 was free for about 6 hours through Hugging Face Inference Providers.
- Covered providers: Z.ai, Together AI, Novita, Fireworks and DeepInfra (Hugging Face paid the cost).
- Inference Providers gives one API that routes to many hosting providers of open models.
- You can set it up as the model backend for Pi, opencode, Codex, Claude Code or any coding agent.
