Run Local LLMs on the Computer You Already Have: A Beginner's Path

Summary

Melvin Vivas argues that you don't need an expensive multi-GPU rig to start running AI models locally. Your current computer works, even running on CPU only. He lays out a starter path: install Ollama or LM Studio, run a small 3B–8B model, try GGUF models, then move on to llama.cpp and Unsloth once you know the basics.

Key points

  • You don't need a $5,000 rig with multiple GPUs and huge amounts of RAM to start with local models.
  • You can start on the computer you have, even on CPU only. It will be slower, but that's fine for learning.
  • At the start, the goal is to understand how local models work, not to build the fastest server.
  • Step 1: install Ollama or LM Studio, the easiest ways to run models locally.
  • Step 2: start with a small model in the 3B–8B parameter range.
  • Step 3: try GGUF models (a quantized model file format).
  • Step 4: once you know the basics, experiment with llama.cpp and Unsloth.
  • Don't buy hardware first and don't feel you need to be an ML engineer. Just get a model running.

Try this

  • Use the computer you already have, even CPU only, before buying any hardware.
  • Install Ollama or LM Studio.
  • Download and run a small 3B–8B model.
  • Try running GGUF models.
  • Once you know the basics, experiment with llama.cpp and Unsloth.
