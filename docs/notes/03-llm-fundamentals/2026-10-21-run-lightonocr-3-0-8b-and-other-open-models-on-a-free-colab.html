Run LightOnOCR-3 0.8B and Other Open Models on a Free Colab T4

Summary

Melvin Vivas added a notebook for the LightOnOCR-3 0.8B vision/OCR model to his public GitHub repo of Colab notebooks. The repo also has notebooks for newer open models that fit on a Google Colab T4 GPU instance, so you can try local-model inference and fine-tuning without paying for hardware.

Key points

  • LightOnOCR-3 is a small (0.8B-parameter) vision model for OCR, small enough to run on a free Colab T4 GPU.
  • The donvito/notebooks repo collects notebooks for fine-tuning and running local models, all made to run in Google Colab.
  • The repo also has notebooks for other new open models that fit on a T4 GPU instance.
  • A T4 GPU is a good limit to aim for: models under about 1B parameters, or quantized larger ones, fit comfortably.
