Summary

Z.ai released GLM-5-Turbo, a faster version of GLM-5 tuned for agent environments such as OpenClaw. You can access it through the GLM Coding Plan, OpenRouter, or the Z.ai API.

Key points

  • GLM-5-Turbo is a high-speed variant of GLM-5.
  • It is built for agent-driven environments such as OpenClaw.
  • Access options: the GLM Coding Plan Max subscription, OpenRouter, or the Z.ai API.
