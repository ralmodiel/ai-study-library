**Topics:** LLM Fundamentals, Prompt & Context Engineering · **Level:** intermediate

## Summary

The creator shares a free Google Colab notebook that shows how to use Fastino Labs' GLiNER2.5 model for information extraction through his aibackends library. It is a hands-on way to try a small, specialised extraction model instead of a general LLM.

## Key points

- GLiNER2.5 is an extraction model from Fastino Labs.
- The notebook runs it through the creator's aibackends project.
- The notebook is in the repo at examples/notebooks/gliner25_extraction_colab.ipynb and opens straight in Colab.
- Small, specialised models like GLiNER can handle structured extraction tasks such as named entities.
