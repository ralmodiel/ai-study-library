# GLM-5.2 released: open weights, 1M context, two reasoning levels

Melvin Vivas · X post · 2026-06-18 · [Open on X](https://x.com/melvindvivas/status/2067599943364481217)

**Topics:** LLM Fundamentals, Industry Trends & Job Market · **Level:** intermediate

## Summary

Z.ai released GLM-5.2, an open-weights frontier model. It is better at coding and agentic tasks, supports a 1M-token context window and has two reasoning-effort levels.

## Key points

- GLM-5.2 is an open-weights frontier model.
- It is significantly better at coding and agentic tasks.
- It handles long tasks well and has a 1M-token context window.
- Two reasoning-effort levels: GLM-5.2 (max) for top performance and GLM-5.2 (high) as a more balanced option.
