Claude Haiku 5.5 in Devin: beats Sonnet 5 at about 1/8 the cost

This note summarises a post by Melvin Vivas on X, posted 8 October 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Melvin Vivas · X post · 2026-10-08 · Open on X

Topics: LLM Fundamentals, AI Dev Tools & Productivity, AI Agents, Tool Use & MCP · Level: intermediate

Summary

Claude Haiku 5.5 is now available in the Devin coding agent. It scores 58.4% on the FrontierCode 1.1 benchmark, ahead of Sonnet 5 at about an eighth of the cost per task. The post also recommends it as a cheap 'sidekick' model in Devin's Fusion mode, with Opus 5.5 as the Lead model.

Key points

  • Claude Haiku 5.5 is now available in Devin
  • Haiku 5.5 scores 58.4% on FrontierCode 1.1, ahead of Sonnet 5
  • It costs about one-eighth as much per task as Sonnet 5
  • Fusion pairs a strong 'Lead' model (Opus 5.5) with a cheaper 'sidekick' model (Haiku 5.5)
  • Available in Devin Desktop and Devin CLI
  • Lesson: small, cheap models can beat bigger ones on cost per task, so compare benchmark scores together with cost
