# GLM-5.2 by Z.ai: open-weights model with a 1M-token context

Melvin Vivas · X post · 2026-06-17 · [Open on X](https://x.com/melvindvivas/status/2066945216503042394)

**Topics:** LLM Fundamentals, AI Agents, Tool Use & MCP, Industry Trends & Job Market · **Level:** intermediate

## Summary

Z.ai released GLM-5.2, a frontier-level model with open weights. It improves on coding and agent tasks, handles long multi-step tasks, and has a 1M-token context window. It offers two reasoning levels: max and high.

## Key points

- GLM-5.2 comes from Z.ai (@Zai_org) and has open weights.
- It is significantly better at coding and agentic tasks.
- It has a 1M-token context window and strong long-horizon capabilities.
- It has two reasoning levels: GLM-5.2 (max) for the hardest problems and GLM-5.2 (high) as a balanced option.
- It's an open-weights option to consider next to closed frontier models.
