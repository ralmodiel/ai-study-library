Liquid AI Open d1: d1-3B and d1-omni-600M Decision Models

Summary

Melvin Vivas says a Colab notebook with examples for Liquid AI's d1-3B decision model is coming. He is building it with his Grok Bot coding agent through Cursor's Cloud agent. The quoted Liquid AI post explains when to use d1-3B (high-quality text and vision decisions) and when to use the experimental d1-omni-600M (when footprint matters). It also links the release blog and the Hugging Face weights.

Key points

  • Liquid AI's d1 family is made of 'decision models', with weights you can download, fine-tune and deploy locally.
  • d1-3B: for high-quality decisions from text and vision.
  • d1-omni-600M: experimental, small model for when footprint matters.
  • The weights are on Hugging Face under LiquidAI/d1-3b.
  • The creator uses a coding agent (Grok Bot through Cursor Cloud agent) to write example Colab notebooks.
  • The Colab notebook had not been released when this was posted.
