# Qwen3.5 Multimodal Model Now on NVIDIA AI Endpoints

Melvin Vivas · X post · 2026-03-01 · [Open on X](https://x.com/melvindvivas/status/2028079565323768069)

**Topics:** LLM Fundamentals, AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

Alibaba's Qwen3.5 is now available through NVIDIA AI endpoints. It is a frontier-class vision-language model built for native multimodal agents. It has about 400B parameters, combines Mixture-of-Experts with Gated Delta Networks, and reasons across text, code and vision, including understanding and navigating user interfaces.

## Key points

- Qwen3.5 comes from Alibaba's Qwen team and is available on NVIDIA AI endpoints.
- It is a vision-language model (VLM) built for native multimodal agents.
- It has about 400B parameters, combining MoE and Gated Delta Networks.
- It reasons across text, code and vision, and can understand and navigate user interfaces.
