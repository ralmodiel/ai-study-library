Summary

Melvin shares Google's announcement of new Gemma documentation for developers. The new site adds a global model selector that customizes code snippets. It also supports agents better, for example by letting you turn any page into Markdown.

Key points

  • Gemma has a new documentation home for exploring, experimenting and building.
  • A global model selector customizes code snippets for the Gemma model you choose.
  • Better agent support: any docs page can be turned into Markdown, which is useful as LLM or agent context.
