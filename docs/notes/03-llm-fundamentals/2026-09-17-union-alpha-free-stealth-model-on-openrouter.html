Summary

The creator shares a new free stealth model, Union Alpha, available on OpenRouter. It is described as a multimodal model for research, coding and agentic workflows, with a 256K context window and tool calling.

Key points

  • Union Alpha is free to use on OpenRouter as a stealth model.
  • It has a 256K context window.
  • It supports tool calling, so it works for agentic workflows.
  • It is pitched as multimodal, with frontier-level general performance for research and coding.
  • Testers are asked to share feedback.
