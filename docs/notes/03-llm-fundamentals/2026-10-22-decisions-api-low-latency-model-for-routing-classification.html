Decisions API: Low-Latency Model for Routing, Classification and Actions

Summary

Melvin Vivas shares a launch video for the Decisions API, now in public beta. It's a fast "decision model" that lets an app choose the right model, tool or action in near real time. The demo shows three uses: sorting loose user input into sales leads, steering a car in a game from video frames, and picking facial expressions for an animated character while GPT Live 1 handles the voice. Melvin says he hasn't tried it himself. He just notes that decision models are becoming popular.

Key points

  • The Decisions API is in public beta for all developers. Its job is to let an app choose the right model, tool or action in near real time.
  • It is claimed to make decisions up to 10x faster than GPT-6 Luna through the Responses API.
  • In the sales-lead demo, the server responded in under 100 ms. The video says it was not sped up.
  • Use case 1: sorting messy free-text user input into sales leads.
  • Use case 2: a game where the API reads frames of the road and obstacles and steers the car to the correct lane. It keeps up even at higher speeds, in a fraction of the time a reasoning model would take.
  • Use case 3: a split setup where GPT Live 1 handles voice and the Decisions API picks the character's expression while the user talks.
  • Design pattern: use a small, fast decision model for routing and classification next to bigger or slower models. This keeps interactions feeling instant.
  • The creator says he hasn't tried it, so treat the speed claims as the vendor's own until you test them.
