Liquid AI's LFM2.5-24B-A2B: a local MoE model for agent tasks

Summary

Liquid AI released LFM2.5-24B-A2B, the largest model in the LFM2.5 family. It is an efficient local model for laptops and PCs that works through multi-step tasks inside agent harnesses. The creator plans to try it in a Colab notebook first, to see if it fits on a T4 GPU, and then with Coworker.

Key points

  • It has 24B total parameters but only 2B active per token (mixture-of-experts style), which makes it efficient.
  • The context window is expanded to 131K tokens.
  • It is built to run locally on laptops and PCs for multi-step tasks inside popular agent harnesses.
  • A practical first test: load it in a Google Colab notebook and check whether it fits on a free T4 GPU.
