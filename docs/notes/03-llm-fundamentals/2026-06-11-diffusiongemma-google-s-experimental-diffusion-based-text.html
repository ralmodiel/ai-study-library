Summary

Melvin Vivas shares Google's announcement of DiffusionGemma, an experimental open model under the Apache 2.0 license. Instead of writing text one token at a time, it generates whole blocks of text at once using a diffusion approach, with the goal of faster generation.

Key points

  • DiffusionGemma is an experimental open model in the Gemma family.
  • Released under the Apache 2.0 license, so it is free to use, including commercially.
  • It generates entire blocks of text at once instead of one token at a time like standard autoregressive LLMs.
  • The main aim of diffusion text generation is faster output.
