# Gemma 4 26B for OCR in LM Studio

**Topics:** LLM Fundamentals, AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator found Gemma 4 26B very good at OCR (reading text from images) when he ran it locally in LM Studio. This points to a local, private option for extracting text from documents.

## Key points

- Gemma 4 26B can read text from images (OCR) well.
- LM Studio is a desktop app for running local models, and it supports image input.
- Running OCR locally keeps your documents private.
