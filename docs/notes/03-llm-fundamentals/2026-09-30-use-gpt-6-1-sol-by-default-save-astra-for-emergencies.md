## Summary

A model-selection tip: GPT-6.1 Sol is capable enough for everyday use, so save Astra for emergencies only. In other words, use the cheaper capable model by default and escalate only when you need to.

## Key points

- GPT-6.1 Sol is very capable for most work.
- Save Astra for emergencies or hard problems.
- General pattern: route most tasks to the efficient model and escalate only when needed.
