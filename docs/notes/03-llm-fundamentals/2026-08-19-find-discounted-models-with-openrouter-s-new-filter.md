# Find Discounted Models with OpenRouter's New Filter

Melvin Vivas · X post · 2026-08-19 · [Open on X](https://x.com/melvindvivas/status/2089999963250151705)

**Topics:** LLM Fundamentals, LLMOps, Deployment & Monitoring · **Level:** beginner

## Summary

OpenRouter now has a filter that lists all discounted models. The creator points to GPT 5.6 Sol (1M context) pricing as an example, a handy way to cut API costs.

## Key points

- OpenRouter's models page can be filtered to show only discounted models (discount=true).
- GPT 5.6 Sol with 1M context was among the discounted models.
- Compare pricing, context length and benchmarks on OpenRouter before choosing a model.
