Summary

Melvin Vivas shares the news that GLM-5.2 now supports vision (image input) in production, available only on Baseten. The quoted post says the model can take in images and convert them to code, made possible by Baseten's post-training and model API teams.

Key points

  • GLM-5.2 now accepts image input in production.
  • Per the quoted post, the vision version is available only on Baseten.
  • Main use case shown: turning images (e.g. UI designs) into code.
  • Baseten credits its post-training and model API teams for the feature.
  • You can try it from the GLM-5.2 page in Baseten's model library.
