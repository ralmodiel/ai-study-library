xAI's Experimental TypeScript SDK: Grok Text, Voice, Image and Video in One SDK

Summary

Melvin Vivas reshares xAI's announcement of an experimental TypeScript SDK, installed with npm install @xai-official/sdk. One SDK covers text, voice, image and video generation with the latest Grok models. It also gives access to tools that run on xAI's servers: real-time X search, web search, code execution and remote MCP. The video is only a short demo intro ("I'm Eve. Welcome to the SpaceX AI TypeScript SDK"), so there is no tutorial content.

Key points

  • Install command: npm install @xai-official/sdk.
  • The SDK is labeled experimental, so expect its API to change.
  • One SDK covers several kinds of output: text, voice, image and video.
  • It works with the latest Grok models.
  • It includes tools that run on xAI's servers, so you don't host them yourself: real-time X search, web search, code execution and remote MCP.
  • Because the tools run on xAI's side, a TypeScript app can use search, code execution and MCP tools without building its own tool infrastructure.
