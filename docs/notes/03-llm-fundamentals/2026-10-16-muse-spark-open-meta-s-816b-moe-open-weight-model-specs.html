Summary

Melvin points to the benchmark results for Muse Spark Open, which the quoted release calls the most capable US open-weight model to date. The model is built for coding and agentic work. The post lists its main specs.

Key points

  • Muse Spark Open is an open-weight model released as the most capable US open-weight model to date.
  • It is built for coding and agentic work: long-horizon tasks, complex software engineering and multi-step reasoning.
  • It has 816B total parameters but only 42B active, which is a mixture-of-experts design.
  • The quoted specs mention a 1M-token figure, likely the context window (the quoted text is cut off).
  • Check the published benchmarks before choosing it for coding or agent workloads.
