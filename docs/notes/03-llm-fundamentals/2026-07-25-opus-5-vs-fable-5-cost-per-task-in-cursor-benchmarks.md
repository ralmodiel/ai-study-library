# Opus 5 vs Fable 5: Cost per Task in Cursor Benchmarks

Melvin Vivas · X post · 2026-07-25 · [Open on X](https://x.com/melvindvivas/status/2080733336423788872)

**Topics:** LLM Fundamentals, LLMOps, Deployment & Monitoring · **Level:** intermediate

## Summary

Based on Cursor benchmarks, the creator says Claude Opus 5 costs about 50% less than Fable 5, uses fewer tokens per task and has a lower cost per task. He concludes that Fable 5 is no longer needed.

## Key points

- Opus 5 is said to be about 50% cheaper than Fable 5.
- Opus 5 uses fewer tokens per task.
- Comparing cost per task is more useful than comparing price per token.
- The data comes from Cursor's benchmarks.
- Takeaway: re-check which model you use when a cheaper, more efficient one comes out.
