Summary

A quick quiz-style reel that defines 11 acronyms AI engineers use often, covering LLM training, retrieval, agents and API rate limits. The last part promotes the creator's AI engineering community, which offers daily mock interviews with working engineers and recruiters.

Key points

  • RAG = Retrieval-Augmented Generation; LLM = Large Language Model.
  • RLHF = Reinforcement Learning from Human Feedback, a way to align models using human preference data.
  • LoRA = Low-Rank Adaptation, a lightweight fine-tuning method.
  • BM25 = Best Matching 25, a classic keyword-ranking algorithm often paired with vector search in hybrid retrieval.
  • MCP = Model Context Protocol, a standard for connecting models to tools and data.
  • CoT = Chain of Thought prompting; ReAct = Reasoning and Acting, an agent pattern that alternates reasoning steps with tool calls.
  • TPM = Tokens Per Minute and RPM = Requests Per Minute, the usual rate limits on LLM APIs.
  • MMR = Maximal Marginal Relevance, a retrieval method that balances relevance with diversity in the results.
