Ornith-1.0: open-source LLM family for agentic coding

Summary

Ornith-1.0 is a new family of open-source LLMs built for agentic coding. Sizes range from 9B dense to a 397B mixture-of-experts (MoE) model. The quoted announcement claims state-of-the-art results among open models of similar size.

Key points

  • Ornith-1.0 is a family of open-source LLMs specialized for agentic coding.
  • Sizes: 9B Dense, 31B Dense, 35B MoE and 397B MoE.
  • It claims state-of-the-art performance among open-source models of comparable size.
  • The smaller dense sizes could suit local or self-hosted coding agents.
