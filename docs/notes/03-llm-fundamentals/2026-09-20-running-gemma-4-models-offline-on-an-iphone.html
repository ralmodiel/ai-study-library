Summary

A demo of Google's Gemma 4 models chatting fully on-device on an iPhone with no internet. The creator notes the models are also trainable, and he built the app using Devin's Mac environment.

Key points

  • Gemma 4 models can run locally on an iPhone, so chat works without internet
  • On-device inference keeps data local and works offline
  • Gemma models are open and trainable, so you can fine-tune them for on-device use
  • The app was built using Devin's (AI coding agent) Mac environment
