Claude support for Apple's Foundation Models framework

This note summarises a post by Melvin Vivas on X, posted 11 June 2026. The original belongs to Melvin Vivas.

Summary

The creator reacts to news that Claude now supports Apple's Foundation Models framework. The quoted post expects local-model tools such as LM Studio, oMLX, Ollama and llama.cpp to add similar support soon. It is a short news pointer, not a tutorial.

Key points

  • Claude can now be used through Apple's Foundation Models framework, per Anthropic's blog post 'Claude for Foundation Models'.
  • The quoted author expects local or open-model runtimes (LM Studio, oMLX, Ollama, llama.cpp) to add support next.
  • The blog link in the post is cut off and returned a 404 when checked. Search for 'Claude for Foundation Models' on the Claude blog instead.
