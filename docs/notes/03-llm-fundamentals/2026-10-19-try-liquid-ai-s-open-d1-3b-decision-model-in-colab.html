Try Liquid AI's open d1-3B decision model in Colab

This note summarises a post by Melvin Vivas on X, posted 19 October 2026. The original belongs to Melvin Vivas.

Topics: LLM Fundamentals, Fine-tuning & Model Customization · Level: intermediate

Summary

Liquid AI released Open d1, two open-weight multimodal decision models: d1-3B (text + vision) and d1-omni-600M (text + image or text + audio). They are built for real-time decision making on hardware from DGX servers to Jetson edge devices. The creator shares a Colab notebook for trying d1-3B.

Key points

  • Open d1 is Liquid AI's open-weight multimodal decision model family
  • d1-3B handles text + vision
  • d1-omni-600M handles text + image or text + audio
  • Built for real-time decision making, from NVIDIA DGX data centers to RTX workstations to Jetson at the edge
  • The creator's GitHub repo has Colab notebooks for running and fine-tuning local models
