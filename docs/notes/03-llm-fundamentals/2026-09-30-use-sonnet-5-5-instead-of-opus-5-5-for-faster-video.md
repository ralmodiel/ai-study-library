# Use Sonnet 5.5 instead of Opus 5.5 for faster video-clipping tasks

Melvin Vivas · X post · 2026-09-30 · [Open on X](https://x.com/melvindvivas/status/2105170260903256309)

**Topics:** LLM Fundamentals, AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator found that Claude Sonnet 5.5 can handle his 'create clips from a long video' task and runs much faster than Opus 5.5, so he switched models for that task. The lesson: for routine, well-defined jobs, a smaller, faster model is often enough.

## Key points

- Sonnet 5.5 completed the 'create clips from a long video' workflow successfully.
- Sonnet 5.5 was much faster than Opus 5.5 on this task.
- Match the model to the task: if a cheaper, faster model handles it, switch to it.
- Test your recurring tasks on smaller models before defaulting to the largest one.
