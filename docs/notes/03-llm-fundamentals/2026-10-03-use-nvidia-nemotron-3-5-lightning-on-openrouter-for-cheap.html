Use Nvidia Nemotron 3.5 Lightning on OpenRouter for Cheap Worker Tasks

Summary

The creator recommends Nvidia Nemotron 3.5 Lightning as a cheap model that works well for 'worker' tasks, meaning the simple, high-volume subtasks in an agent or automation pipeline. He calls it through OpenRouter.

Key points

  • Nemotron 3.5 Lightning is cheap and handles worker or sub-agent tasks well.
  • Save expensive frontier models for the hard reasoning steps. Send routine worker tasks to a cheap, fast model.
  • OpenRouter gives one API for many models, which makes it easy to swap models per task.
  • The OpenRouter model page lists the model's API pricing and benchmarks.
