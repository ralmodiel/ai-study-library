Summary

This short post says that Tencent Hunyuan's Hy3 model is free on Nous Research's Nous Portal for one more week. Hy3 is pitched as a low-cost model for agent work, and it is described as strong at coding, reliable tool calling, reasoning and long-context tasks. The video has no speech, so the only lesson is that a free model is there to try for agent and coding experiments.

Key points

  • Hy3 is a model from Tencent Hunyuan.
  • Nous Research made Hy3 free on Nous Portal for one extra week 'by popular demand' (posted 2026-07-21, so the free week is likely over).
  • Hy3 is built for low-cost agent use.
  • Its stated strengths are coding, reliable tool calling, reasoning and long-context tasks.
  • You get access by signing up for Nous Portal.
