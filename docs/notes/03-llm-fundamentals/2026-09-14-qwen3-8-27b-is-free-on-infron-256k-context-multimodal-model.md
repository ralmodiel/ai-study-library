## Summary

A quoted post announces that Qwen3.8-27B is free to use on the Infron platform. The model has 27B parameters, a context window of about 256K tokens, and native text, image and video understanding. It is aimed at coding, research and long-horizon agents.

## Key points

- Qwen3.8-27B has 27B parameters.
- It has a context window of about 256K tokens.
- It is multimodal and understands text, images and video natively.
- It is built for coding, research and long-horizon agent tasks.
- It is currently free to use on Infron, so it's a cheap way to test an open model for agent work.
