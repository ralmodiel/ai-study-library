Topics: LLM Fundamentals, Fine-tuning & Model Customization · Level: intermediate

Summary

Fastino's GLiNER2.5-Decide runs on CPU or GPU and can classify the intent of customer support messages. The creator shares a notebook you can run in Google Colab to try it.

Key points

  • GLiNER2.5-Decide runs on both CPU and GPU, so you don't need a big GPU.
  • Example use case: intent classification for customer support workflows.
  • The creator's notebooks repo has local-model fine-tuning and inference notebooks you can run in Google Colab.
