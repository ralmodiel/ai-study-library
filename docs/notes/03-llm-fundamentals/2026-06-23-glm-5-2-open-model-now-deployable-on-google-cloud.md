# GLM 5.2 open model now deployable on Google Cloud

Melvin Vivas · X post · 2026-06-23 · [Open on X](https://x.com/melvindvivas/status/2069108561440026809)

**Topics:** LLM Fundamentals, LLMOps, Deployment & Monitoring, Industry Trends & Job Market · **Level:** intermediate

## Summary

Z.ai's open GLM 5.2 model, a strong coding model for long-running agents, can now be self-hosted on Google Cloud's Agent Platform. The quoted post points to Z.ai's launch blog for details.

## Key points

- GLM 5.2 is an open model aimed at coding and long-running agents.
- You can self-host it on Google Cloud Agent Platform.
- Z.ai's launch blog has the technical details.
