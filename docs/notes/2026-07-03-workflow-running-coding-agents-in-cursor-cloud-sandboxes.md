## Summary

The creator explains how he uses Cursor Cloud to start coding agents on different repos in remote sandboxes, so his laptop's resources aren't used. He pulls complex multi-service projects to his machine for user testing. Website work happens fully in the cloud web or iPhone app, because Cursor tests the changes and shows screenshots and video recordings.

## Key points

- Cursor Cloud starts agents on different repos inside remote sandbox environments.
- Coding runs remotely, so it doesn't use your laptop's resources. The creator says this is free.
- For complex projects with multiple services, pull the code locally and do user testing there.
- For websites, work fully from the Cursor cloud web UI or the iPhone app.
- Cursor can test changes and show screenshots and video recordings as proof.
