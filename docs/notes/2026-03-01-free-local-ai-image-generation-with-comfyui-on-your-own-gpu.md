# Free Local AI Image Generation with ComfyUI on Your Own GPU

Melvin Vivas · X post · 2026-03-01 · [Open on X](https://x.com/melvindvivas/status/2028126807996944796)

**Topics:** AI Dev Tools & Productivity · **Level:** beginner

## Summary

The creator suggests running image generation locally instead of paying for a hosted service: buy a GPU and install ComfyUI. He runs it on an NVIDIA RTX 3090.

## Key points

- After you buy the hardware, ComfyUI lets you generate images locally with no per-image fees.
- The creator runs ComfyUI on an NVIDIA RTX 3090 (24 GB VRAM).
- The main cost is the one-time GPU purchase, not a subscription.
