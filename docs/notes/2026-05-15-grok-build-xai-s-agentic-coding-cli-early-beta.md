## Summary

xAI released an early beta of Grok Build, an agentic CLI for coding, building apps and automating workflows. It is available only to SuperGrok Heavy subscribers, and xAI will improve it based on feedback.

## Key points

- Grok Build is an agentic command-line tool for coding, building apps and automating workflows.
- Early beta, limited to SuperGrok Heavy subscribers, so it is paid.
- It joins other agentic coding CLIs such as Codex and Claude Code.
