# Adding Agent Capabilities to ai-backends with Pi

Melvin Vivas · X video post · 2026-08-15 · [Open on X](https://x.com/melvindvivas/status/2088652078348636217)

**Topics:** AI Agents, Tool Use & MCP, LLMOps, Deployment & Monitoring, Portfolio Projects · **Level:** intermediate

## Summary

Melvin added agent capabilities to his open-source ai-backends project using Pi. ai-backends is an API server for common AI use cases. It supports many models and providers, running locally with Ollama or LM Studio or in the cloud via OpenRouter, OpenAI, Anthropic and others.

## Key points

- ai-backends is an API server runtime for common AI use cases.
- It supports multiple models and providers.
- It runs locally with Ollama or LM Studio, or in the cloud via OpenRouter, OpenAI, Anthropic, etc.
- Agent capabilities were added using Pi (@pidotdev).
- It's open source on GitHub, so you can read the code to see how agents are built in.
