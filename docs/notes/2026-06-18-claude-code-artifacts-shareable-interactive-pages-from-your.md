## Summary

A short announcement repost: Claude Code now supports Artifacts. These are interactive pages built from a Claude Code session, such as a PR walkthrough or a living project dashboard, that you can share with your team at a private link. The feature is in beta on Team and Enterprise plans. The video's transcript has no usable speech, so the caption is the only content.

## Key points

- Claude Code (Anthropic's coding assistant) added a feature called Artifacts.
- Artifacts are interactive pages built from your Claude Code session.
- Example uses: a PR (pull request) walkthrough or a living project dashboard.
- Artifacts are shared with your team at a private link.
- Availability: beta, only on Claude Team and Enterprise plans.
