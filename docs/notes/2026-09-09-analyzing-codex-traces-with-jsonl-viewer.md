## Summary

The creator shares jsonl-viewer, an open-source tool he built for viewing and editing .jsonl files. He suggests using it to understand and analyze Codex session traces, which are stored as JSONL. It also works for fine-tuning and training datasets.

## Key points

- Codex traces are stored as JSONL files.
- jsonl-viewer lets you view and edit .jsonl files.
- It works for agent traces and for fine-tuning/training datasets.
- Reading traces helps you see what a coding agent actually did.
