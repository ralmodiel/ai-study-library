# free-code: Recompiled Claude Code with Guardrails Removed, Works with Codex

## Summary

This post shares 'free-code', a recompiled build of Claude Code's source with telemetry and security-guardrail prompts removed and experimental features turned on. One of those features is 'ultraplan', an async multi-agent planning mode. The creator notes that it works with Codex. Treat it with caution: it is an unofficial build with its safety prompts stripped out.

## Key points

- free-code is a recompiled build of Claude Code's source code, not an official release.
- Telemetry and the security-guardrail prompts have been removed.
- All experimental features are enabled, including 'ultraplan' mode.
- Ultraplan is an async agentic planning mode that starts a multi-agent research session.
- According to the creator, it works with OpenAI Codex.
- Security caution: unofficial builds without guardrails carry security and licensing risks.
