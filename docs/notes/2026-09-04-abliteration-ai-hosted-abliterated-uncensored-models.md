## Summary

The creator points to Abliteration.ai, which hosts 'abliterated' models if you need them. Abliteration is a technique that removes a model's refusal behavior by editing its weights, so these models have weaker built-in safety guardrails.

## Key points

- Abliteration.ai (@abliteration_ai) offers hosted abliterated models.
- Abliterated models have had their refusal behavior removed.
- If you use them, you need to add your own guardrails, because the built-in refusals are gone.
