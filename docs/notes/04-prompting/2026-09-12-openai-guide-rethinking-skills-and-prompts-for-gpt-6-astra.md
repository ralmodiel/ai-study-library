## Summary

The creator shares an OpenAI developer blog post on getting more out of GPT-6 Astra. The post covers revisiting skills, AGENTS.md and task prompts. Its core advice: make skill triggers specific, load guidance only when it's relevant, and define what done looks like.

## Key points

- Review your skills, AGENTS.md and task prompts when switching to GPT-6 Astra
- Make skill triggers specific so skills load only when they apply
- Load guidance only when it's relevant instead of putting everything up front
- Define clearly what 'done' looks like for each task
