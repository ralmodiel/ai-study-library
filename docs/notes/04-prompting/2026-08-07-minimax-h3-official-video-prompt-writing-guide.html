Summary

Melvin Vivas shares MiniMax's official prompt-writing guide for its MiniMax-H3 video model. The guide is hosted in the model's Hugging Face repo. It explains how to write prompts that get good results from this video model.

Key points

  • MiniMax has published an official prompt-writing guide for MiniMax-H3, its video generation model.
  • The guide is the file docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md in the MiniMaxAI/MiniMax-H3 Hugging Face repo.
  • Before writing your own video prompts, read the model vendor's official guide.
