Keep One Topic per Chat (Why Dots Didn't Fit)

This note summarises a post by Melvin Vivas on X, posted 4 October 2026. The original belongs to Melvin Vivas.

Follow Melvin Vivas: Melvin Vivas on X (@melvindvivas) · Melvin Vivas on X (@donvito) · Melvin Vivas on GitHub · Melvin Vivas's website (donvitocodes.com) · Melvin Vivas's blog (melvinvivas.com)

Melvin Vivas · X post · 2026-10-04 · Open on X

Topics: Prompt & Context Engineering, AI Dev Tools & Productivity · Level: beginner

Summary

The creator doesn't like Dots because it mixes different topics into one chat. He keeps each topic in its own chat in ChatGPT and Codex too, which is a simple way to manage context.

Key points

  • Keep each chat or session to a single topic
  • Mixing topics in one chat clutters the context
  • The creator does this in ChatGPT and Codex as well
