# Use local Qwen 3.6 to write JSON prompts for Ideogram 4

Melvin Vivas · X post · 2026-06-20 · [Open on X](https://x.com/melvindvivas/status/2068065147265110074)

**Topics:** Prompt & Context Engineering, AI Dev Tools & Productivity · **Level:** intermediate

## Summary

The creator says Qwen 3.6, running locally for free, can replace ChatGPT or Claude for turning ideas into structured JSON prompts for the Ideogram 4 image model.

## Key points

- A local open-weight LLM (Qwen 3.6) can turn simple prompts into JSON prompts for image models.
- This replaces paid cloud assistants like ChatGPT or Claude for this task.
- Running it locally makes it free and private.
