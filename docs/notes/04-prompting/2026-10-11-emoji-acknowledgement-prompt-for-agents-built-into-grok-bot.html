Emoji Acknowledgement Prompt for Agents (Built Into Grok Bot)

Summary

A quoted post shares a prompt for Dot or any agent: when a request needs no clarification, the agent reacts with an emoji instead of replying in text. Melvin points out that Grok Bot already does this by default, without the prompt.

Key points

  • The prompt: "from now on if you're gonna do something and there is no extra clarification needed from me, instead of responding with text, acknowledge with an emoji on my request."
  • This cuts down on unnecessary text replies from always-on agents.
  • It works with Dot or any agent that follows standing instructions.
  • Grok Bot acknowledges with an emoji by default, so it needs no prompt.
