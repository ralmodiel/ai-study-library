Summary

TypeSafe AI's Jev model is now in beta on OpenRouter, with no waitlist. Jev is a 'System One' model: you give it your app's state plus a typed question, and it returns a typed decision with a probability attached, so you skip JSON prompting, parsing and validation.

Key points

  • Jev is available on OpenRouter in beta, with no waitlist
  • 'System One' model: it makes fast decisions rather than generating text
  • Input: app state plus a typed question; output: a typed decision with a probability
  • Removes the need for JSON prompting, a parsing layer and output validation
