Summary

A short checklist for adapting Codex setups to GPT-6 Astra. Because the model is more capable, prompts, skills and AGENTS.md files should get shorter and less prescriptive. They should still set clear decision boundaries and say clearly what 'done' means.

Key points

  • Give the model fewer instructions; smarter models need less hand-holding
  • Keep skills short
  • Keep AGENTS.md lean
  • Set clear decision boundaries (what the agent may decide on its own)
  • Write a clear definition of done for each task
  • Force less step-by-step process on the model
