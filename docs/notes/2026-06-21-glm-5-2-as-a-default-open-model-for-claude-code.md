## Summary

The creator says GLM 5.2 is now his default open-weight model. He finds it works well inside Claude Code and calls it the best GLM release so far. It's a short practitioner opinion on picking an open model for agentic coding.

## Key points

- GLM 5.2 is the creator's default open model.
- It works well as the model behind Claude Code.
- He rates it better than earlier GLM versions for coding.
