# Hermes Agent: each bot is its own profile

Melvin Vivas · X post · 2026-08-22 · [Open on X](https://x.com/melvindvivas/status/2091050200450412860)

**Topics:** AI Agents, Tool Use & MCP · **Level:** intermediate

## Summary

The creator explains a new Hermes Agent feature: each Hermes Bot is a separate profile. Each profile has its own model settings, channels, skills, MCP servers and cron jobs, so you can run several specialized agents side by side.

## Key points

- In Hermes, every bot is a separate profile.
- Each profile has its own model configuration.
- Each profile has its own channels, skills and MCP servers.
- Each profile can run its own scheduled cron jobs.
- This lets you run several specialized agents next to each other.
