# Free Local Image Generation with Z-Image-Turbo and ComfyUI

Melvin Vivas · X post · 2026-03-18 · [Open on X](https://x.com/melvindvivas/status/2034160862135787926)

**Topics:** AI Dev Tools & Productivity, Portfolio Projects · **Level:** intermediate

## Summary

The creator gets free, unlimited AI image generation by running the Z-Image-Turbo model locally in ComfyUI on an RTX 3090 GPU. Claude Code helped come up with prompt ideas.

## Key points

- Running image models locally removes per-image API costs.
- Z-Image-Turbo runs in ComfyUI on one consumer RTX 3090 (24 GB VRAM).
- A coding agent such as Claude Code can generate prompt ideas for the image model.
