# Make App Product Videos with Claude Code and Opus 5.5

Melvin Vivas · X post · 2026-09-27 · [Open on X](https://x.com/melvindvivas/status/2103898579136020973)

**Topics:** AI Dev Tools & Productivity, Prompt & Context Engineering · **Level:** beginner

## Summary

Shares a ready-to-use prompt that makes Claude Code (running Opus 5.5 on high effort) build a 15-second motion-graphics promo video of your app straight from its repository. The trick is to run it inside the project's repo so the model can read the app's features, and to frame the task as a designer's showreel so the result is more ambitious.

## Key points

- Open Claude Code inside your project's repository so it has the app's code and features as context.
- Use Opus 5.5 with high effort for best results.
- Prompt: 'Make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. go all out. Make it about this app and its features'
- Giving the model a persona and high stakes ('showreel for a résumé', 'go all out') pushes it toward more ambitious output.
- Coding agents can make marketing assets, not just code.
