## Summary

An observation that GPT-6 Sol Ultra spawns subagents at the same Ultra reasoning level, which uses up usage limits quickly. A cost warning for multi-agent coding workflows.

## Key points

- GPT-6 Sol Ultra often spawns Sol subagents at the same Ultra reasoning level.
- High-reasoning subagents multiply token use and use up plan limits fast.
- Keep an eye on subagent reasoning levels to control cost.
